# 연결 — 사람·곳 이름 목록 (계획 14 작업 9). 화면에는 이름과 "내가 필사한 곳"(구절 본문 그대로)만 보이고 해설은 없다.
# 한 줄 = 이름 | 무리 | 찾는 말 [| 덧붙임 …]
#   이름     : 화면에 보이는 이름. 동명이인은 본문의 말로 가른다 (예: "마리아의 남편 요셉" — 마 1:16).
#   무리     : 사람 · 곳
#   찾는 말  : 개역한글 본문에 글자 그대로 나오는 말, 여럿이면 · 로 나눈다.
#              말 앞 글자가 한글이면 세지 않는다 (사마리아의 "마리아", 드루실라의 "실라", 도마가의 "마가"를 거른다).
#   덧붙임   : 범위 <참조>   — 이 구절들 안에서만 찾는다 (동명이인을 가를 때)
#              빼기 <참조>   — 찾는 말이 있지만 다른 사람·곳인 절 (verify: 그 절에 찾는 말이 실제로 있어야 한다)
#              같은 이름 <말> — 동명이인 무리. 같은 무리의 줄끼리는 한 절도 겹치면 안 된다 (verify)
# 참조 문법은 src/content/ref.ts (쉼표로 이어 쓰기, 장을 넘는 범위 "눅 1:27-2:51").
# 근거·뺀 까닭은 docs/content-audit.md §6-13. 고친 뒤: npm run build:connections && npm run verify
