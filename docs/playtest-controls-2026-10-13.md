## 범위와 개발용 변경

- 기존 127.0.0.1:5173 저장은 첫날·서고 0권이며 이전 캐시 화면이 나타났다. 최신 localhost 주소에서 새 시험 칸으로 확인했다. 사용자가 말한 현재 27권 저장 자체는 접근하지 못했으므로, 그 저장의 잔치 발생을 확인했다고 볼 수는 없다.
- `?test=tea-hall`, `tea-cafe`, `copy`, `yard`, `feast`로 필요한 장면에 들어가는 개발용 새 저장을 추가했다. 배포에서는 DEV 조건으로 실행하지 않는다.
- React StrictMode의 효과 재실행으로 시험 칸이 두 번 생성되던 것을 취소 플래그로 막았다. 기존 `?test=26` 경로에도 적용했다. 별도 주소에서 시험 칸 하나만 생성된 것을 불러오기 목록으로 확인했다.
- 시험 데이터의 서고 등급과 요한계시록 완료 기록을 실제 저장 규칙에 맞췄다. 저장 정리 후에도 27권을 유지하고 잔치를 열 수 있는 통합 검사를 추가했다.
- 작업 중 다른 파일 변경으로 HMR이 수차례 화면을 초기화했다. 최종 저장 복원 검사는 `artifacts/controls-playtest/vite.config.ts`로 HMR·src 감시를 끈 localhost:5181 서버에서 수행했다. 콘솔 오류 0건.
- 바느질·텃밭 등 다른 모임 방식은 이번 점검 범위에서 변경하지 않았다.
