# 남은 모바일 흐름 검증

검증일: 2026-10-11. 기존 화면 검증에서 남긴 여행 완료, 공동시설, 모임·행사 당일, 세대 교체, 서고 엔딩을 이어서 확인했다. Chrome 모바일 에뮬레이션과 격리된 개발용 저장 상태를 사용했다. 각 흐름의 선행 상태를 준비한 뒤 화면의 버튼과 손일을 조작했으며, 날짜 경계는 게임의 실제 아침 정산 함수로 처리했다. 실제 사용자 저장을 변경하지 않았다.

## 발견하여 수정한 오류

은퇴한 부모가 마을에 계속 남는 현재 규칙에서는 `movedHeir()`가 후계자를 반환하지 않는다. 대화 내용은 `slotPerson()`으로 후계자를 참조하는데 머리글은 부모 이름을 표시하여 인물이 불일치했다.

`TalkBox.tsx`의 대화 인물 이름과 접근성 이름을 실제 일터 인물인 `slotPerson()`에 맞췄다. 일반 대화·특별 대사·작업 화면·확인 창에 같은 이름을 적용했다. 부모가 이사하지 않아도 후계자 ‘아론’으로 표시되는 브라우저 화면과 회귀 테스트를 확인했다. 수정 후 320·360·390px 및 저장 복원에서도 이름이 유지된다.

## 검증 및 증거

- 관련 테스트 **82개 통과**: 후계자 대화, 주민 대화, 공동시설, 모임 손일, 세대 성장, 여행, 필사 입력·키보드 대응, 잔치 앨범과 세대 저장 복원. 전체 테스트를 재실행한 결과는 아니다.
- `npm run build` 성공. 기존 번들 크기 경고는 남아 있다.
- [전체 캡처 모음](../artifacts/mobile-check/expanded-gallery.html)에 이어서 검증한 화면을 추가했다.
- [추가 검증 원자료](../artifacts/mobile-check/remaining-results.json): 화면 문구, 넘침 측정, 저장 상태 변화.

실제 휴대폰·iOS Safari·OS 가상 키보드·실제 터치 길게 누르기·홈 화면 설치·장시간 성능은 여전히 미검증이다. 길게 누르기는 에뮬레이션 브라우저의 포인터 입력으로 확인했다. 모든 모임 종류·여행 경로·시설·조건 조합을 전수 검증한 것은 아니며, 각 기능의 대표 완료 흐름과 일부 예외 분기를 확인했다.
