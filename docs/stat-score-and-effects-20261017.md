# 능력치 점수와 실제 효과 (2026-10-17)

## 변경
- 표시와 게임 효과, 단계 상승 알림, 최고 단계 업적을 모두 동일한 점수 기준으로 계산: 1~20 / 21~40 / 41~60 / 61~80 / 81~100점.
- 기존 저장의 점수와 성장량을 보존하기 위해 내부 경험치 인코딩은 유지하고, 게임 단계는 `levelOf`에서 점수를 기준으로 계산한다. 원시 `Stat.level`은 저장 인코딩 전용이다.
- 가방의 누적 경험치 안내를 점수별 단계 안내로 바꾸었다. 11점은 1단계다. 81점으로 5단계가 되어도 100점까지 성장한다.
- 지능에 따른 퀴즈 오답 자동 표시/비활성화를 제거했다. `quizDims`, `hintOptions` 및 가방·게임 안내·도움말 편지의 설명도 제거했다. 사용자가 이미 틀린 선택을 표시하는 피드백은 유지한다.
- 손재주의 ‘손놀림이 너그러워지고’ 문구를 삭제했다. 전체 동작 속도 상승 효과는 없으며 기존 제작 미니게임 보조는 유지한다.

## 주석 외 실제 실행 경로 확인
- 매력: `stats.charmBonus → game.heartUp`: 단계별 추가 호감도 0/0/1/1/2점. 주민별 하루 한 번, 실제 보너스가 적용된 경우만 소모하며 이야기 보상은 제외. 관계 상한과 하루 제한 적용, 생일 선물은 하루 제한 예외다.
- 매력: `stats.sellBonus → merchant-selling.sellPrice / sell-stand.standPrice`: 3단계부터 판매 개당 +1닢.
- 근력: `stats.tiredScale → game.toil → finishGather / finishHelp`: 해당 작업 피로 0/6/12/18/24% 감소. 시간 경과 자체의 피로나 모든 작업에 일괄 적용되는 효과는 아니다.
- 근력: `stats.extraChance/luckyExtra → game.withExtra → finishGather`: 채집 추가 생산 확률 0/4/8/12/16%. 도구를 제외한 첫 번째 지급 물건 +1, 가방이 넘치면 미지급.
- 운: 위 채집/제작 추가 생산 확률에 0/3/6/9/12%p를 더한다. 근력 또는 손재주와 운이 모두 5단계면 총 28%다.
- 운: `stats.visitBonus → game의 다음 날 방문 선정 → bonds.pickVisitor`: 기본 20%에 단계별 0/5/10/15/20%p 추가. 마음 5 이상, 해당 주민 방문 후 4일 이상, 오늘 등장 및 방문 선물 등의 조건이 필요하며 방문 기능 해금도 따른다. 저녁 초대 확률에는 적용하지 않는다.
- 운: `stats.rainBonus → game.morningSupplies`: 설치된 빗물 항아리에 비 온 다음 날 아침 3단계부터 물 +1.
- 손재주: `game-store.craft → handEase → startMini`: 최대 찧기 1회 증가량 +20%, 누르기/타이밍 성공 범위 +0.1, 고르기 물건 유지 시간 +20%. 제작에만 handEase를 전달하며 채집·돕기 등은 기본 난이도다. 타이밍 커서 이동 속도는 동일하다.

## 확인
- 관련 테스트 8개 파일, 76개 통과: 능력치 1~100점 전체와 저장 보존, 경계 상승 알림, 실제 채집·제작·호감도·판매 효과, 가방 표시, 지능 최고치에서도 네 보기 모두 활성, 이미 틀린 보기 피드백, 퀴즈 진행 및 필사 방식.
- TypeScript 빌드 검사, 콘텐츠 검사, Vite/PWA 빌드 통과.
- 브라우저 접근은 기존 권한 거부 상태이므로 이번 변경에 대한 브라우저 육안 확인은 수행하지 않았다.
