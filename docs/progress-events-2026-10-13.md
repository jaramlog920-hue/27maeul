# 기존 기능에 연결한 책·성장 이벤트

선택한 1·2·4·5·6번. 별도 해금·보상·계승 시스템을 추가하지 않는다.

- `firstOtBook`: 실제 첫 구약 책의 완필 전환. 모든 장 번호가 완료됐는지 확인하고, 일반 `bookBound` 대신 새 서고 장면을 예약한다. 처음 마친 책의 인덱스를 플래그에 저장하여 재생 때에도 그 책 이름을 표시한다.
- `psalmRest`: 시편 150장 완필 전환에서 한 번. 이미 시편을 끝낸 옛 저장에는 소급하지 않는다. 첫 구약 책을 시편으로 마쳤다면 첫 책과 시편 장면이 각각 한 번 열린다.
- `firstHomeBook`: 기존 완성본 집 책장 배치가 실제로 성공하고, 빈 책장에 첫 책을 놓은 때만. 미완성·가득 찬 책장·내리기·이미 본 뒤 재배치는 제외한다. 원래 제본과 책등 색을 사용하며, 첫 쪽의 시작일·완성일은 실제 기록이 남아 있는 경우에만 표시한다.
- `childLeaves`·`childStays`: 기존 성장 결과와 대사는 유지하며 도트 배경을 추가한다. 어른은 기본 캐릭터와 같은 비율이다. 현재 아이의 옷장·피부·이름을 사용한다. 직업과 거주지 선택은 별도이며, 실제 다른 지역으로 떠나는 선택에서도 배웅 장면을 한 번 예약한다. 이미 배웅한 뒤 집으로 돌아왔다가 다시 떠나면 재예약하지 않는다.
- `workSuccession:<parentSlot>`: 실제 첫 은퇴·계승 전환의 아침에 한 번. 부모의 자리 ID를 장면 ID에 남기고 생성된 자녀 정보를 저장에서 읽는다. 부모도 같은 일터 곁에 남아 쉰다. 주민 자율 진행·세대교체·은퇴의 기존 조건을 그대로 따른다. 이전 은퇴가 있는 저장에는 소급하지 않는다.

모든 장면은 기본 스프라이트를 정수 배로 그린다. 새로 팔·다리를 늘리지 않는다. 앨범 사진은 시작 화면 대신 안정된 8초 시점의 별도 캔버스로 즉시 저장한다. 빨리 닫거나 모션 감소 설정을 켜도 사진이 남으며, 앨범 재생은 기존 사진을 바꾸지 않는다. 미리보기는 실제 저장을 바꾸지 않는다.
