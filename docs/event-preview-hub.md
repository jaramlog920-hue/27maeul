# 모든 이벤트 미리보기

고정 주소: `/assets/events/index.html` (개발 서버: http://localhost:5173/assets/events/index.html).

검색, 여섯 분류, 도트 모션/대화 필터, 개별 재생, 검색한 목록 순서대로 보기를 제공한다. 실제 저장과 선택 결과에는 영향을 주지 않는다.

## 앞으로 이벤트를 추가할 때

모든 새 이벤트는 반드시 이 통합 미리보기에서 확인한다. 별도 갤러리만 만들지 않는다.

- 게임 대화는 `SCENES`, 도트 장면은 `scenic-moments.json` 및 `landscapeKind`에 등록한다. `eventPreviewEntries()`가 두 목록을 직접 읽어 자동 표시한다.
- 개별 이벤트 주소는 `/assets/events/play.html?event=<이벤트 ID>`이다. 실제 게임과 같은 장면 렌더러와 대화 데이터를 사용한다.
- 대표 이미지는 `public/event-previews/`에 저장하고 레지스트리의 이미지 매핑에 연결한다. 없는 이미지는 기본 카드로 표시한다.
- 추가 후 통합 목록과 재생, 대화/선택지를 확인한다. 예전 개별 갤러리에도 통합 목록 링크를 제공한다.
- Vite 다중 진입점으로 게임과 함께 빌드된다. `dist/assets/events/`의 두 페이지와 대표 이미지가 배포 결과에 포함된다. 개발 서버를 다시 켜도 같은 주소를 사용한다.

## 생활 이벤트 다섯 가지

낭독 완료, 첫 초대 식사, 완성본 표지 변경, 독립한 아이의 실제 편지, 공동시설 완공을 실제 행동에 연결했다. 실제 참석자/표지/편지 날짜를 기록하고 재생 시 사용한다. 추가 보상은 주지 않는다.
