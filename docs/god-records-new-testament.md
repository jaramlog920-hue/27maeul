# 하나님 기록: 신약 전용 및 근거 보충

2026-10-16 사용자 요청: 말씀 탭의 하나님 기록은 구약을 제외하고 신약만 사용하며 부족한 근거를 보충한다.

기존 데이터 43개 키워드·134줄은 이미 신약이었다. 기존 신약 근거는 보존하고 다음 21줄을 추가하여 총 155줄로 늘렸다. 본문은 로컬 개역한글 `nt-krv.json`을 `dump-ref.mjs`로 확인했다. 구약 필사·말씀 조각 등 다른 기능은 변경하지 않는다.

고후 1:4는 바로 앞 절의 위로의 하나님을 이어 설명하는 같은 문장이다. 딛 3:5도 앞 절의 하나님을 이어 설명한다. 살전 5:23은 기도문 안의 명시적 호칭인 평강의 하나님만 수록한다. 딤전 1:17의 만세의 왕·썩지 않으심은 영원하심의 직접 근거다. 선하심(막 10:18), 영이심(요 4:24), 빛이심(요일 1:5)처럼 분명한 단일 근거가 있는 항목은 추측성 구절로 숫자를 채우지 않았다.

저장 정리·장 완료 발견·이전 완료 장의 추가 기록 채우기·화면 묶음 모두 신약 책과 일치하는 한 절 표기만 허용한다. 신약 책 ID로 잘못 저장된 구약 참조도 표시하지 않는다. 유효한 기존 기록의 날짜를 유지하고, 추가 근거가 든 완료 장은 불러올 때 중복 없이 채운다.

검증: 엔진 및 말씀 화면 26개 테스트 통과. 스크립트 테스트의 하위 프로세스 실행은 환경 EPERM 제한으로 실행되지 않아, 동일한 검증기 15개 정상/오류 사례를 PowerShell에서 직접 실행해 모두 확인했다. TypeScript, 전체 콘텐츠 verify, Vite 및 PWA 빌드 통과. 로그는 `artifacts/scenery/god-records-nt-*`에 보관했다. 배포는 앞서 확인한 Vercel 접근 제한이 해소되지 않아 수행하지 않았다.
