# 전체 발견 버그 수정 및 옛 집 외관 정리 (2026-10-20)

## 반영 범위

`progress.md`의 종합 재감사 확정 13건(M-01~05, L-01~08)을 수정했다. 비선택 자녀 공동주택 정원, 주민 결혼식 일정 충돌, 후계 배우자 옷장·귀가·일정 이름, 다중 일터 주인 표시, 제작 공간, 이동 공간 대표 위치, 텃밭 수납, 형제 생일 대기열, 형제/여행 외형, 손상된 가방 수량 정규화에 해당한다. 기존 R2-001/002(모달 알림/제작 재고) 수정도 유지한다. 이전 D001~D008은 기존 수정과 회귀 검사를 대조했다. 사용자가 유지하기로 한 보상 정책·밸런스는 변경하지 않았다.

## 사용자가 지적한 옛 집 그림

원인: `newland-building-art.ts`에 준비된 별도 직업 외관과 실제 지도·아이콘·이벤트에서 쓰는 `old-village-art.ts`의 공통 옛 외관이 따로 남아 있었다. 사용자 설명에 따라 둘 모두 별도 집 디자인으로 쓰지 않는다.

- 직업 일터 18종 전체의 옛 지붕·벽·창 외관 생성 코드를 제거했다. `drawNewlandHouse`의 신약 마을 주택 원본을 공유하고 사용자 후속 요청으로 작은 직업 소품도 모두 제거했다.
- 주택·손님집·가족 주택·미술관 기본 외관도 같은 현재 주택 원본을 사용한다. 손님집 하트 간판과 실제 주택의 선택 색·확장 폭 경로는 유지한다.
- 서고 미리보기도 실제 마을과 동일한 `drawLibraryExterior`를 사용한다. 정원·공동 마당과 생활 소품/실내는 유지한다.
- 지도·메뉴 아이콘·이벤트 배경·문 동작·공사 미리보기·PNG 내보내기를 같은 현재 원본에 연결했다. 비교용 `before/` 18장과 `buildings-before-after.png`를 삭제하고 생성 코드/미리보기 링크도 제거했다.
- 공유 생활 소품 팔레트는 별도로 보존한다. 건물 추가 색은 별도 색 키로 변환해 옷·가구·실내가 재색칠되지 않도록 회귀 검사한다.
- 저장의 건물 id·좌표·방향·주인·비용·완공 여부를 수정하거나 삭제하지 않는다. 옛 저장도 현재 그림으로 표시한다.

## 검증

로그·사진은 `artifacts/bugfix-all-20261020/` 아래다.

- 전체 테스트: `npm test -- --configLoader native --pool threads --maxWorkers 2 --reporter=json --outputFile artifacts/bugfix-all-20261020/full-suite.json`. 555파일, 30,787개 중 30,728통과·54실패·5건너뜀. 실패는 모두 하위 Node 프로세스를 실행하는 콘텐츠 검사 8파일에 한정됐다.
- 같은 8파일을 로컬 하위 프로세스 실행이 가능한 권한으로 그대로 재실행: 76/76 통과 (`subprocess-rerun.json`). 제품 코드 수정으로 실패를 덮지 않았다.
- 전체 실행 중 후속 집 그림/UI 변경이 있었으므로 최신 상태 전체 실행이라고 주장하지 않는다. 변경된 집 그림 관련 7파일 35검사, 후계 가족 UI·일정 관련 3파일 23검사를 별도 실행했다. 상세 결과는 `native-building-final.log`, `family-ui-final.log`.

- `tsc --noEmit`, `npm run verify`, 로컬 Vite/PWA 빌드 완료. 청크 크기 경고는 남아 있다.
- 실제 임시 Edge 프로필: 형제 옷장, 성장한 여행 자녀, 각각 주인이 있는 두 일터, 후계 배우자 옷장 전후를 실제 렌더러로 확인. 모바일·가로 사진과 작업 동작 0/2/5초를 기록했다.

- 임시 페이지에서 저장 쓰기만 QuotaExceededError로 실패시켜 실제 공간 부족 안내·백업 다운로드·다시 저장·회복을 확인했다. 실제 디스크를 채우지 않았다 (`quota-results.json`).

## 범위와 상태

실제 사용자 저장은 건드리지 않았다. 수정·검증은 로컬이며 배포하지 않았다. 과거 감사 재현 문서는 증거로 보존한다. 모든 미지의 버그가 없다는 보장은 아니며, 미재현 의심/실기기 미확인/정책 질문을 수정 완료로 세지 않는다. 세부 검사 자동화는 기존 완료 후 정지 상태를 유지한다.

최종 집 외관 회귀: 7파일 35/35 통과, 타입 검사 통과, 최신 빌드의 실제 브라우저 검증 통과. 내보내기로 함께 갱신된 인물/실내 PNG를 HEAD로 복원하려던 보조 작업은 자동 승인 검토가 기존 변경 손실 가능성으로 거부하여 실행하지 않았다. 해당 PNG는 현재 생성 결과를 보존했다.

사용자 최종 요청: 모든 직업 일터의 외관 부착 소품 생성 함수와 호출을 삭제했다. 18종 × 4방향이 소품 없는 현재 주택 그림과 전체 화소 기준으로 같음을 확인했다. 최신 7파일 35검사·타입 검사·PNG 내보내기·실제 브라우저 화면 검증 통과(browser-no-exterior-props.log).
