# 기존 주민의 노년 도트

2026-10-07 사용자 요청: 기존 주민이 노인이 됐을 때 변하는 도트.

- 주민 23명의 기존 외형을 바탕으로 앞·뒤·좌·우, 걷기 두 박자, 앉기·독서 네 박자 PNG를 만들었다. 원래 모습과 노년을 비교하는 preview.html과 before-after.png를 제공한다.
- `elder-details.ts`: 머리 영역만 은회색·밝은 은색·회녹색 그늘로 바꾼다. 모자·두건·액세서리·피부색·작업복·앞치마·가방·신발은 유지한다. 눈가에 작은 주름을 더하고 머리를 한 픽셀 낮춰 자세를 표현한다. 지팡이나 다른 옷을 일괄로 붙이지 않는다.
- `SpriteOpts.elder`를 통해 기존 방향·깜빡임·포즈·가구 사용·행사·가족 모션에 공통 적용한다. 사람 및 모션 캐시 키에도 노년 표시를 넣는다.
- 기존 주민의 `gen.persons[id].stage === 'elder'` 또는 `gen.retired[id]`가 있을 때 지도와 수첩 초상에 적용한다. 후계자는 부모의 노년 표시를 물려받지 않고 자기 단계로 판단한다. 후속 사용자 요청으로 생성 주민의 출생 후 244일 노년도 연결했다(`docs/generated-elders.md`).
- `generationRows`·`familyFrame`에서 노년 단계도 지원한다.
- 자산: `assets/elder-residents/`; 재생성: `node scripts/export-elder-art.mjs`.
- 테스트: 주민 23명·4방향·발 앵커·작업복 보존·좌우 대칭·팔레트·모자 보존·선택 외형 불변·앉기·독서·노년/은퇴 판정. 관련 4파일 33개 테스트 통과. PNG 비교 모음 시각 검수 완료.
- `npx tsc -b` 및 `npm run build`(콘텐츠 검증·TypeScript·Vite·PWA 생성) 통과. 기존 조각 검증 경고 43개와 큰 번들 경고가 남는다. 작업 중 다른 세대교체 파일의 타입 오류가 일시적으로 출력됐으나 해당 파일은 수정하지 않았고, 이후 타입 검사와 빌드가 통과했다.
- 커밋·배포는 수행하지 않았다.
