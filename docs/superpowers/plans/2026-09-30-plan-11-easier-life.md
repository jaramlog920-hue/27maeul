# 스물일곱 권의 마을 — 계획 11: 편해지는 살림 (계획서, 계획 9 다음에 진행)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**언제:** 계획 9(요한계시록) 다음, 계획 10(모이는 곳)·계획 6(연애)보다 먼저. 사용자 요청(2026-09-30 16:15): "플레이할수록 인터페이스나 게임이 편해져야 하는데 그 기능도 넣어야 할 것 같아. 예) 글쓰는 데 필요한 재료 자동 수급 가구 구매, 걷는 속도 빨라지는 아이템 등등".

**Goal:** 날이 갈수록 같은 일(갈대 꺾기 → 파피루스, 그을음+물 → 잉크, 우물 오가기, 먼 길 걷기)을 덜 하게 된다. 한꺼번에 주지 않고, 닢을 모으거나 이웃과 가까워지거나 서고를 채울수록 하나씩 산다·얻는다 — "자라는 것"이 보이게(재미 기준: 판단·실패·자라는 것).

**Architecture:** 살 것은 기존 거래(장날 상인, 목수 부탁)와 `TOOLS`(좋은 펜·밝은 등잔·넓은 책상처럼 한 번 사면 계속 효과)를 넓힌다. 저절로 생기는 재료는 `goToSleep`의 아침 처리에서 `inv`에 더한다(가방이 차면 보관함으로). 걷는 속도는 `movement.ts`의 `SPEED`에 배수를 곱한다. 새 상태는 `GameState`에 더하고 `save.ts`에서 기본값.

## 지금 반복되는 일 (2026-09-30 코드 기준)

- 한 장 = 파피루스 1 + 잉크 1(`CHAPTER_COST`). 파피루스 = 갈대 1(호숫가) → 작업대 30분 미니게임. 잉크 = 그을음 1 + 물 1 → 작업대 20분 미니게임. 물 = 우물.
- 가방 한 칸 최대 9(`MAX_STACK`).
- 걷기 3.5칸/초(`SPEED`), 탭하면 길을 찾아 걸어감.
- 이미 있는 편해지는 것: 좋은 펜(잉크 두 병), 밝은 등잔, 넓은 책상(엮기 시간 20% 줄임), 새 손잡이 기름틀(기름 두 병).
