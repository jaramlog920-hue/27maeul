# 스물일곱 권의 마을 — 계획 5: 사도행전 방

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 서고의 첫 잠긴 방(사도행전 방)을 연다 — 복음서처럼 이웃에게 사도행전 조각을 받아 장을 엮고 서고에 꽂으며, 방 안의 "여정 판"에 본문에 나오는 곳 이름 카드를 본문 순서대로 잇는다. 여정을 다 이으면 호숫가 나루에 배가 들어온다.

**Architecture:** 책 종류 `Book`에 `'ac'`(사도행전)를 더한다. 복음서만의 것(도장·복음서 탐정·"어느 복음서")은 `GOSPELS`(mt·mk·lk·jn)로 남기고, 조각·엮기·서고 꽂기는 `BOOKS`(다섯 권) 기준으로 넓힌다. 여정 카드는 `scripts/journey/ac.txt` → `src/content/journey.json`(검증 스크립트가 곳 이름이 그 구절 본문에 글자 그대로 있는지 검사). 사도행전 방은 서고 안 왼쪽 위 잠긴 문 너머 새 방(`ROOMS`에 `acts`, 지도 아래 보이지 않는 곳).

**Tech Stack:** 기존과 같음.

## Global Constraints

- 설계 §7-1: 조각 엮기 + 여정 잇기, 여정은 **본문에 나오는 곳 이름 카드를 본문 순서대로**(실제 지도 위치는 그리지 않는다), 카드마다 그 곳이 나오는 구절을 보여 준다, 다 채우면 나루터에 배가 온다, **도장 없음**.
- 성경 콘텐츠 오류 0: 조각 범위·제목·곳 이름은 `nt-krv.json`에서 꺼내 확인(`node scripts/dump-ref.mjs "행 1:1-11"`). 제목·곳 이름 낱말은 본문에 있어야 한다(verify). 해석·교리 라벨 금지. 바울의 "선교 여행 1·2·3차" 같은 본문에 없는 구분 이름은 쓰지 않는다 — 여정은 본문 순서 하나로 잇는다.
- 조각 줄 형식은 복음서와 같다(`행 1:1-11 | 제목 |`), 도장 칸은 비운다. 1:1–28:31 빠짐없이·겹치지 않게, 문장 중간에서 끊지 않는다. `(없음)` 절(행 8:37, 15:34, 24:7, 28:29 등 — 원문에서 확인)은 번호만 걸치고 보이지 않는다(계획 3 작업 1의 `versesOf` 거름). 대괄호 구절은 보이되 퀴즈로 묻지 않는다.
- 여정 카드 규칙: 같은 곳이 여러 번 나오면 **여정에서 새로 가는 자리마다** 카드 한 장(예: 안디옥이 두 번). 곳 이름은 개역한글 표기 그대로(예: `다메섹`, `구브로`, `루스드라`). 바다·지방 이름(예: `아시아`)은 사람이 그곳으로 "가는" 문장일 때만. 판단이 애매한 곳은 넣지 않고 content-audit에 적는다.
- 사도행전 방 열림: 복음서 방 완성 잔치(계획 4 작업 3, `flags.gospelFeast`) 다음 날부터. 그 전에는 잠겨 있다(계획 4의 빛나는 문 그대로).
- 사도행전 서고 퀴즈: 퍼즐·빈칸·먼저 나오는 이야기 + "어느 책?"(출제 범위에 다른 책이 있으면). 탐정 문제 없음. 정답 유일 규칙과 `quizzable` 적용(계획 3 작업 1).
- 문구·그림 규칙은 계획 4와 같다(청소년 톤 파스텔, 2픽셀 이상 선, 금지어 verify).
- 커밋 전 네 가지 검사, 커밋 끝줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, 브랜치 `plan-1-trial`. 배포는 작업 6에서만(사용자 사전 승인).
