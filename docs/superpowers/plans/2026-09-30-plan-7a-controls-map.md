# 스물일곱 권의 마을 · 기록자의 나날 — 계획 7-1: 조작과 지도 다듬기

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사용자가 폰으로 해 보고 짚은 것들을 고친다(2026-09-30 아침). 두 게임(스물일곱 권의 마을 `twenty-seven/`, 기록자의 나날 `gospel-days/`) 모두에 해당하는 것은 둘 다 고친다.

1. 오른쪽 아래 둥근 조이스틱은 네 방향으로만 움직이는데 둥글어서 원하는 쪽으로 잘 안 간다 → **네 방향 + 가운데(누르기)** 조이스틱을 기본으로, 옛 둥근 것은 설정에서 고를 수 있게. **조이스틱 자리(오른쪽/왼쪽)**도 설정에서 고른다.
2. 걸을 때 뒷모습(그리고 앞모습) 다리가 양옆으로 벌렸다 오므리는 개구리 걸음 → 다리가 앞뒤로 번갈아 나가는 걸음.
3. 설정·도움말 창이 처음 열었을 때 아래로 더 있다는 게 안 보인다 → 스크롤할 게 남았다는 표시.
4. (마을만) 빵 굽는 이웃이 빵집과 목수 집 사이 한 칸 길을 막는다.
5. (마을만) 넓히기 전인데 내 집 겉모습이 너무 크다 → 가장 작은 이웃집과 같은 크기, 집 안은 이웃집처럼 따로 된 방.

**Tech Stack:** 두 게임 모두 Vite, React 19, TypeScript, Zustand 5, Vitest. 마을은 gospel-days를 복사해 시작했으므로 조이스틱·스프라이트·설정 코드가 거의 같다.

## Global Constraints

- 화면 문구는 한국어, 게임 문장은 각 게임의 문구 파일(마을 `src/content/life-text.json`)에, verify(금지어) 통과. "벌" 금지.
- 그림: 청소년 톤 차분한 파스텔, 2픽셀 이상 선, 유아틱·하트 금지. 그림을 바꾸면 미리보기에서 확대해 확인.
- 설정 값은 기존 조이스틱 켜짐/꺼짐처럼 `localStorage`에(키는 게임마다 `twenty-seven/…`, `gospel-days/…`), 없으면 기본값. 저장 파일 형식과 버전은 그대로(마을은 필드를 더하면 `save.ts`에서 기본값 채우기).

### Task 1: 네 방향 조이스틱과 설정 (마을)

**Files:** `src/features/play/Joystick.tsx`(+테스트), `Settings.tsx`, `src/store/game-store.ts`, `src/app/global.css`, `life-text.json`

- [ ] **네 방향 패드(기본)**: 위·아래·왼·오른쪽 네 단추와 가운데 단추가 십자로 놓인 패드. 방향 단추를 누르고 있는 동안 그쪽으로 계속 걷는다(지금 조이스틱처럼 한 칸 끝나면 다음 칸). 손가락을 누른 채 다른 방향 단추로 미끄러지면 방향이 바뀐다(pointer capture + 좌표로 판정). 가운데 단추 = **누르기**: 바라보는 쪽 앞 칸(없으면 서 있는 칸)을 화면에서 누른 것과 똑같이 처리(`tap`) — 이웃과 말하기, 장소 쓰기, 문 열기.
- [ ] **설정**: "조이스틱" 칸에 켜짐/꺼짐(기존), **모양** 네 방향(기본)/둥근, **자리** 오른쪽(기본)/왼쪽. 왼쪽이면 화면 왼쪽 아래.
- [ ] 단추는 손가락에 맞게 크게(한 단추 44px 이상), 반투명, 누르는 동안 눌린 모양. 게임 화면을 너무 가리지 않게.

- [ ] 커밋 `feat: 네 방향 조이스틱(가운데 누르기), 모양·자리 설정`.
