# 스물일곱 권의 마을 — 계획 12: 아이 (초안, 계획 6 다음에 진행)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**언제:** 계획 6(연애와 결혼) 다음. 계획 11 작업 4의 능력치 다섯(`GameState.stats`)이 있어야 한다.

**Goal:** 결혼 뒤 아이가 태어나 자란다(설계 "아이 — 결혼 뒤 태어나 자란다, 자라는 단계"). 아이는 부모의 능력치 **타고난 값**을 물려받고, 자라서 그 능력치에 맞는 일로 살림을 돕는다. 누구와 결혼하느냐에 따라 아이가 달라진다.

## 사용자 결정 (2026-09-30)

- 아이는 **돕는 역할**이다. 대를 이어 아이로 플레이하지 않는다 — 게임의 목표(서고 스물일곱 권)가 흐려지지 않게.
- 능력치는 지능·손재주·매력·근력·운. 아이는 **단계가 아니라 타고난 값**을 물려받는다(1단계부터 스스로 자람).

## 물려받기

- 플레이어 쪽: 결혼할 때 단계 4 이상인 능력치 → 아이의 타고난 값 +1.
- 배우자 쪽: 후보마다 집안에 맞춘 잘하는 능력치 하나 → +1 (계획 6 후보 정의에 `stat` 필드).
- 한 능력치의 타고난 값은 최대 2.

| 남 | 집안 | 능력치 | 여 | 집안 | 능력치 |
|---|---|---|---|---|---|
| 웬델 | 빵 굽는 집 | 손재주 | 메리골드 | 포도원 | 운 |
| 코스모 | 어부 댁 | 근력 | 페넬로피 | 베 짜는 집 | 손재주 |
| 루디 | 제본 골목 목수 댁 | 지능 | 틸리 | 대장간 | 근력 |
| 덱스터 | 양치기 댁 | 운 | 주니퍼 | 벌 치는 집 | 지능 |
| 바질 | 약방 | 매력 | 파피 | 찻집 | 매력 |

- 표는 `neighbors.json`의 `family`·`stat`과 같다 (2026-09-30 고침: 틸리=대장간/근력, 주니퍼=지능, 바질·파피 추가).

## 자라는 단계

| 단계 | 모습 | 하는 일 |
|---|---|---|
| 아기 | 집 안 요람 | 없음 (아기 잔치) |
| 걷는 아이 | 동반 동물처럼 곁을 따라다님 | 없음 |
| 돕는 아이 | 혼자 마을을 다님 | 타고난 값이 가장 높은 능력치의 일을 하루 한 번 (아래). 그 일로 아이 자신의 단계도 오름 |

| 가장 높은 능력치 | 하루 한 번 |
|---|---|
| 근력 | 물 또는 갈대 1 |
| 손재주 | 파피루스 또는 잉크 1 |
| 매력 | 이웃 한 명 하트 +1 (대신 인사하러 감) |
| 지능 | 일지에 이웃 이야기 한 줄, 가끔 조각 하나를 먼저 들어 옴 |
| 운 | 가끔 뜻밖의 선물 (무화과·꿀 등) |

- 같으면 배우자 쪽 능력치를 먼저.
- 모든 도움은 "덜 반복"이지 "공짜"가 아니다 — 하루 한 번, 계획 11의 균형 기준 안에서.

## 정한 것 (구현 2026-09-30, `src/engine/child.ts`)

- 결혼하고 14일 지난 아침에 태어난다(장면 `childBorn`, 이름 정하기 창). 모습(사내아이·여자아이)은 날 씨앗.
- 아기 0~13일(넓힌 방 요람) → 걷는 아이 14~41일(기록자 뒤를 따라다님, 장면 `childWalks`) → 돕는 아이 42일부터(아침 우물가·낮 장터·저녁 집 앞·밤 집 안, 장면 `childHelps`).
- 돕는 일은 아침에 한 번: 근력 물/갈대, 손재주 파피루스/잉크 (날마다 번갈아), 매력 이웃 한 명 마음 +2, 지능 사흘에 한 번 오늘 조각을 먼저 들어 옴, 운 이틀에 한 번 무화과/꿀. 아이 자신의 그 능력치 경험치 +10.
- 요람·아이 그림: 요람은 작은 나무 요람, 걷는 아이는 아기 걸음 그림, 돕는 아이는 물 긷는 아이 그림에 옷 색만 바꿈(사내아이 풀빛, 여자아이 보랏빛).

## 아이와 함께 보내는 시간 (2026-10-04 사용자 — 다음 작업)

**방향:** 보육원 = 빠르고 편한 능력치 성장(지금 그대로), **직접 함께하기** = 조금 느리지만 친밀도 + 추억 + 특별 장면. 효율 때문에 무조건 보육원에 맡기지도, 매일 아이 미니게임을 해야 하는 육아게임이 되지도 않게. **모든 활동을 미니게임으로 만들지 않는다** — 누르기 → 짧은 장면 → 결과.

| 함께하기 | 오르는 것 | 장면·결과 |
|---|---|---|
| 📖 같이 책 읽기 | 지능 | 아이가 옆에 앉아 책을 봄 |
| 🧩 퍼즐·블록 놀이 | 지능·손재주 | |
| 🧵 같이 만들기 | 손재주 | 작은 장난감·장식품이 생김(집 꾸미기 가구로 쓸 수 있게) |
| 🥖 같이 요리하기 | 손재주 | 가끔 실패작(탄 빵 등)도 나옴 |
| 🌿 산책하기 | 근력 | 마을에서 작은 사건이나 물건 발견 |
| 🏃 공놀이·달리기 | 근력 | |
| 🏘️ 마을 구경하기 | 매력 | 이웃이 아이에게 말을 걺 |
| 🎁 이웃에게 심부름 | 매력 | |
| 🗺️ 가족 여행 | 여러 능력치 조금 | 추억 하나 |
| 🌙 잠들기 전 이야기 | (능력치 없음) | 친밀도·기분 |

- 하루에 함께하기 한두 번(아이 쪽 피로·하루 시간), 보육원과 같은 날 둘 다 가능.
- **아이와 함께 책상에 앉기(필사와 이음, 계획 14 작업 10):** 아이가 어느 정도 자라면 필사를 시작할 때 가끔 "○○가 옆에 앉고 싶어 해요." → [같이 있기] / [혼자 쓰기]. 아이는 필사하지 않고 능력치도 얻지 않는다 — 옆에서 그림 그리기·책 넘겨보기·졸다 잠드는 작은 도트 그림만. 장을 마치면 장 완료 화면 끝에 "○○와 함께 조용한 시간을 보냈어요." 한 줄.
- **가족 추억(앨범):** 능력치 숫자만 남지 않게, 처음 있는 일마다 앨범 한 장 — 처음 같이 산책한 날 · 빵을 태운 날 · 봄 소풍 · 책상 옆에서 잠든 날 · 첫 장날 구경 · 가족 여행 등. 앨범의 "가족" 쪽에 차곡차곡.
- **배우자와 식사·가족 생일 (2026-10-04 사용자):** 결혼 뒤 저녁에 가끔 배우자와 같이 먹는 짧은 장면(배고픔·기분), 배우자·아이 생일에 작은 장면과 앨범 한 장(생일은 결혼·출생 날 기준, 선물하면 마음 +). 미니게임 없음.
- **넣지 않는 것:** 아이의 신앙을 수치로 키우는 것(성경 교육 +3 같은 것), 매일 해야 손해 안 보는 아이 퀘스트.
