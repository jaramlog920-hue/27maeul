# 스물일곱 권의 마을 — 계획 15: 계절은 자라는 것, 날씨는 그날의 하늘

**사용자 결정 (2026-10-04):** 지붕·길·호수 같은 바탕 색은 계절마다 바꾸지 않는다(이상해 보임). 대신 현실에서 실제로 바뀌는 것 — 자라는 것·날씨·사람 — 만 바꾼다.

## 바꾸는 것

| 계절 | 자라는 것 |
|---|---|
| 봄 | 과일나무 몇 그루(정해진 자리)에 흰·분홍 꽃, 풀밭 들꽃 늘어남, 보리밭 새싹(연두), 갈대 새순 |
| 여름 | 나뭇잎 한 톤 짙게, 키 큰 풀포기, 보리 누렇게 익음, 호수 반짝이는 물빛(움직이는 하이라이트 몇 점) |
| 가을 | 활엽수 일부만 노랑·붉은 잎(올리브·소나무 같은 늘푸른나무는 그대로), 나무 밑 낙엽 몇 장, 포도 익음(있음), 보리 벤 그루터기, 갈대 갈색, 장터 좌판에 수확 바구니 |
| 겨울 | 활엽수 잎 진 가지, 포도 덩굴 마름, 밭 맨흙, 텃밭 쉼(있음) |

| 날씨(그날만) | |
|---|---|
| 눈 온 날 | 지붕 위·땅에 눈(지금의 흰 덮개를 지붕 윗줄·땅 가장자리 중심으로 다듬기) |
| 추운 아침(겨울 맑은 날 6–9시) | 호숫가 물가 한 줄 살얼음 |
| 비 온 뒤(비 온 날 저녁~다음 날 낮) | 길에 물웅덩이 몇 개 |
| 겨울 | 굴뚝 연기 많이, 이웃 목도리(스프라이트 목 줄 색) |

## Global Constraints
- 풀 색은 이미 계절마다 바뀐다(`SEASON_GRASS`) — 그대로 두되 가을·겨울 풀이 세이지 톤과 어울리게만 확인.
- 그림 규칙(청소년 톤 파스텔, 2픽셀 이상 선), 채도 필터(`saturate(0.87)`)를 지난 뒤의 모습으로 확인.
- 나무 종류 표시: 지도에 그리는 나무 중 어떤 것이 활엽수/과일나무/늘푸른나무인지 자리로 정한다(`world.ts` 데이터, 테스트).
- 성능: 계절 그림은 지도 캐시(`mapFor(season)`)에 굽고, 날씨 것만 매 프레임.
- 커밋 전 네 가지 검사, 커밋 끝줄 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## 작업
1. 나무 종류 데이터와 계절 나무(꽃·짙은 잎·물든 잎·빈 가지·낙엽), 보리밭·갈대·포도 덩굴 계절 모습 — 지도 캐시에 굽기.
2. 날씨 그림: 눈 쌓임 다듬기, 살얼음, 물웅덩이, 겨울 굴뚝 연기, 이웃 목도리.
