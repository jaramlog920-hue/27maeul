# 계획 18 — 구약 서고와 두 번째 마을

작성: 2026-10-05
상태: 기획 플랜 작성 완료 / 구현 시작 전
연결 계획: [계획 19 — 주민의 자율 가족과 다음 세대](2026-10-06-plan-19-resident-generations.md). 새 주택·일터·공동 공간을 주민 가족의 성장과 연결한다.
사용자 요청: 신약 완필 뒤 빈 토지와 작은 구약 서고를 받고, 첫 마을을 오가며 새로운 삶을 꾸미는 기획을 플랜으로 작성.

## 1. 목표와 완성된 모습

두 번째 맵은 ‘신약에서 받은 것을 가지고 빈 땅에 새로운 삶을 세우는 곳’이다.
첫 마을에서 배운 기술과 맺은 관계가 자식의 독립, 이웃의 꿈, 새로운 입주민의 이야기로 이어진다.
처음에는 작은 서고 하나뿐이지만, 완성된 마을에는 플레이어가 배치한 길·정원·집, 자식의 일터, 주민의 꿈터, 함께 사용하는 마당과 기억이 남는다.
정해진 완성 배치나 모든 건물을 지어야 하는 종료 조건은 없다. 빈 공간을 남겨도 된다.

## 2. 기획의 기준

- 신약 완필 보상으로 토지와 작은 서고를 받는다. 처음 땅과 서고를 사기 위해 돈을 모을 필요는 없다.
- 작은 서고에도 구약의 모든 책을 보관할 수 있다. 책상 하나와 작은 책장 하나로 시작한다.
- 필사는 돈·기름·재료·피로·시간·건물 확장에 막히지 않는다. 기록 설비 업그레이드를 다시 만들지 않는다.
- 건축과 꾸미기는 선택적인 생활 활동이다. 서고 확장은 공간·전시·만남을 넓히는 일이다.
- 첫 마을과 두 번째 마을은 계속 왕래한다. 기존 공방·찻집 등의 역할을 유지한다.
- 신약에서 발견한 하나님에 대한 키워드는 사라지거나 소비되지 않는다.
- 성경 본문, 출처, 플레이어의 메모, 게임의 가상 이야기와 연출 문구는 구분한다.
- 신앙의 깊이나 옳고 그름을 능력치·돈·정답 점수로 평가하지 않는다.
- 아래 건물과 주민 방식은 구현을 위한 제안안이다. 개별 비용·규모·인물·보상은 아직 확정하지 않는다.

## 3. 개방과 첫날

1. 기존 신약 27권 완필·서고 완료 판정을 확인한다. 단순 수집량으로 개방하지 않는다.
2. 완료 보상 장면에서 토지와 작은 서고를 받는다. 보상은 저장당 한 번만 지급한다.
3. 지도에 두 번째 맵 입구가 나타난다. 방문을 미루어도 보상을 잃지 않는다.
4. 첫 방문에는 작은 서고와 빈 토지만 보인다.
5. 서고 문을 열면 아침빛이 들어오는 연출과 창세기의 ‘빛이 있으라’ 구절을 출처와 함께 제시한다.
6. 첫 기록을 남긴 뒤 맵 전체가 드러난다. 연출 건너뛰기를 지원하며 필수 추가 비용은 없다.
7. 길과 정원, 생활 공간을 자유롭게 배치하기 시작한다. 첫 마을로 즉시 돌아갈 수 있다.

‘태초부터 빛이 있었다’는 게임 연출 문구로 쓸 경우 성경 직접 인용처럼 표시하지 않는다.
사용할 번역과 정확한 구절 표기는 구약 본문 준비 단계에서 검수한다.

## 4. 반복해서 이어가는 이유

기본 흐름: 기록하기 → 사람의 바람을 발견하기 → 공간 선택·준비하기 → 그곳에서 일어나는 이야기 → 변화와 기억 남기기.
각 흐름은 독립적으로 선택할 수 있다. 건물을 지어야 다음 구절을 쓰는 구조로 묶지 않는다.

장기적인 관심사는 다음과 같다.
- 이웃의 꿈이 이루어진 뒤 실제 생활은 어떻게 바뀌는가?
- 독립한 자식이 자신의 직업과 관계를 어떻게 이어가는가?
- 다음 방문자는 누구이며, 어떤 습관과 이야기를 가지고 오는가?
- 내가 선택한 공동 공간이 주민들의 만남을 어떻게 바꾸는가?
- 기록과 관계의 기억이 마을 풍경에 어떻게 남는가?

건물마다 ‘건설 완료’ 뒤 최소 한 개의 후속 생활 이야기와 반복되는 일과를 설계한다.
수익 수령과 동일 대사 반복만으로 후속 생활을 대신하지 않는다.

## 5. 두 마을을 오가는 규칙

- 날짜·시간·계절·가족·소지품·관계는 하나의 저장에서 공유한다.
- 왕래할 때 기존 필사 진행, 가구 배치, 예약된 약속이 유지된다.
- 맵 이동은 명시적인 입구/지도 선택으로 한다. 다른 맵으로 강제 이동시키지 않는다.
- NPC는 같은 시각에 두 곳에서 활동하지 않는다. 이사·방문·출근·약속을 하나의 위치 상태로 관리한다.
- 기존 주민의 이사는 강제하지 않는다. 원래 직업과 시설을 누가 운영할지 정한 뒤 이사를 허용한다.
- 첫 마을에 있는 필수 서비스가 사라지지 않도록 출퇴근·부분 방문부터 지원한다.
- 첫 마을과 둘째 마을의 집·가구를 별도 소유 공간으로 저장한다.

## 6. 신약 키워드의 계승

기존 godRecords의 발견 기록을 원본으로 사용한다. 중복 키워드를 얻기 위해 다시 기록하도록 요구하지 않는다.
원문 기록은 보존하고, 두 번째 맵에서는 발견한 키워드와 출처를 돌아보는 화면을 제공한다.

키워드는 건물 개방 재료가 아닌 생활 선택의 관점으로 연결한다.
예시:
- 사랑: 서로 다툰 주민의 이야기를 듣고 함께 쓰는 마당을 마련한다.
- 소망: 작업에 실패한 주민의 재도전을 도와 다음 이야기를 연다.
- 평안: 조용한 쉼터를 선택하고 주민의 쉬는 일과에 연결한다.

실제 지원 목록은 기존 키워드 목록과 대조해 결정한다. 미발견 키워드로 생활 기능을 영구 차단하지 않는다.
선택의 결과는 대사·만남·공간 이용·기억에 남긴다. 키워드별 우열이나 ‘더 신앙적인 선택’ 점수를 만들지 않는다.

## 7. 건물 목록 제안

| 건물 | 쓰임 | 건설 뒤 생활 |
|---|---|---|
| 구약 서고 | 필사·보관·전시·개인 메모 | 읽은 책과 주제별 기록, 함께 읽은 기억 |
| 자식의 집 겸 일터 | 독립한 자식의 거주와 직업 공간 | 출근·방문·작업·가족 사건 |
| 주민의 꿈터 | 첫 마을에서 들은 꿈을 실현 | 개장·첫 손님·어려움·개선·새 일과 |
| 입주 주택 | 새로운 주민의 거주 | 고유 습관·관계·작은 이야기 |
| 손님집 | 여행자·친척의 임시 체류 | 새로운 인물과 재방문, 입주 전 만남 |
| 공동 마당 | 식사·발표·작은 행사·공동 활동 | 참석 인물에 따라 달라지는 장면 |
| 기억 정원 | 가족과 마을의 기억 전시 | 실제 사건의 기념물과 날짜·참여자 |

공방·찻집을 자동으로 두 번째 맵에 복제하지 않는다. 기존 시설과 다른 역할이나 인물의 사연이 있을 때만 새로운 공간으로 제안한다.

## 8. 건축과 가구 배치

> 2026-10-07 사용자 확정: 새 배경 도트 소재(`assets/background-materials-simple.png`)는 **유저가 길·바닥·나무를 직접 꾸밀 수 있도록 선택해서 배치하는 추가 요소**로 준비한다. **구약 맵의 기본 길 자체를 변경하거나 기존 길 그림을 일괄 교체하지 않는다.** 소재 시안이며 게임 연결은 별도다. [소재 사용 범위](../../../assets/background-materials-usage.md)를 적용 기준으로 삼는다.

건축 흐름: 목록에서 건물 선택 → 쓰임·거주자·비용 확인 → 부지 미리보기 → 배치 확정 → 건설 → 내부 꾸미기 → 사용 시작.
서고의 기본 기능은 건설 대기와 관계없이 사용 가능하다.

- 기본 서고와 첫 건축 연습에 필요한 최소 꾸미기 재료는 보상으로 제공하는 안을 우선 검토한다.
- 선택 건물의 비용·재료는 기존 경제와 대조한 뒤 결정한다. 반복 필사를 돈 획득 수단으로 강제하지 않는다.
- 건물·가구의 출입구와 이동 경로를 검사한다. 집 안에 갇히는 배치를 막는다.
- 기존 가구 회전·외형·사용 동작을 재사용한다. 맞지 않는 크기의 그림을 늘려 쓰지 않는다.
- 이동/철거 전에 거주자와 예약 활동을 처리한다. 필수 서고 접근을 없앨 수 없다.
- 철거 환불·건설 취소 비율은 미정이며, 구현 전에 중복 환불 방지 규칙을 정한다.

## 9. 자식의 집 겸 일터

현재 구현된 자식 직업 목록과 능력/관심 기반 추천을 이어받는다. 새 맵 때문에 직업을 다시 무작위로 정하지 않는다.
독립은 플레이어와 자식이 선택하는 사건으로 다루고, 성장 즉시 자동 이주시키지 않는다.

직업별 공간 예시: 요리사의 작은 조리실, 화가의 작업실, 직조인의 베 작업방, 정원사의 온실/뜰, 도예가의 작업장.
이 예시는 기존 직업 ID와 대조한 뒤 실제 목록으로 확정한다.

진행: 독립 대화 → 거주/출퇴근 방식 선택 → 직업에 맞는 집 마련 → 가구 배치 → 첫 작업 → 첫 방문 → 후속 생활.
첫 작업의 성공 여부, 부모와 함께 만든 물건, 방문 식사 등을 실제 발생했을 때 가족 기억에 남긴다.
자식이 없는 저장에서도 두 번째 맵의 다른 기능을 이용할 수 있다.

## 10. 주민의 꿈터

첫 마을에서 주민이 꿈을 이야기한다. 수첩에 ‘들은 바람’으로 기록한다.
두 번째 맵 개방 뒤 건물 목록에 ‘미술관 — ○○의 꿈’처럼 근거를 표시한다.
꿈을 아직 듣지 않았다면 만나서 알아갈 수 있으며, 기간 제한으로 사라지지 않는다.

공통 이야기 단계:
1. 꿈을 듣는다.
2. 공간과 운영 방식을 함께 정한다.
3. 준비 또는 작은 시도에 참여한다.
4. 개장한다.
5. 예상과 다른 어려움을 만난다.
6. 선택한 해결 방식이 일과·소품·대사에 남는다.

개별 주민의 꿈은 기존 설정을 읽고 결정한다. 모두에게 같은 가게 개장 이야기를 배정하지 않는다.
건물과 이사는 별도 선택이다. 첫 마을에 살면서 새 맵의 꿈터로 출근할 수도 있다.

## 11. 새로운 주민과 수집

누가 찾아올지는 랜덤으로 하되, 입주는 플레이어가 선택한다.
손님집에서 며칠 대화하고 습관과 사연을 알게 된 뒤 빈집으로 초대한다.
입주를 거절하거나 미루어도 불이익 없이 재방문할 수 있다.

각 인물의 최소 구성:
- 구분되는 외형·말투·생활 취향
- 실제 공간과 시간에 따른 일과
- 고유 선물 한 개와 출처가 드러나는 설명
- 작은 이야기와 완료 뒤 변화
- 다른 주민과의 관계 한 개 이상

고유 선물은 첫 입주 때 한 번만 지급한다. 재이사로 복제되지 않는다.
도감은 발견한 선물과 인물의 기억을 기록한다. 무작위 방문 기록은 저장해 재접속으로 선물을 계속 다시 뽑지 못하게 한다.
수집을 위해 주민을 계속 내보내야 하는 구조를 피한다. 입주하지 않은 인물과의 후속 친분으로 얻는 대체 경로를 검토한다.
방문/재방문 확률·보장 횟수·입주 정원·초기 인물 수는 미정이다.

## 12. 구약 서고의 확장

작은 서고는 처음부터 모든 책을 보관한다. 확장은 보관 용량 증가가 아니라 다음 공간을 더하는 일이다.
- 책별 기록대: 완필한 책과 기억한 구절
- 주제별 진열: 약속·지혜·탄식·회복 등의 기록 묶음
- 개인 메모 자리: 자신의 생각을 성경 본문과 구분해 기록
- 함께 읽는 자리: 실제 참여자와 읽은 날의 기억
- 전시/열람 공간: 가구 배치와 장식 선택

구약 본문 전체 제공과 생활 맵 개방은 별도 개발 항목이다. 본문 일부만 준비됐을 때 전권 필사가 구현됐다고 표시하지 않는다.
정경·권수·책 순서·번역·사용 권한·본문 분량·입력 단위는 데이터 준비 전에 확정한다.
기존 신약 Book 타입을 단순 확장해 신약 전용 판정이 깨지지 않도록 성경 범위와 책 식별 구조부터 설계한다.

## 13. 공동 마당과 기억 정원

공동 마당은 소모임·함께 일하기·가족 발표·작은 행사의 기존 엔진을 우선 재사용한다.
계획만 있고 미구현인 행사 기능은 별도 구현 항목으로 표시한다.
혼자 준비해도 장소는 쓸 수 있고, 초대된 NPC가 실제로 참석해야 공동 기억을 기록한다.

기억 정원은 실제 완료한 사건에서만 기념물을 연다.
옛 저장에 날짜가 없으면 날짜 미상으로 표시하고 날짜나 참여자를 만들어내지 않는다.
기념물은 배치/회수할 수 있으며, 추억 기록 자체는 회수나 철거로 삭제되지 않는다.

## 14. 저장 구조 제안 — 아직 코드 API 확정 아님

- 둘째 맵 개방 여부·보상 지급·첫 방문 연출 완료
- 현재 맵 ID와 맵별 플레이어 위치
- 맵별 건물·길·장식·가구 배치와 소유 공간 ID
- 주민별 거주지·출퇴근·방문 상태 및 꿈 이야기 진행
- 자식의 독립·주거·일터 연결
- 방문자 추첨 상태·재방문·입주·고유 선물 수령 기록
- 서고 전시 선택·개인 메모·공동 읽기 기억

옛 저장에는 선택 필드와 안전한 기본값을 적용한다.
이동 후 불러오기는 현재 맵의 유효한 입구로 복구한다. 삭제된 건물이나 잘못된 좌표에서 시작하지 않는다.
신약 기록·가족·소모임·취향·직업·가구 외형·장신구 색상은 그대로 보존한다.

## 16. 구현 순서와 완료 기준

아래 항목은 모두 구현 시작 전이다. 체크박스는 실제 연결·검증 후에만 표시한다.

- [ ] 작업 1: 기존 신약 완료 판정·구약 데이터·맵/저장 구조 조사. 정경/번역/범위를 확정하고 데이터 작업량 기록.
- [ ] 작업 2: 두 맵 왕래와 저장. 첫 마을 진행 보존, 같은 날짜/시간, 안전한 위치 복구 확인.
- [ ] 작업 3: 완필 보상과 첫 방문. 한 번만 지급, 옛 완필 저장도 수령, 건너뛰기와 재접속 확인.
- [ ] 작업 4: 작은 구약 서고와 필사. 본문 준비 범위를 정확히 표시, 무조건 필사, 저장/진도/출처 확인.
- [ ] 작업 5: 부지 배치·건축·실내 가구. 출입/경로, 이동/취소/철거, 소유 공간별 저장 확인.
- [ ] 작업 6: 신약 키워드 계승과 생활 선택 대표 사례. 원본 보존·미발견 시 대안·결과 기억 확인.
- [ ] 작업 7: 자식의 집 겸 일터 대표 직업. 기존 추천/선택 보존, 자식 없는 저장, 독립/출퇴근/가족 방문 확인.
- [ ] 작업 8: 주민의 꿈터 대표 인물. 첫 마을 떡밥부터 개장 후 어려움·변화까지 전체 이야기 확인.
- [ ] 작업 9: 손님집과 새로운 주민 대표 인물. 저장된 추첨·재방문·입주 선택·선물 중복 방지·도감 확인.
- [ ] 작업 10: 공동 마당과 기억 정원. 실제 참석자/완료 사건만 기록, 옛 날짜 보존, 배치/회수 확인.
- [ ] 작업 11: 서고 전시 확장과 나머지 직업/주민 콘텐츠. 완성된 사례의 규칙으로 확장하고 빈 메뉴 제거.
- [ ] 작업 12: 전체 검증과 사용자 검토. 신약 진행 중/완필/기존 가족/자식 없음/모바일/사계절 저장 시나리오 확인.

첫 제작 분량은 작업 1–5의 ‘받은 땅과 작은 서고를 실제로 오가는 경험’까지로 제안한다.
전체 완성 목표는 작업 12까지이며, 첫 제작 분량을 전체 완료로 표현하지 않는다.

## 17. 구현 전에 결정할 항목

### 추가 사용자 결정: 구약 가이드의 신학 기준은 고신

사용자 지정: 대한예수교장로회(고신)의 개혁주의 신학을 기준으로 구약 읽기 안내를 작성한다.
추가 사용자 결정: 교단명·신앙고백서명·외부 참고 자료 목록을 필사 화면이나 설정/소개에 별도 표시하지 않는다. 내부 제작 문서에 근거와 검토 이력을 보관하고, 성경 본문·출처와 게임 해설은 구분한다. 해석이 나뉘는 내용을 모든 교회의 공통 견해로 단정하지 않는다.
성경을 최종 기준으로 삼고, 고신이 사용하는 웨스트민스터 신앙고백서와 대·소요리문답을 교리적 검토 기준으로 사용한다. 적용할 판본과 최신 교단 문서는 콘텐츠 제작 전에 확인한다.

가이드 작성 원칙:
- 역사·문법·문학적 문맥과 당시 독자에게 주어진 의미를 먼저 설명한다.
- 하나님 말씀, 서술, 등장인물의 주장을 구분한다. 기록된 행동을 곧바로 승인된 행동으로 안내하지 않는다.
- 하나님의 언약과 구속의 흐름에서 본문을 읽고, 신약과 그리스도와의 연결은 성경적 근거를 제시한다. 근거 없는 숫자/사물의 알레고리 해석은 피한다.
- 구약의 하나님과 신약의 하나님을 서로 다른 성품의 하나님으로 대비하지 않는다. 사랑·거룩·공의·긍휼을 함께 고려한다.
- 율법의 적용은 도덕법·의식법·시민법의 구분과 그리스도 안에서의 성취를 고려한다. 고대 이스라엘에 주어진 명령을 현대 개인에게 그대로 이행하라고 요구하지 않는다.
- 질문과 탄식을 허용하고, 고난을 특정 개인의 죄나 믿음 부족으로 단정하지 않는다.
- 전쟁·심판·노예제·성폭력 등 어려운 본문은 별도 문맥 안내와 검토를 거친다. 모든 단락을 긍정적인 성품 키워드 하나로 요약하지 않는다.

화면 순서: 필사 전 문맥 안내 → 필사 본문 → 본문에서 확인되는 사실 → 하나님의 성품/일하심과 근거 → 신약 연결(근거가 있을 때) → 개인 질문·메모.
안내와 메모는 선택적으로 열람한다. 읽거나 답해야 필사할 수 있게 만들지 않는다.

편집·검토:
- 각 해설에 본문 범위·근거 구절·교리 근거·참고 자료·검토 상태를 기록한다.
- AI 초안은 검토 완료 해설과 구분한다. 고신의 공식 설명이나 승인을 받은 자료라고 표시하지 않는다.
- 교리와 어려운 본문 해설은 고신 목회자 또는 관련 전공자의 검토를 거친 뒤 공개하는 것을 출시 기준으로 제안한다. 실제 검토자는 아직 지정되지 않았다.
- 교단 안에서도 해석이 나뉘는 세부 사항은 하나의 견해를 교단 전체의 확정 입장으로 표현하지 않는다.

참고: 고려신학대학원 유해무 교수 『헌법 해설』 소개 — https://www.kts.ac.kr/home/research/124?page=3
이 자료는 웨스트민스터 신앙고백서와 대·소교리문답의 해설 취지를 확인하는 참고이며, 개별 구절의 해설 검토를 대신하지 않는다.

1. 구약의 정경·번역·책 순서와 본문 사용 범위.
2. 두 번째 마을의 이름·지형·전체 크기·건축 가능한 구역.
3. 선택 건물의 비용·재료·건설 대기·취소/철거 환불.
4. 처음 구현할 자식 직업과 주민의 꿈 대표 인물.
5. 새 방문자 수·입주 정원·재방문 방식·고유 선물의 대체 획득 경로.
6. 왕래에 게임 시간이 흐르는지, 활동 중 이동을 어떻게 처리할지.

이 항목들은 문서 작성 단계에서 임의로 확정하지 않는다. 구현에 앞서 실제 화면과 데이터 범위를 제시해 결정한다.

## 18. 출시 확인
