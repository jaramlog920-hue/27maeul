# 스물일곱 권의 마을 — 설계 문서

- 작성일: 2026-09-29
- 상태: 설계 승인됨, 구현 계획 전
- 프로젝트 경로: `cloooo/twenty-seven`
- 바탕: `cloooo/gospel-days`(기록자의 나날) 엔진과 정확성 파이프라인을 폴더째 복사해서 시작한다.
- 콘텐츠 최상위 기준: `docs/exclusion-list.md` (기록자의 나날 제외 목록을 상속)

## 0. 목적과 범위

**목적**: 네 복음서를 한 장씩 엮고 서고에 꽂으면서, 복음서들 사이에서 같은 이야기와 다른 이야기를 **스스로 가려낼 수 있게** 돕는다. 방법은 스타듀밸리 + 심즈 + 기록자의 나날을 섞은 **도트 생활 시뮬레이션**이다. 플레이어는 낡은 마을 서고를 맡은 필사가로 살면서 돈을 벌고, 이웃과 가까워지고, 집을 꾸민다.

**재미의 뼈대** (재미 기준: 기록자의 나날·증언대)
- 무엇을 판단하는가: 서고에 책을 꽂을 때 나오는 퀴즈. 특히 서고에 책이 늘수록 "이 구절은 어느 복음서?"를 낱말 차이로 가려내야 한다.
- 틀리면 어떻게 되는가: 책은 꽂히지만 책등이 맨 책이나 은박에 머문다. 틀린 구절은 매일 읽기로 돌아오고, 재료를 들여 다시 도전할 수 있다.
- 무엇이 자라는가: 서고 선반(맨 책 → 은박 → 금박), 마을(새 가게·이웃·장소), 직업 단계, 도구, 집.

**첫 버전 범위**
- 네 복음서 전체 (마 28장 · 막 16장 · 눅 24장 · 요 21장 = 89장)
- 서고의 **복음서 방** 하나. 다른 방은 잠긴 문으로만 보인다.
- 생활: 닢(돈), 필사 의뢰, 공방, 장날, 텃밭, 필요 4종, 이웃 최대 13명, 집 꾸미기·넓히기
- 웹앱(모바일 세로 우선), 서버 없음

**범위 밖 (다음 업데이트)** — §8에 정리
- 연애·결혼(후보 8명: 남 4, 여 4), 아이
- 사도행전 방, 바울 서신 방, 공동 서신 방, 요한계시록 방

## 1. 확정된 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 시대 | **옛 느낌의 마을**(돌집·올리브·포도원·양 떼·고깃배), 연도·나라·지명은 밝히지 않음 | "그 시절을 사는 느낌"(사용자 요청). 단, "그 시대에 누가 27권을 모았다"는 정경 형성 역사를 주장하지 않는다(학자 논쟁 영역) — 첫 안내와 서고 입구에 밝힌다 |
| 주인공 | 가상 인물. 여자/남자 선택, 이름은 플레이어가 지음(금지어 검사) | 연애·결혼·말하는 주인공을 위해. 실존 인물 창작을 피한다 |
| 주인공의 표현 | 말하고 감정을 드러낸다. 단, 성경 이야기에 대한 감정 반응·해석은 없다 | 플레이어의 감상을 대신 정하지 않는다 |
| 조각 | 이웃이 **책 이름을 붙여** 건넨다. "지금 엮는 책"의 조각만 온다 | 매일 루프는 편하게, 판단은 서고에서 모아서 |
| 엮기 | 집 책상에서 한 장씩 차례대로(기록자의 나날 방식). 장을 마치면 내 책장에 한 칸 | 검증된 엔진 재사용 |
| 판단 | 한 권을 다 엮으면 서고에 꽂는다. 이때 퀴즈 5문제. 출제 범위는 **서고에 이미 있는 책 + 지금 꽂는 책** | 서고가 찰수록 문제가 저절로 어려워진다 |
| 틀렸을 때 | 책은 언제나 꽂힌다. 맞힌 수로 책등 등급. 재도전에는 재료가 든다 | 진행은 막지 않고, 더 잘하려면 일해야 한다 |
| 돈 | 화폐 "닢". 엮은 말씀 책은 팔지 않는다 | 말씀을 상품처럼 다루지 않는다 |
| 이웃 | 역할 이름만, 최대 13명 | 기록자의 나날 §2-2 상속. 연애 업데이트 때 이름 규칙을 따로 정한다 |
| 구현 | gospel-days를 폴더째 복사, 새 git·새 Vercel 프로젝트 | 이미 배포한 게임과 서로 영향을 주지 않는다 |

## 2. 플레이 경험

### 2.1 무대
- 이름 없는 작은 도트 마을. 겉모습은 옛 느낌이다(돌집, 평평한 지붕, 올리브 나무, 포도원, 양 떼, 호숫가 고깃배). 기록자의 나날의 도트를 최대한 가져다 쓴다.
- 첫 안내 화면: "이 마을과 이웃은 게임을 위해 만든 것입니다. 성경 본문은 항상 출처와 함께 따로 보여 드립니다."
- **장소**: 주인공의 집(작업실, 문 앞 편지 바구니), 마을 서고, 장터, 쉼터 주막, 제본 골목, 텃밭, 벤치 있는 언덕, 호숫가 나루, 우물가, 포도원, 양 우리, 벌통 있는 들
- 처음에는 일부만 열려 있고, 서고에 책이 꽂힐 때마다 장소가 하나씩 열린다(§2.7).

### 2.1.1 지도와 배치
- **한 장짜리 지도를 약 48×40칸으로 넓힌다**(기록자의 나날 32×28의 두 배쯤). 화면에 보이는 칸은 16×20 그대로, 카메라가 따라간다.
- 아직 안 열린 곳은 덤불·울타리로 막혀 있다가, 서고 권수에 맞춰 치워지며 길이 열린다.
- **마을 서고**는 지도에는 바깥 모습만 있고, 문을 누르면 **서고 안 화면**으로 들어간다. 서고 안: 복음서 방(네 칸 선반, 책등 등급이 보임)과 잠긴 문 네 개(사도행전·바울 서신·공동 서신·요한계시록).
- 주인공 집 옆에 **집 넓히기용 빈 땅**을 남긴다.
- 대략의 배치 (구현 때 칸 단위로 다듬는다):

```
 ┌──────────── 언덕·벤치 ─────────┬── 포도원(1권) ──┐
 │  주인공 집 [빈 땅]    우물          │                 │
 │  제본 골목  ─── 큰길 ──── 마을 서고 ─┼── 벌통 들(3권) ─┤
 │  빵집  주막    장터(1권 확장)        │                 │
 │  텃밭      양 우리        베 짜는 집 │  호숫가 나루(2권)│
 └───────── 대장간(4권) ──────────────┴──── 호수 ~~~~ ─┘
```

- 지도가 넓어져 걷는 시간이 늘어나므로, 시험판에서 집–서고–장터 사이 걸음 수를 재서 너무 멀면 배치를 당긴다.
- **날씨**: 맑음, 비, 바람, 안개, 뜨거운 한낮 (기록자의 나날과 같음)
- **장날**: 이레마다. 떠돌이 상인이 귀한 재료와 가구를 가져오고, 주인공은 공방 제품을 판다.
- **계절 행사**: 마을 잔치로만 둔다. 성경 절기 이름은 쓰지 않는다.
- 날짜와 계절은 흐르지만 **시간 제한은 없다.**

### 2.2 주인공
- 시작할 때 여자/남자 모습과 이름을 고른다. 서고를 맡게 된 **견습 필사가**다.
- 말하고, 반가워하고, 피곤해한다. 이웃과 생활 대화를 나눈다.
- 성경 조각을 받거나 읽을 때는 조용히 읽고 받아 적는 모습만 보인다. 감동, 눈물, 해석 대사는 없다(§exclusion 1-2).
- 기록자의 나날의 "살아 숨 쉬는" 몸짓(숨쉬기, 깜빡임, 자율 행동, 날씨 반응, 습관, 흔적, 발소리)은 그대로 가져온다.
- 동반 동물: 고양이 또는 강아지(기록자의 나날과 같음).

### 2.3 하루의 흐름

| 때 | 할 일 |
|---|---|
| 아침 | 문 앞 편지 바구니 확인(필사 의뢰), 동물 밥, 날씨 보기 |
| 낮 | 이웃에게 조각 받기, 필사 의뢰·공방 일, 텃밭, 장날 |
| 틈틈이 | 벤치에서 모은 조각 읽기 → 피로 회복 (두 시간에 한 번, 기록자의 나날과 같음) |
| 저녁 | 집 책상에서 재료 + 조각으로 한 장씩 엮기 |
| 자기 전 | 성경 읽기 → 다음 날 **'평안'** (피로 한도 +20, 하루 동안) |
| 밤 | 일지 한 줄 자동 기록 (게임 속 사실만) |

- **자기 전 읽기**에 나오는 조각 순서: ① "다시 읽을 구절"(서고 퀴즈에서 틀린 것) ② 오늘 받은 조각 ③ 내 책장에서 고른 조각.
- 읽기 자체는 선택이다. 안 읽어도 불이익은 없고, '평안'이 붙지 않을 뿐이다.

### 2.4 책 한 권의 흐름

1. **책 고르기**: 책상에서 "지금 엮을 책"을 네 복음서 중 고른다. 언제든 바꿀 수 있고, 책마다 진행이 따로 저장된다.
2. **조각 받기**: 이웃이 지금 엮는 책의 조각을 책 이름과 함께 건넨다. 장 단위로 풀린다(기록자의 나날 조각 배분 방식).
3. **엮기**: 책상에서 조각을 차례대로 잇는다. 순서가 틀리면 "다시 살펴보자" 안내만 나온다. 잉크·종이·등잔 기름이 필요하다.
4. **장 기록 퀴즈와 내 책장**: 한 장을 다 이으면 기록자의 나날처럼 **기록 퀴즈 다섯 문제**(그 장 안에서 출제)를 푼다. 틀려도 벌은 없고, 재료는 다 맞혔을 때 쓴다(기록자의 나날과 같음). 기록을 마치면 내 책장에 그 책의 칸 하나가 채워진다. 장 퀴즈는 "그 장을 익히기", 서고 퀴즈는 "여러 권을 가려내기"로 역할이 다르다.
5. **서고에 꽂기**: 한 권을 다 채우면 들고 서고로 간다. 퀴즈 5문제(§3.5)를 푼다.
6. **책등 등급**: 맞힌 수 0~2 → 맨 책, 3~4 → 은박, 5 → 금박.
7. **다시 읽을 구절**: 틀린 문제의 구절이 목록에 들어간다. 자기 전 읽기와 벤치 읽기에서 먼저 나온다. 한 번 읽으면 목록에서 빠진다.
8. **재도전**: 서고에서 꽂힌 책을 골라 다시 푼다. **금박 재료 1 + 등잔 기름 1**이 든다. 등급은 더 높은 쪽만 남는다(내려가지 않음).
9. **복음서 방 완성**: 네 권이 모두 꽂히면 마을 잔치가 열리고, 주인공은 서고지기가 된다. 사도행전 방의 문이 살짝 열리는 장면으로 첫 버전이 끝난다. 게임은 이후에도 계속된다(금박 모으기, 생활).

### 2.5 돈과 일

**화폐 "닢"** — 게임에서 지은 이름. 성경의 돈 이름은 금지어다.

| 버는 법 | 내용 | 미니 활동 |
|---|---|---|
| 필사 의뢰 | 편지 나르는 이웃이 아침에 바구니에 넣어 둔다. 편지 대필, 가게 문패·나무판 글씨, 장부 정리. 의뢰 글은 모두 게임 창작 문장 | 도트 글자 따라 긋기. 반듯할수록 수고비 +최대 50% |
| 공방 제품 | 잉크, 종이, 제본 표지를 만들어 장날에 판다 | 잉크 개기, 종이 뜨기, 표지 누르기 |
| 텃밭·채집 | 무화과, 포도, 허브, 꿀 | 심기, 물 주기, 거두기 |

**돈 쓰는 곳**: 엮기 재료(잉크·종이·등잔 기름), 금박 재료, 도구 성장(갈대 펜 → 좋은 펜, 작은 등잔 → 밝은 등잔, 좁은 책상 → 넓은 책상), 가구, 집 넓히기(작업실 → 방 하나 더), 씨앗, 동물 간식.

**직업 단계**

| 단계 | 오르는 조건 | 열리는 것 |
|---|---|---|
| 견습 필사가 | 시작 | 편지 대필 |
| 마을 필사가 | 의뢰 10건 + 서고에 1권 | 문패·나무판 의뢰, 공방 |
| 제본 장인 | 의뢰 30건 + 서고에 2권 | 표지 만들기, 비싼 의뢰 |
| 서고지기 | 복음서 방 완성(4권) | 서고 열쇠, 다음 방 예고 |

수치(단가, 재료값, 도구값)는 구현 계획에서 정하고, 시험판을 플레이하면서 맞춘다.

### 2.6 필요 수치 (배고픔 · 피로 · 기분 · 추위/더위)
> 2026-09-29 사용자 결정: 외로움은 뺀다. 계절 칸 하나를 두고, 겨울엔 **추위**, 여름엔 **더위**로 부른다. 봄·가을엔 이 칸을 숨긴다.
- **배고픔**: 밥으로 채운다.
- **피로**: 잠, 벤치 읽기로 풀린다. '평안'인 날은 피로가 천천히 쌓인다(하루 동안 약 20% 덜 — 한도 +20과 같은 효과).
- **추위**(겨울): 화덕 곁, 담요, 집 안에서 풀린다(기록자의 나날과 같음).
- **더위**(여름 한낮, 바깥): 집 안에 들어가거나 물을 마시면 풀린다. 뜨거운 날씨엔 더 빨리 오른다.
- **기분**: 따로 쌓지 않고 그때그때 계산한다. 좋은 날씨·꾸민 방·좋은 도구로 오르고, 배고픔·피로·추위/더위가 높으면 내려간다. 기분이 좋으면(70 이상) 엮기와 편지 대필에 드는 시간이 줄어든다.
- 무리하면 앓아눕고, 이웃이 수프를 들고 찾아온다(기록자의 나날과 같음).

### 2.7 이웃과 마을 성장
- **역할 이름만** 쓴다. 최대 13명. 처음 7명으로 시작하고, 서고에 책이 꽂힐 때마다 새 이웃이 이사 온다.

> 2026-09-29 사용자 결정(구현 기준): 이미 만든 이웃 9명(빵 굽는 이웃·물 긷는 아이·포도원 할아버지·떠돌이 상인·대장장이·양치기·기름 짜는 이웃, 마음으로 이사 오는 베 짜는 이웃·벌 치는 이웃)은 그대로 두고, **편지 나르는 이웃(처음부터)·주막 주인(서고 1권)·어부(2권)·제본 골목의 목수(3권)** 넷을 더해 13명으로 한다. 아래 표는 처음 설계안이다.

| 때 | 이웃 |
|---|---|
| 처음 (7) | 물 긷는 아이, 빵 굽는 이웃, 편지 나르는 이웃, 주막 주인, 제본 골목의 목수, 양치기, 떠돌이 상인(장날에만) |
| 서고 1권 (+2) | 베 짜는 이웃, 포도원 주인 · 장터 확장, 포도원 열림 |
| 서고 2권 (+2) | 어부, 약초 캐는 이웃 · 호숫가 나루 열림 |
| 서고 3권 (+1) | 벌 치는 이웃 · 언덕 벤치길과 벌통 들 열림 |
| 서고 4권 (+1) | 대장장이 · 복음서 방 완성 잔치 |

- 역할 목록은 구현 때 바뀔 수 있다. 성경 직함(제사장·세리 등)은 쓰지 않는다. 양치기·포도원 주인·어부 같은 생활 직업은 쓰되, 이벤트는 생활의 일로만 둔다(exclusion 2-3).
- 하트 0~100. 인사, 선물, 부탁으로 스무 날쯤 걸려 쌓인다. 기록자의 나날의 마음 이벤트 A~E(부탁 · 아침 방문·저녁 초대 · 마을 성장 · 이웃끼리 모임 · 마음 9 선물과 앨범)를 가져온다.
- 조각을 건넬 때는 "이야기 하나 전해 드릴게요"처럼 말한다. 목격자처럼 말하지 않는다.
- 이웃 데이터에 `romanceable: false` 자리를 둔다(다음 업데이트용). 첫 버전에서는 쓰지 않는다.

### 2.8 모으는 재미
- **서고 선반**(핵심): 네 권의 책등. 맨 책 · 은박 · 금박.
- **조각 도감**: 네 복음서 조각을 구절 범위, 제목, 도장과 함께 모은다. 책별 보기, "○○에만" 보기.
- **선물 도감, 요리법, 풍경 앨범**: 기록자의 나날과 같다.
- **나의 한 줄**: 한 권을 꽂은 뒤 선택적으로 적는다. 플레이어 본인의 말로 저장된다.

### 2.9 소리
기록자의 나날과 같다. Web Audio 합성, 첫 탭 전엔 소리 없음, 음소거 버튼.

## 3. 콘텐츠와 정확성

### 3.1 원칙
최상위 기준은 `docs/exclusion-list.md`. 이전 게임들의 5원칙(개역한글 그대로 인용, 본문이 말하지 않는 것은 단정하지 않기, 교파 해석 금지, 동명이인 구분, 정답이 둘 되는 보기 금지)과 기록자의 나날 §2~§4를 상속한다. 이 게임에서 새로 생기거나 바뀌는 것은 exclusion-list에 적는다.

### 3.2 본문 데이터
- `nt-krv.json`, `ref.ts` 등 본문 파이프라인은 gospel-days에서 그대로 가져온다.
- 게임에 나오는 성경 문장은 전부 이 파일에서 뽑는다. 기억으로 쓴 인용은 금지한다.

### 3.3 조각 (`pieces.json`)
```ts
type Book = 'mt' | 'mk' | 'lk' | 'jn'
type Stamp =
  | { kind: 'same'; book: Book; ref: string }    // 같은 이야기
  | { kind: 'similar'; book: Book; ref: string } // 비슷한 이야기
interface Piece {
  id: string;       // 'mt-005-001'
  book: Book;
  ref: string;      // '마 5:1-12'
  chapter: number;  // 시작하는 장
  title: string;    // 낱말은 모두 본문에 있는 말
  stamps: Stamp[];  // 자기 책은 가리키지 않는다. 비어 있으면 '네 복음서 중 ○○에만'
}
```
- 각 책을 1장 1절부터 끝 절까지 빠짐없이, 겹치지 않게 덮는다.
- **누가 조각**: gospel-days의 156개를 그대로 가져온다(이미 검수됨). `book: 'lk'`만 더한다.
- **마태·마가·요한 조각**: 새로 만든다. 만드는 순서는 마가 → 마태 → 요한.
- 제목은 본문의 말로. 해석 라벨 금지(gospel-days §3-3).

### 3.4 도장 (네 방향)
- 분류 기준은 gospel-days §4와 같다. 같은 이야기는 때·곳·인물과 말씀이 분명히 겹칠 때만. 애매하면 비슷한 이야기.
- **양방향 일치**: A 조각이 B 책의 구절을 `same`으로 가리키면, 그 구절을 담은 B 조각도 A 책을 `same`으로 가리켜야 한다. `similar`도 같다. 검증 스크립트가 강제한다.
- 누가 조각의 기존 도장이 기준점이 된다. 새 책을 만들다가 누가 쪽 도장을 고쳐야 하면, 고친 이유를 `content-audit.md`에 적고 사용자 검수를 받는다.
- 도장 안내: "도장은 오늘 우리가 보는 신약성경의 네 복음서를 서로 견주어 붙인 표시입니다." 도장이 없으면 "네 복음서 중 ○○복음에만 있는 이야기".

### 3.5 서고 퀴즈 (`quiz.ts` 확장)
- 다섯 문제. **출제 범위 = 서고에 이미 꽂힌 책 + 지금 꽂는 책**. 재도전일 때는 서고에 있는 모든 책.

| 종류 | 조건 |
|---|---|
| 말씀 조각 맞추기 | 지금 꽂는 책에서 |
| 빈칸 | 지금 꽂는 책에서. 다른 보기로 채운 문장은 출제 범위 어디에도 없어야 한다 |
| 먼저 나오는 이야기 | 지금 꽂는 책에서 |
| **어느 책?** | 출제 범위에 책이 둘 이상일 때. 보기는 출제 범위의 책들 |
| 복음서 탐정 | "같은 이야기" 도장이 있는 조각만. 출제 범위에 도장 상대 책이 있을 때 |

- 첫 권을 꽂을 때는 "어느 책?"과 탐정 문제가 없으므로 앞의 세 종류로 다섯 문제를 채운다.
- **정답 유일 규칙**: 문제에 쓰는 문장은 출제 범위의 모든 책에서 **글자 그대로 한 곳에만** 있어야 한다. 마태·마가처럼 글자까지 같은 절은 "어느 책?"에서 뺀다. 테스트가 네 권의 모든 조합(15가지)을 검사한다.
- 틀려도 벌점은 없다. 틀린 문제의 구절은 "다시 읽을 구절"에 들어간다.

### 3.6 지어낸 문장 (`life-text.json`)
- 이웃 대화, 이웃 이야기, 필사 의뢰 글, 문패 글씨, 일지 틀, 행사, 요리법, UI 문구를 한 파일에 모은다.
- 금지어 검사 대상: `life-text.json`, `items.json`, `places.json`, 이웃 데이터, 주인공과 동물 이름 기본값, 플레이어가 입력한 이름(입력 때 검사).
- 필사 의뢰와 문패에 성경 문장을 쓰지 않는다.
- 주인공 대사는 허용한다(gospel-days의 `speaker: 'writer'` 금지 규칙은 이 게임에 없다). 대신 주인공 대사에 성경 인용·해석이 없는지 금지어와 검수로 본다.

## 5. 테스트와 배포

### 5.1 검증 스크립트 (`npm run verify`, `prebuild`)
1. 네 권 각각을 조각이 빠짐없이, 겹침 없이 덮는다.
2. 제목 낱말이 해당 본문에 있다.
3. 도장 참조 구절이 실제로 있고, 자기 책을 가리키지 않는다.
4. **도장 양방향 일치**.
5. 금지어(§exclusion 2)가 생활 문구, 이웃, 아이템, 장소, 이름 기본값에 없다.
6. 각 규칙마다 `scripts/fixtures/`에 역방향 픽스처를 두고 실제로 걸리는지 테스트한다.

### 5.2 단위 테스트 (Vitest)
gospel-days 테스트를 유지하면서 더한다: 닢 거래, 의뢰와 직업 단계, 서고 꽂기·등급·재도전(등급이 내려가지 않음, 재료 부족 시 불가), 다시 읽을 구절 목록, 여러 권 퀴즈(15가지 조합 전부 정답 유일, 첫 권은 "어느 책?" 없음), 필요 4종과 '평안', 텃밭, 이웃 이사, 책 바꾸기와 책별 진행 저장, 저장·불러오기.

### 5.3 화면 확인
브라우저 미리보기를 모바일 크기로 띄워 하루 루프와 서고 꽂기를 실제로 플레이하고 스크린샷으로 공유한다.

### 5.4 배포
새 Vercel 프로젝트 `twenty-seven`. 배포 전에 사용자에게 확인한다. 배포 뒤 말씀놀이터에 카드를 추가하는 것도 사용자 승인 뒤에 한다.

## 6. 만드는 순서 (계획 단계에서 세분화)
1. **복사와 뼈대**: gospel-days 복사, 이름 바꾸기, 주인공 고르기, 닢, 필사 의뢰 하나
2. **시험판**: 누가 한 권 → 서고 꽂기 → 퀴즈 → 책등. 마가는 앞 몇 장만 넣어 "어느 책?" 문제가 나오는지 확인한다. **사용자에게 먼저 보여 주고 재미를 확인한다.**
3. **생활 채우기**: 공방, 장날, 텃밭, 필요 4종, 이웃 13명과 이사, 직업 단계, 집 넓히기
4. **콘텐츠**: 마가 → 마태 → 요한 조각과 도장, `content-audit.md`, 권마다 사용자 검수
5. **완성과 다듬기**: 복음서 방 완성 잔치, 사도행전 예고, 도감·앨범, PWA, 성능, 배포

## 7. 수치 (시험판에서 맞출 첫값)
- 책등 등급: 0~2 맨 책 · 3~4 은박 · 5 금박
- 재도전 비용: 금박 재료 1 + 등잔 기름 1
- '평안': 피로 한도 +20, 다음 날 하루
- 외로움: 사흘 동안 대화가 없으면 가득
- 이웃: 처음 7명, 최대 13명
- 나머지(닢 단가, 재료값, 도구값, 배고픔 속도)는 gospel-days 값에서 출발해 시험판에서 정한다.

## 7-1. 2026-09-29 사용자 결정 (계획 3~6)

- **계획 3 — 콘텐츠**: 마가 나머지·마태·요한. 서브에이전트로 진행. `(없음)` 절은 어디에도 보이지 않게, 대괄호 구절은 본문 그대로 보이되 퀴즈로 묻지 않는다. 권마다 검수 요약은 기록만 하고 계속 진행(사용자가 돌아오면 한꺼번에 보여 준다).
- **계획 4 — 완성과 다듬기**: 작은 정리 → 새 이웃 넷 행사 참여 → 복음서 방 완성 잔치와 사도행전 방 예고 → 도감·나의 한 줄 → 집 넓히기(**2단계**: 방 하나 더 → 다락 서재)와 넓은 책상 → PWA·오프라인·성능 → 배포(올리기 전 확인).
- **잔치 뒤**: 결말로 끝내지 않고 **계속 산다**(잔치 장면 + 사도행전 방 예고).
- **계획 5 — 사도행전 방**: 복음서처럼 **조각을 받아 엮고 서고에 꽂는 흐름 + 여정 잇기**. 여정 잇기는 **본문에 나오는 곳 이름 카드를 본문 순서대로** 잇는 놀이(실제 지도 위치는 그리지 않는다 — 지리 정확성 논쟁을 피한다). 카드마다 그 곳이 나오는 구절을 보여 준다. 다 채우면 나루터에 배가 온다. 도장은 없다.
- **계획 6 — 연애·결혼**: 후보 8명(남 4, 여 4)에게 **영어 개인 이름**. 성경 인물 이름은 영어 형태까지 금지(John, Mary, Peter, Sarah, Daniel, Chloe, Phoebe, Lydia, Julia, Priscilla, Susanna, Joanna, Martha, Rhoda, Tabitha, Claudia 등 — 계획 6에서 목록을 만들고 금지어 검사에 더한다). 연애 대화에 성경 구절 금지, 결혼식은 마을 잔치.
