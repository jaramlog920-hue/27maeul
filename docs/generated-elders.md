# 생성 주민의 노년 연결

2026-10-07 사용자 요청: 랜덤으로 태어난 주민도 노년까지 자라야 한다.

- 성장 단계: 출생 → 14일 어린이 → 42일 청소년 → 84일 성인 → 244일 노년.
- 결정: 노년은 성인 이후 네 계절(160일)로 기본 연결했다. 기준은 `gen-config.ts`의 `STAGE_AT.elder` 하나로 조정한다. 고정 주민의 나이를 임의로 새로 계산하지 않는다.
- 아침 정산 `settleGrowth`에서 born 주민의 나이로 노년으로 전환한다. 노년이 되면 다시 젊어지지 않고, 소식 `grew:elder`는 한 번만 기록한다.
- 생성 주민의 이름·성별 모습·피부색·머리 모양·옷·부모·태어난 날을 유지한다. `genAvatar`와 공통 노년 도트 함수를 쓰므로 가능한 생성 외형 전체에 적용된다.
- 부모가 이사 간 뒤 일터를 이어받은 주민에게도 자신의 노년 표시를 전달한다. 지도·가구 모션·수첩 초상에 동일 적용한다.
- 부모 곁의 생성 가족에게 노년 표시를 전달한다. 일터를 물려받지 않은 형제도 성인·노년 단계에서 화면에서 빠지지 않게 한다.
- 기존 은퇴·이사·선물·사망 규칙은 변경하지 않았다.
- 저장 형식은 기존 elder 단계와 호환된다. 저장 복원·단계 경계·아침 정산·한 번만 소식·형제 표시·외형 불변·방향별 도트를 테스트했다.
- 관련 테스트 4파일 36개 통과, `npx tsc -b` 통과, `npm run build`의 콘텐츠 검증·TypeScript·Vite·PWA 생성 통과. 기존 콘텐츠 경고와 큰 번들 경고가 남는다.
- 자산: `assets/generated-elders/preview.html`(생성 외형 12가지 대표 예시), PNG 156장, manifest·before-after.png. 원본 함수는 실제 저장된 생성 주민의 외형으로 런타임에 그린다. 재생성: `node scripts/export-generated-elders.mjs`.
- 커밋·배포는 수행하지 않았다.
