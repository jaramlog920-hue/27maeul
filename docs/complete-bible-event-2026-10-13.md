# 두 서고 사이에 선 날

사용자가 고른 5번(신약 27권 + 구약 39권) 하나만 구현했다. 다른 구약 묶음 완성 이벤트는 추가하지 않았다.

구약은 별도 책 꽂기 동작 없이 완필한 책이 자동 전시되는 기존 구조를 따른다. 신약 27권이 모두 꽂혀 있고 구약 39권의 모든 실제 장이 끝난 상태로 처음 바뀔 때 `completeBible`를 예약한다. 보통 마지막 구약 책의 마지막 절을 쓰는 순간이다. 반대 순서의 저장도 마지막 신약 책 꽂기에서 잡는다. 이미 완성한 옛 저장·반복 입력·책등 재도전은 재예약하지 않는다. 조건 판정은 로딩한 본문 범위나 장 배열 길이에 의존하지 않는다.

하나의 전체 화면 이벤트:
- 0~4초: 작은 책상과 빈 종이 한 장.
- 4~9초: 신약 27권의 서고. 실제 은박·금박 등급.
- 9~15초: 구약 39권의 서고. 기존 전시의 파스텔 배색·띠·줄·점·마름모를 따른 13권×3단.
- 15~21초: 두 서고로 이어지는 길에 등불이 하나둘 켜지고 사람들이 모임.
- 21초 이후: 두 서고 앞의 기념사진. 실제 마을에 온 가까운 이웃과 현재 배우자·아이를 반영하고, 아기는 기존 요람 그림을 사용.

두 서고는 같은 크기·벽·문·창문·지붕 형태를 공유한다. 신약 지붕은 기존 녹색, 구약 지붕만 청회색이다. 두 지역을 한 화면에 담는 기념 구도이며 게임 지도를 바꾸지 않는다. 마지막 사진은 23초 구도를 별도 그려 앨범에 남기므로 바로 넘겨도 책상 사진으로 남지 않는다. 사진 재감상 때 원래 사진을 보존한다. 다시 보기/모션 줄이기를 지원하고 닫으면 계속 플레이한다. 추가 해금·돈·시간·호감도 보상은 없다.

검증: 실제 구약 마지막 절, 신약/구약 누락, 다른 완성 순서, 중복 방지, 저장, 즉시 넘기기의 앨범 사진과 기존 구약 필사·신약 완성·제본·잔치·저장 회귀 등 141개 테스트 통과. 완필 진행을 갖춘 마지막 절 fixture 별도 4개 재확인. 콘텐츠 검사·TypeScript·제작 빌드 통과. 브라우저에서 다섯 컷과 실제 재생·다시 보기 확인.
