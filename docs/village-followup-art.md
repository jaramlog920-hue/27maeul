# 가족·만남·서고 방문객 도트 후속

2026-10-07. 사용자 요청 범위: 부모 집 요람, 만남 표정 5종, 서고 방문객 도트와 지도 연결.

## 구현

- `village-followup-art.ts`: 기존 homeCradle·generationRows 아기 원본을 겹쳐 요람을 합성. 낮은 눈 깜빡임, 밤(19–07시)은 잠든 눈. 저장된 피부색을 사용한다.
- `village-followup-scene.ts`: 부모 가구의 home에 해당하는 실제 방에서만 출생한 baby 단계 아이를 표시. 미래 출생·다른 가구·성장한 아이는 표시하지 않는다. 문·입구·주민 자리·붙박이·기존 장식 가구와 겹치지 않는 바닥을 고른다. 형제는 각각 별도 자리에 배치한다.
- 만남 표정: 하트·웃음·대화·머쓱·화남을 13×13 말풍선(내부 9×9)으로 통일. 게임은 공유 코드 원본을 칠하고 투명 PNG도 동일 원본에서 내보낸다. 런타임 파일 로딩 없이 자산과 게임 그림이 일치한다.
- 방문객 네 종류: 기존 아바타 시스템을 써서 서로 다른 머리·옷·피부·키를 사용한다. 기존 읽기·손일 모션으로 책 읽기·방명록 쓰기를 그린다.
- 방문객 출현: 오늘 날짜의 방명록에 기록이 있을 때만 09–17시. 09–10시 및 16–17시는 서고 앞, 10–16시는 안쪽 바닥. 입장 직후 30분은 쓰기, 이후 읽기. 서기는 14–15시에 한 번 더 쓴다. 게임 시간으로 자리가 전환된다.
- renderer는 깊이 순서 목록에 요람·손님을 추가한다. 저장·출생·관계·방명록 보상·경로 차단은 변경하지 않는다.

## 결정과 범위

- 결정: PNG를 매번 읽지 않고 공유 도트 원본을 쓴다 — 기존 게임의 캐시 방식에 맞추며 생성 자산과 그림이 달라지지 않게 한다.
- 결정: 방문객은 기존 기록을 보여 주는 그림으로 연결한다 — 새 NPC 생성·대화·소문·가르치기 보상을 중복시키지 않는다. 실제 문까지 걷는 경로·상호작용은 이번 범위에 포함하지 않는다.
- 결정: 요람은 기존 집의 빈 바닥에 그리며 통행을 막지 않는다 — 동선 변경은 이번 요청 범위 밖이다. home에 해당하는 실내 방이 없는 가구에는 임의의 다른 집을 배정하지 않는다.
- 부부 저녁·밤 동선, 구약 서고 방 확장, 연인 구절 선물은 남은 기능 후속이다.

## 자산과 검증

- `node scripts/export-village-followup.mjs`: 표정 PNG 5장, 요람 8장, 방문객 48장, manifest·정지 모음·움직이는 preview.html.
- 새 테스트: 부모 집·날짜·성장 단계·형제 배치·밤 수면·방문 시간 경계·팔레트·도트 크기·상태 불변성.
- `npx tsc -b` 통과, 후속 도트 테스트 4개 통과.
- `npm test -- --reporter=dot`: 186개 테스트 파일·2,412개 테스트 전체 통과(120.63초).
- `npm run build`: 콘텐츠 검증(prebuild)·TypeScript·Vite·PWA 생성 통과. 기존 조각 검증 경고 43개, 본문 없는 허용 구약 절 19곳, 큰 번들 경고가 남는다. 테스트에서는 jsdom의 Canvas 미구현 경고가 출력됐으나 실패는 없다.
- PNG 모음 시각 검수: 표정 5종, 요람 앞 난간과 아기, 방문객의 서로 다른 외형 확인.
