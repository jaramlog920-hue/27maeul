# 전체 화면 도트 장면 다섯 가지

1. 비 오는 밤 필사: 실제 비 오는 날 밤에 필사 장을 완료하면 하루 한 번 예약한다. 타이핑 중에는 끼어들지 않는다.
2. 한 권 완성: 기존 `bookBound` 장면을 전체 화면으로 그린다. 마지막 글자를 쓰는 모습에서 약 4초 뒤 책을 덮는 모습으로 바뀐다. 게임 시간을 새벽으로 강제 변경하지 않는다.
3. 연인 노을: `dateSunset`과 `date:sunset:0~2`에 연결한다. 주인공과 실제 상대의 외모를 같은 비율로 나란히 앉힌다.
4. 아기가 잠든 밤: 아기 요람 곁에서 밤에 이불 덮기를 실행하면 하루 한 번 예약한다. 기존 돌봄 호감도 외에 새 보상을 추가하지 않는다. 새 장면은 가족 일지에도 남는다.
5. 첫눈 마을: 기존 `firstSnow` 장면을 눈 덮인 지붕과 따뜻한 창문이 있는 전체 화면 그림으로 바꾼다.

주인공은 기존 10×14 화소 그림을 두 배로 그린다. 앉은 인물의 전체 높이도 28화소로 맞추고, 보이는 다리는 4화소와 신발 2화소로 구성한다. 뒷모습에서는 손이 등받이를 뚫고 나오지 않는다.

새 이야기의 완료·앨범·저장 경로는 기존 장면 시스템을 사용한다. 기존 필사 보상·데이트 횟수·해금 기준은 그대로다. 비 오는 밤과 아기 장면의 예약 표식 및 대기 장면은 저장 복원 검사로 확인했다.

미리보기: `assets/stargazing/preview.html?scene=rainCopy`. ‘다음 장면’으로 위 순서대로 이어진다. 모아보기는 `assets/stargazing/moments.html`. 미리보기는 실제 저장의 진행이나 앨범을 변경하지 않는다.

검증: 관련 9파일 180개 통과, 아기 검사 초기 상태의 타입을 보완한 뒤 관련 2파일 13개 재검사 통과. 실제 브라우저에서 다섯 장면을 순서대로 확인하고 `artifacts/scenery/01~05-*.jpg`에 캡처를 남겼다.

최종 전체 빌드와 콘텐츠 사전 검증도 통과했다. 로그는 `artifacts/scenery/build.log`에 있다.
