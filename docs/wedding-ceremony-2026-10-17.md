# 결혼잔치 구도 적용과 예복4종

최신 사용자 수정: 아래 최초 복장4종은 기본 옷 목록으로 옮겼고, 새 정장/드레스4종을 별도로 제작해 장날 구매·약혼자 선물·결혼식 착장 선택까지 연결했다. 최신 구현/검증/연애 조건은 wedding-attire-and-route.md를 따른다. 아래 비교용 자산만 준비했다는 설명은 그 이전 시점의 이력이다.

사용자가 루디 시안을 본 뒤 “그렇게적용해줘”라고 승인했고, 이어 결혼식 복장 도트를 남자2종/여자2종 요청했다.

## 적용

- 공통 drawDexterWedding 경로의13개 결혼잔치에 승인한 둥근 손님 배치를 적용했다. 실제 이사 온 손님을 빠뜨리지 않으며 키·노년·계절 외형을 유지한다. 가운데 꽃 아치와 부부 앞은 비우고, 손님은 시차를 두고 고개를 돌리거나 기존 짧은 팔 인사 도트를 쓴다.
- 모닥불은 왼쪽으로 옮기고 일반 잔칫상/루디 탁자는 앞쪽으로 옮겼다. 바질 약차와 메리골드 포도는 기존 옆 탁자의 받침을 유지한다. 양·편지·포도·약차·천·올리브 잔·잔치 차·꿀·생선·고리·빵·깃발과 배우자별 원래 단계/행동은 보존한다.
- 고정320×220 구도를 캔버스에 동일 비율로 맞춘다. 결혼잔치에만 wedding-ceremony 화면 클래스를 붙여 휴대폰에서도 캔버스가 끝없이 세로로 늘어나지 않게 했다. 다른 이벤트의 화면 비율은 유지한다.
- 게임·미리보기·썸네일이 기존 공통 렌더러를 사용하므로 새 구도가 함께 반영된다. 결혼 상태·발생 조건·원문·보상·옷장·저장 데이터를 변경하지 않았다.

## 복장 자산

`wedding-outfits.ts`의 남자 세이지 조끼/아이보리 겉옷, 여자 아이보리 리본/장밋빛 레이스4종이다. 원래 캐릭터의 얼굴·머리·피부·짧은 손과 발을 보존하고 기존 몸통/바지/긴 치마 도트 위의 옷만 바꾼다. 정면·오른쪽·뒷면·왼쪽과 서기/손 흔들기 원본 크기의 투명 PNG4장 및 비교 PNG를 내보냈다. 이4종은 사용자가 고르기 위한 자산이며 실제 저장된 옷차림을 자동 교체하거나 새 옷장 선택 기능까지 추가하지 않았다.

## 확인

13종의 전 원문 단계·0/0.9/2/8초·기본/실제 기록자 예시를 가로 동작 시트로 확인했다. 새320×220 휴대폰 캔버스 구도와 실제300×170 썸네일도 전 단계에서 확인했다. 39장과 복장 비교1장/투명 자산4장, 총44장 PNG를 직접 열어 확인했으며 해시는 wedding-ceremony-review/visual-review.json에 기록했다. 긴 동작 시트 일부는 도구 표시에서2048px로 축소되므로 모든 시트를 원본 픽셀 확대했다고 주장하지 않는다. 실제 브라우저 시각 검증은 기존 접근 게이트 때문에 수행하지 않았다.

관련3개 파일1,732개 검사 통과(wedding-ceremony-final-tests.log). 실제 배우자·입주 손님·대사·결혼 상태/저장/앨범 보존 및 미리보기 무변경, 예복4종의4방향/서기/인사에서 머리·손·발/입력 불변, 손님 위치와 중복/누락 검사를 포함한다. TypeScript와 전체 사전 검사/Vite/PWA 빌드 통과(wedding-ceremony-build.log). 기존 대형 청크 경고는 남는다. 이전676개/공유118개 제작 기록과 다른 작업 변경은 보존했다.
