## 7. 미확인 위험·제외한 후보·검사 한계

1. **다중 책 cold 로딩 원인 미확정:** loveVerse에 php/jn 조각을 함께 주면 map/filter와 Set 반복에서는 두 책이 나오지만, mocked NtContent props에는 php만 관측된다. 최소 하네스에서도 관측됐으나 소스·Vite 변환·프로덕션 번들은 정상 for-of다. 실제 브라우저의 고급 연애→다중 책 cold 로딩까지 검증하지 못해 제품 버그로 확정하지 않았다. 순수 moods 캐시의 로드 실패 후 회복은 확인했다. `ui/modal-observation.json`, `root/modal-books-results.json`, `ui/ModalLayer.transformed.js`로 이어서 조사한다. 추가 배열 prototype 계측은 테스트 관측을 교란해 증거에서 제외했다.
2. **의도된 넘침 정책과 손실:** 여행 보상과 자동 잉크 생산물이 가득 찬 가방·궤짝 없음 조건에서 버려지는 것은 확인했다. stash의 명시적 버림 정책 때문에 확정 버그로 세지 않았다. 알림·생산 중단·보상 보관 정책은 남은 제품 결정 사항이다. 귀환을 막으면 여행에 갇힐 수 있으므로 공간 없음만으로 귀환을 막는 수정을 권하지 않는다.
3. **실기기 미검증:** iOS/Android 한글 IME, 가상 키보드 visualViewport, 음성 권한·외부 인식 서비스, 백그라운드 오디오, 실제 캔버스 메모리, 터치 기기별 동작은 데스크톱/jsdom 검사로 보장하지 않는다. 새 낭독 모임은 인식 mock·실패 대체 UI 검사와 소스 검토이며 마이크 외부 전송은 실행하지 않았다.
4. **PWA/저장 장애 한계:** 실제 서비스워커 업데이트 경쟁, 완전 오프라인의 미방문 청크, 강제 종료, 실기기 quota 소진은 미실시다. 기존 IndexedDB 실패·원자성·이관·재시도·충돌 회귀를 실행했고 실제 두 탭 충돌 보호는 확인했다. 사이트 데이터 삭제/복구 시험은 하지 않았다.
5. **렌더 범위:** 249개 렌더 모듈의 많은 그림 데이터는 구조·등록 스모크 검사 중심이다. 모든 장면·선택·성별·나이·복장·날씨·화면 크기·연속 시간의 모든 픽셀을 시각 비교하지 않았다. `src/render/AGENTS.md`가 요구하는 그림 완료 판정을 하지 않는다. 마지막에 추가된 마당 기능도 실제 브라우저 픽셀 검증은 미완료다.
6. **상태 공간 한계:** 정상·비정상·경계와 저장 왕복을 검사했지만 모든 조작 순서·난수 씨앗·다세대 장기 상태를 전수 탐색하지 않았다. 기존 감사의 장기 시뮬레이션 결과는 이번 새 실행 숫자에 합치지 않았다. 일부 재현은 합성 중후반 상태를 직접 구성했다.
7. **의존성/보안 한계:** 로컬 package/lock/설정, 입력·저장·React 렌더·외부 요청 경로를 검토했다. 모든 외부 라이브러리 구현·최신 취약점 DB·실제 Vercel 설정을 검증하지 않았다. 의존성 목록을 외부 전송하는 npm audit나 운영 API·배포 시험은 실행하지 않았다. 인증·권한 서버가 없는 구조이므로 존재하지 않는 서버의 권한 시험을 통과로 표시하지 않는다.
8. **기각:** Settings 가져오기 중 '처음부터'는 확인창만 열고 실제 삭제는 busy·동일 latch로 막힌다(합성 모킹 erase0회). 기존 열쇠 구매, 일터 제목·선물, 제빵사 중복은 현행 재현에서 수정 확인했다. 의도 확인이 필요한 동작과 테스트 환경 실패를 제품 버그로 늘리지 않았다.
9. **동시 수정:** 감사 중 다른 작업의 소스 변경이 반복됐다. 시작/재개/마당 추가 후 기준점을 분리했다. 542파일 전체 실행이 종료 시점 작업트리 전체의 고정 스냅샷 검증이라고 주장하지 않는다. 마지막 변경은46개 관련 검사·40개 감사 재현·타입·Vite 빌드로 검증했다. 이후 변경은 별도 재검증이 필요하다.
