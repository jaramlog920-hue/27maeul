# 27마을 전체 밸런스 점검 — 2026-10-13

이 보고서는 변경 전 점검 기록이다. 이후 승인된 호감도 조정을 코드에 적용했으며, 현재 규칙과 최종 검증은 [호감도 변경 기록](../../heart-balance-2026-10-13.md)을 참고한다. 아래 호감도 수치는 점검 당시 기준으로 남긴다.

**판정: 편안한 필사 중심 게임으로서 기본 제한은 갖춰져 있지만, 해금 속도·경제·생활 성장의 연결은 조정이 필요하다.** 특히 책 선택에 따른 해금 격차, 이미 부자가 된 뒤에야 열리는 생활 기능, 새벽 시간 정지 뒤의 무시간 채집이 크다.

게임 수치는 변경하지 않았다. 현재 소스의 신약 27권 전체 본문으로 진행량과 수입을 계산하고, 시간·경제·성장·가족·제작·모임·시설 관련 기존 테스트 475개와 이번 시나리오 5개를 실행했다. 총 30파일·480개 통과. 테스트 통과는 ‘재미있는 밸런스’의 증명이 아니라 계산과 동작 확인이다.

타입 검사는 점검 중 통과했으나 마지막 재검사에서는 `src/render/newland-house-art.ts:93`의 사용하지 않는 변수 `i` 오류1건이 나왔다. 밸런스 계산과 시나리오 테스트 결과에는 영향을 주지 않는 별도 외관 코드의 문제이며, 전체 타입 검사가 최종 통과한 상태로 보고하지 않는다.

## 읽는 기준

- **실제 시간과 게임 시간을 구분한다.** 이동 중 실제 1초 = 게임 1분. 필사·대화 등 창을 열면 자연 시간은 멈춘다. 행동의 30분·60분은 완료 시 게임 시계를 즉시 넘기는 비용이다. 따라서 ‘필사 60분’이 실제 60초 소요라는 뜻은 아니다.
- 아래 글자 수는 게임 대조와 같은 NFC 정규화 후 공백·문장부호·기호를 제외했다. 신약은 **260장, 7,957절, 315,654글자**다.
- 타이핑 시간은 **분당 완성 글자 200개**라는 가정으로만 계산했다. 한글 키 입력 횟수인 ‘타수’와 다르다. 읽기·이동·오타·화면 전환은 제외하고, 전부 직접 쓰기를 선택한 비교용 기준이다. 퍼즐을 사용하면 달라진다. 실제 이용자 소요 시간은 아직 측정하지 않았다.
- 새 게임은 `growthVersion`에 따른 해금이 적용된다. 개편 이전 저장(`growthLegacy` 또는 표식 없음)은 기능이 모두 열려 같은 기준으로 비교할 수 없다.
- 필사 삯은 점검 시점의 **20 + 절 수×5, 장당 최대 200닢**을 사용했다. 오래된 경제 보고서·코드 주석의 12~30닢 생활 수입을 현재 전체 경제로 오해하면 안 된다.

## 2. 해금 전체 표

‘순서대로’는 마태→계시록. ‘짧은 책 우선’은 장 수가 적은 책부터, 동률은 글자 수가 적은 책부터다. 두 열은 해당 기능이 열릴 때까지 마친 누적 장 수다. 모든 책을 처음부터 선택할 수 있기 때문에 실제 가능한 경로다. 짧은 책 우선이 모든 상황에서 실제 플레이 시간을 최소화한다는 뜻은 아니다.

기능 해금은 책을 마쳤는지로 판단하고, 제본·서고에 꽂기는 대부분의 기능에 필요하지 않다. 새 터는 별도로 **27권을 모두 꽂고 완독 잔치가 정산돼야** 받는다. 화면에서 ‘권수’, ‘완필’, ‘서고 채움’을 같은 말처럼 쓰면 혼동할 수 있다.

## 9. 유지해도 좋은 제한

인사·도움·선물의 주민별 하루 제한, 첫 필사 장에만 주는 삯, 판매처별 일일 제한, 희귀품 종류별 구입 제한, 공동시설 동시1개, 주민 출산·인구 상한, 음식과 재료의 미니게임 실패로 재료를 잃지 않는 원칙, 퀴즈를 선택하지 않아도 책을 꽂을 수 있는 구조는 편안한 생활 게임에 잘 맞는다.

단순히 돈을 덜 주거나 모든 날짜를 늘리는 방식으로는 책 선택 격차와 늦은 생활 해금을 해결하지 못한다. **핵심은 ‘읽는 책의 자유’와 ‘생활의 자연스러운 성장’을 함께 유지하는 해금 구조**다.

2. **해금 곡선을 결정:** 첫 요리·모임·연애·출생을 이용자가 어느 실제 플레이 시간에 경험하도록 할지 정한 뒤 장 수와 생활 경험 조건으로 연결. 책 순서 잠금은 되살리지 않는다.
3. **필사 수입은 현재 의도를 보존:** 초반 물가는 유지하고 중후반 선택 소비를 늘린다. 필사 외 일은 수입 기대치를 설명하거나 관계·기술·독점 보상으로 역할을 분명히 한다.
4. **관계 진행 안내:** 문턱에 도달했을 때 다음 사건의 장소·시간·참석자와 조건을 보여주고, 주민 연애 전 관심 후보를 표현할 기회를 준다.
5. **아이 활동은 출생에 연결:** 기본 활동은 나이에 따라, 깊은 활동·진로는 후반 책 조건으로 확장한다.
6. **실사용 시간 측정:** 처음 하는 사람3~5명으로 PC/모바일 각각 입력 방식, 장 완료 실시간, 하루 필사량, 첫 생활 기능까지 이탈률, 남는 돈, 마음 문턱 대기일을 기록한다. 현재의 이론 시간만으로 ‘즐겁다’ 판정은 하지 않는다.

정확한 권장 비용이나 목표 일수는 의도한 플레이 길이에 따라 달라진다. 이번 보고서의 조정안은 확정 수치가 아니라 현재 병목을 줄이는 방향이다.

## 재현 자료·점검 범위

- `progression-model.json`:27권 실제 본문량, 모든 권수 도달량, 경로별 필사 수입. 정규화 글자수와 순서·가정 포함.
- `runtime-probes.json`:시간 제한 후 채집, 성인 배움터, 자율생활/연애 해금 순서, 모든23명 주민 배율, 병든 아침 회복 결과.
- `parameters.json`:비테스트 소스에서 수치 상수·규칙 함수·시간/돈/마음 호출을 추출한 **소스 색인**. 정규식으로 주변 소스를 보존한 자료라 모든 항목이 순수 밸런스 상수라는 뜻은 아님.
- `source-inventory.md`:색인에 포함한 엔진 모듈 목록. 그림 좌표·저장 마이그레이션·연출 숫자도 섞여 있으므로 실제 밸런스 해석은 위 보고서와 개별 원본을 기준으로 한다.
- `scripts/audit-balance-2026-10-13.mjs`:본문 진행량·수입 계산 재실행용.
- `src/engine/balance-audit-2026-10-13.test.ts`:확인된 현재 행동의 재현 시나리오. 문제를 고치면 해당 감사 시나리오의 기대값도 수정해야 한다.

이번에 모든 무작위 이벤트의 장기 분포나 모든 UI 경로를 자동 플레이한 것은 아니다. 특히 특정 주민의 사건 조건 때문에 며칠 기다리는지, 모바일 타이핑/퍼즐의 실제 부담, 완독 후 160일 이상 생활의 재미는 이용자 테스트가 남는다. 기존 테스트 통과와 소스 점검 범위를 이 부분의 완료로 확대 해석하지 않는다.
