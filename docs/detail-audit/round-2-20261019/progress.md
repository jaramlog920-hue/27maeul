## 유한 검사 큐

각 항목은 실제 코드와 기존 테스트를 먼저 읽어 미검사 조건 하나로 좁힌다. 아래는 검사 예정이며 검증 결과가 아니다. 필요하면 항목을 여러 회차로 분리하고 이미 확인된 조합은 건너뛴다.

1. **수납 가구 실제 사용 → 마지막 물건 꺼내기 → 가방 한도 거절/부분 수령.** `src/engine/game.ts`의 `takeFromChest`, `src/features/bag/StorageView.tsx`, `src/engine/easier.test.ts`, `StorageView.test.tsx`를 기준으로 수량 보존, 선택 상세와 안내, 닫기/재열기, 저장 복원을 대조한다.
2. **수납 가구 실제 사용 → 넣기 → 보관함 한도/넣을 수 없는 물건.** 기존 정상 넣기·집 밖 거절 테스트와 겹치지 않는 수량 경계 및 열린 창에서 상태가 바뀐 경우를 고른다.
3. **설치한 기능 가구 → 작업 시작 → 재료가 가방/보관함에 나뉜 경계.** 실제 사용 가능한 가구 하나와 작업 하나만 고른다. 성공·재료 부족·취소·산출물 보관 한도를 좁게 대조하고 1차 대장장이 보상/마감/촛대 조합은 제외한다.
4. **아이 전환 → 이미 열린 행동 창 → 하루 상태 변경.** 1차 진로 초안·성인 배움터·성장 첫날 도움 조합을 제외하고 현재 코드에 남은 지연 실행 조건 하나를 고른다.
