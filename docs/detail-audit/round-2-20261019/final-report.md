## 완료한 경계

1. 수납 가구의 마지막 꺼내기:50종 빈칸/99개 묶음 경계, 거절·취소·상태 회복·부분 수령·실제 재접속.
2. 모두 넣기의 부분 수납:보관29/가방2→보관30/가방1, 잔여 상세/버튼, 한도 재시도, 빈 공간 확보 후 마지막 수납, 두 차례 실제 재접속.
3. 설치 작업대의 혼합 재료:가방 양털1+이불장2, 상세·시작·취소·완료·fixture 지연 재검사·실제 영구 저장 복원.
4. 배움터 아이별 하루 제한:첫째 완료/둘째 미이용에서 가족 선택·재진입, 이름/버튼/비용/경험치 대상, 중복 거절·복원, fixture 열린 창/다음 날 방어 검사.

각 실행 시점의 검증 테스트 합계는20개(5+6+4+5) 통과다. 하나의 최신 소스 전체 회귀 실행 결과가 아니라 회차별 결과이며, 검사를 진행하는 동안 기존 작업 트리와 HEAD가 바뀐 점을 소스 상태/해시와 함께 기록했다. 브라우저 검증은001·003·004·005에서 완료했다.002의 개발 서버 차단은003의 임시 정적 빌드 검사로 보완했고 원인을 게임 결함으로 세지 않았다.

## 검사 방식·한계

- 실제 사용자 저장 접근 없음. jsdom 메모리 저장소와 새 임시 Edge context를 사용했다. 게임 소스·동작·밸런스·대사·그림 수정 없음.
- 실제 포인터/UI 조작과 fixture 주입을 회차마다 구분했다. 초기 진행/재료/아이 상태는 fixture다. 열린 창에서 자원·아이·날짜를 강제로 바꾸는 조건은 방어 검증이며 자연 발생 경로까지 재현했다는 뜻이 아니다.
- 모바일390×844의 대표 경계 중심이다. 모든 가구/기기/해상도/생애 단계 전수 검사는 아니다.003~005는 현재 소스의 감사용 정적 빌드와 같은 번들 store bridge를 사용했다. 배포하지 않았다.
- 외부 글꼴은 일부 검사에서 제외했다. pageerror0은 모든 네트워크가 정상이라는 뜻이 아니다. 로컬 preview의 analytics404를 게임 기능 오류로 세지 않았다.
- 검사 하네스의 객체 동일성·능력치 순서·소수 시간 단언 착오는 바로잡고 초기 로그를 보존했다. 기존 기대값 불일치를 새 버그로 세지 않았다.
- 회차별 자세한 명령·재현 순서·실제/기대·코드 근거·증거·미확인은001~005 보고서에 있다.
