# 004 — 탁자 위 물건이 있는 회전 거절과 복구

날짜: 2026-10-18 (한국 시각). 기본 집의 식탁 위 꽃병 한 개만 대상으로 회전 거절, 꽃병 이동/회수, 탁자 회전 재시도, 저장 복원 전후를 검사했다. 게임 동작·밸런스·대사를 수정하지 않았다.

## 조건과 원인 분리

- 기본 집과 붙박이 가구를 유지했다.
- 식탁 `{x:20,y:112}`, down. 꽃병은 같은 칸의 탁자 위(`on:true`). 기록자는 `{x:20,y:114}`.
- 탁자의 빈 오른쪽 칸 `{x:21,y:112}`을 누르면 식탁, 꽃병 칸 `{x:20,y:112}`을 누르면 꽃병을 선택한다.
- 꽃병을 옮길 바닥은 `{x:22,y:113}`. 회전 후 식탁과 겹치지 않는다.
- 검사마다 꽃병이 없을 때 식탁 회전이 가능한 대조 조건을 먼저 확인했다.
- 처음 사용한 `{x:19,y:113}`은 기본 가구를 유지하면 다른 통로 조건 때문에 꽃병을 치워도 회전할 수 없는 자리였다. 그 실패를 버그로 세지 않고, 위의 대조 조건이 성립하는 자리로 검사 배치를 고쳤다.

## 결과

### 회전 거절

꽃병이 탁자 위에 있으면 식탁 회전을 거절하고 안내한다. 탁자와 꽃병의 위치·방향·수량, 가방, 선택과 저장 문자열이 보존됐다.

### 바닥으로 옮기는 경로

꽃병이 바닥 `{x:22,y:113}`으로 이동하면 `on` 표식이 지워진다. 꽃병은 방 안에 한 개, 가방에는 0개다. 식탁을 재선택하면 right로 회전하고 바닥 꽃병은 그대로다. 저장 후 다시 열어도 같은 상태다.

### 가방으로 회수하는 경로

꽃병만 회수되고 식탁은 남는다. 가방 꽃병은 0→1, 방 안 꽃병은 1→0이다. 식탁을 재선택하면 right로 회전한다. 재접속 후에도 수량과 배치가 일치한다.

### 실패·취소 경계

- 꽃병을 잘못된 바닥으로 옮기는 시도가 실패하면 탁자 위 표식과 선택·수량이 보존된다. 이동을 취소한 뒤에도 꽃병이 남아 있으므로 식탁 회전은 계속 거절된다.
- 가방에 꽃병이 99개일 때 회수하면 가방 안내가 나오고 원래 탁자 위 꽃병은 남는다. 탁자 회전 조건이 잘못 해제되지 않는다.
- 저장 복원 전후에 탁자 위/바닥 상태가 뒤바뀌거나 꽃병이 복제되는 현상은 확인하지 못했다.

### 이전 실패 안내의 잔상

빠르게 물건을 치운 뒤 회전하면, 성공 화면에도 직전 실패 toast가 짧게 남을 수 있다. 이전 회차의 미확인 관찰을 이어 확인했으며 두 브라우저 경로 모두 4초 제한 안에 정상적으로 사라졌다. 영구적인 실패 안내나 새 확정 버그로 분류하지 않는다.
