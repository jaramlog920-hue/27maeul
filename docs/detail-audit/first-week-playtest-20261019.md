# 처음 하는 사람으로 1~7일째 플레이 점검 (2026-10-19)

배포판과 같은 커밋 `e49615f`를 따로 떼어 낸 폴더에서 개발 서버를 띄우고, 휴대폰 크기(375×812) 브라우저로 새 게임을 시작해 7일째 장날까지 진행했다.
게임 코드는 바꾸지 않았다. 아래는 "처음 하는 사람이 막히거나 어수선하게 느낄 곳"만 골랐다.

## 점검 방법과 한계

- 새 게임 → 캐릭터 만들기 → 오프닝 → 마가복음 1장 한 절 직접 필사 → 나머지 절과 빌레몬서는 개발용 연결로 채움 → 제본 → 서고 → 잠 → 2~7일째 아침 → 이웃 대화·돕기 → 장날 거래 창.
- 브라우저 창이 앱 뒤에 가려져 있어 애니메이션 시간이 거의 흐르지 않았다. 그래서 걷기·시간 흐름은 게임 진행 함수를 직접 돌렸고, 미니게임(반죽 치대기)은 끝까지 해 보지 못했다.
- 화면 캡처가 한 박자 늦게 찍히는 일이 있어, 창 내용은 화면 글(DOM)로 다시 확인했다.
- 개발 서버 특유의 현상(첫 화면 컴파일 지연, 다른 작업자의 파일 수정으로 인한 자동 새로고침)은 실제 배포판과 관계없어 목록에서 뺐다.
