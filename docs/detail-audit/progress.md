# 27마을 세부 기능 검사

사용자 요청: 한 차례에 좁은 행동 연결부를 약 10분 집중 검사한다. 게임 전체 시뮬레이션을 반복하지 않고, 코드 조건 분기에서 빠진 예외와 안내·반응 부족을 찾는다. 게임 동작·밸런스·대사는 승인 없이 수정하지 않는다.

반복 실행 완료: 이 대화의 heartbeat `27`은 10분 간격으로 사용했으며, 001~013의 1차 큐 완료 후 도구로 PAUSED 변경을 확인했다. 최종 보고서는 `final-report.md`다. 같은 조건을 반복하지 않도록 새 검사 요청 시 이 파일과 회차 보고서를 이어 읽는다.

## 큐

1. 1차 완료: 가구 설치 실패와 취소 — 상태·toolbar 8건과 기존 배치 6건, 데스크톱/모바일 실제 포인터 6흐름 확인. D001 안내 부족, D002 의도 확인, D003 설치 대기/기존 선택 조작 구분 부족 기록.
2. 1차 완료: 가구 회전·차지하는 칸·충돌·저장 일치 — 벽 끝과 탁자 위 물건의 거절·복구·재접속 확인. D004 의도 확인 항목 유지. 탁자 위 물건 경로는 새 문제 없음.
3. 1차 완료: 선물 마지막 수량·하루 제한·보상 — 같은 날 재시도와 다음 날 초기화·저장 복원 확인. D005 하루 제한 안내 부족 유지. 새 날 처리 오류 없음.
4. 1차 완료: 아이 성장 직후 대사·메뉴·가능 행동 — 14일/42일/84일과 전날 배움터 표식 경계 확인. D008 진로 초안 전환 버그, D007 도움 수령 실패 안내 부족은 미수정. 성인 배움터 허용은 기존 2026-10-13 보고 동작이라 새 발견으로 세지 않았다.
5. 사용자 추가 요청·1차 완료: 대장장이 관련 설치 가구의 실제 사용. 협탁 보상(008), 나무통 마감(009), smith:2 부탁 촛대 보상(013)의 실제 사용/반응·회수/재접속을 확인했다. D006 한 칸 상판 선택 제약은 의도 확인 필요. 모든 가구 전수 검사로 일반화하지 않는다.

## 검사 규칙

- 실사용 저장 대신 jsdom 메모리 저장소나 임시 브라우저 프로필을 사용한다.
- 기존에 변경 중인 게임 코드를 보존한다. 재현을 위해 게임 동작을 바꾸지 않는다.
- 새 발견은 재현된 버그 / 재현된 안내·사용성 부족 / 의도 확인 필요 / 미검증 의심으로 구분한다.
- 이미 알려진 ModalLayer의 선물 문장·가구 방향 기대값 불일치 3건은 새 발견으로 중복 보고하지 않는다.
- 각 회차에 확인 조건, 증거, 정확한 명령과 결과, 미확인 범위, 다음 회차의 더 작은 대상을 남긴다.
