- 성인 자녀의 배움터 이용은 기존 `docs/audits/balance-2026-10-13/report.md`의 확인 동작이다. 012에서 현재 UI·성장·저장 경계를 추가 확인했지만 새 발견 수에 넣지 않았다.
- 기존 ModalLayer의 선물 문장·가구 방향 기대값 불일치 3건은 새 버그로 세지 않았다.
- 원래 그림이 아닌 실제 방향 그림의 색을 확인해 나무통 마감 누락 의심을 배제했다. 캔버스 배율 착오와 450ms 유령 클릭 차단에 걸린 자동 입력도 게임 오류에서 제외했다.
- 새 터, 모든 가구·모든 NPC·모든 직업·모든 형제/예약 조합은 전수 검사하지 않았다. 발견되지 않은 조건이 정상이라는 보장은 하지 않는다.
- 현재 재현 근거가 없는 의심을 확정 발견으로 남기지 않았다.
