# 다른 기능 모바일 검증

2026-10-11~12, 격리된 Chrome 모바일 에뮬레이션. 실제 사용자 저장을 쓰지 않았다.
이번 추가 캡처는 기능 흐름 390×664, 재접속 오류 재현 320×664이다.
29장을 추가해 기존 갤러리는 총 300장이다. `다른 기능` 필터로 볼 수 있다.

## 실제로 실행한 흐름

| 기능 | 확인 결과 |
| --- | --- |
| 텃밭 | 향초 씨앗 심기, 매일 물 주기, 잠들기로 3일 성장, 익은 작물 수확. 향초 8개에서는 가방 상한 안내가 나왔고, 별도 여유 가방에서는 6→8개와 밭 비움을 확인했다. |
| 강아지 | 입양 가능한 둘째 날에 몽실로 이름 짓기, 집에 두기, 다시 데리고 다니기. |
| 고양이 | 둘째 날 나비 입양. 집에서 지낸다는 설명과 동행 버튼을 숨기는 화면. |
| 작업대 | 잉크 손일을 포인터 반복 입력으로 완료. 완료 후 그을음·물 각각 1개 소비, 잉크 1개 획득. |
| 목수 | 재료 궤짝 주문으로 50닢 차감. 잠든 다음 날 주문 목록에서 제거되고 설치 표식이 활성화됨. |
| 새 터 건축 | 주택 미리보기, 주문 후 150닢·올리브 4·파피루스 3 차감. 취소 확인 후 전액·재료 환불과 주문 제거. |
| 손님집 | 넬리에게 20~22일 매일 대화. 같은 날 재대화 차단, 사흘째 버들 바구니 선물. 날짜 전환 중 자동 말씀 조각 창은 분리해 대화 창을 다시 확인했다. |
| 필사본 다시 읽기 | 본문을 받지 않은 새 접속에서 에베소서 1장 완성본을 선택하면 펼치지 못하는 오류 재현. |

후반 성장·재료·가족 상태와 접근 위치는 개발용 초기 상태로 준비했다. 심기·물주기·수확·입양·주문·취소·대화·손일은 화면으로 실행했고, 날짜는 실제 `goToSleep` 엔진으로 넘겼다. 여유 가방 수확은 가득 찬 가방 분기와 별도 초기 상태다.

## 수정

`CopiedReadPick`이 신약 책도 선택할 때 먼저 내려받도록 수정했다.
작성 중인 장 목록도 아직 받지 않은 본문에 접근하지 않고 저장한 절 위치를 유지하도록 수정했다.
회귀 테스트는 본문 다운로드가 끝나기 전에 펼치지 않는지, 다운로드 후 에베소서 23절이 보이는지, 본문 없이도 작성 중인 장 목록이 남는지를 확인한다.

관련 6개 파일 30개 테스트와 `npm run build`가 통과했다.
수정 후 브라우저 재검증은 개발 서버가 응답을 멈춰 완료하지 못했다. 수정 전 오류 재현 캡처와 테스트 결과를 증거로 남겼다.

### 2026-10-12 후속 확인

개발 서버 복구 후 브라우저에서 미리 본문을 받지 않은 에베소서 완성본 23절과 작성 중인 빌레몬서 3절을 확인했다. 위 미완료 항목은 정상 연결 조건에서 검증 완료했다.
추가로 본문 요청 실패 후 재시도 문제와 후계자 연애 화면 이름 문제를 발견했다. 사용자 요청에 따라 제품 코드는 수정하지 않고 `docs/bug-report-mobile-2026-10-12.md`에 재현 상태·캡처와 함께 기록했다.
추가 검증 52장을 더해 갤러리는 총 352장이다.
