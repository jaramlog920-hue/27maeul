| 표현 방식 | 예시 |
|---|---|
| 전용 이벤트 장면 | 겨울 우리, 날아간 새, 부서진 배, 다시 뜬 배, 사흘, 밤의 기침, 공책 맨 뒤, 새 식구, 둘이 만든 장난감 |
| 작은 삽화 | 게시판의 첫 부탁, 선물, 부탁을 들어준 날, 새 이웃, 서고 문 개방, 겨울 도구 닦기, 항아리 표지, 책 받침 |
| 기존 대화창 | 모임 초대 안내, 재료를 요청하는 이웃의 부탁, 고향 길, 늦게 닫은 약방, 바쁜 날, 호감도 과거 이야기, 같은 내용의 관계 확인 |

추천 제작 순서: 가족의 큰 전환(청혼·결혼·출산) → 인물의 핵심 이야기(새·배·진로·돌봄·글자·공책) → 가족 활동 → 기억에 남는 조용한 생활 장면. 작은 삽화는 기존 물건 도트를 정확한 대상에 연결하는 것부터 시작한다. 전체화면 장면처럼 확대·연속 동작을 붙일 필요는 없다.

검토 주의: 작은 삽화도 해당 대사에 맞는 실제 물건·상황을 보여 줘야 한다. 모든 항목에 공통 두 인물을 넣고 배경색만 바꾸는 방식은 쓰지 않는다. 기존 대화창 항목은 이벤트 자체를 지우는 뜻이 아니며 원래 선택·보상·관계 기록을 그대로 유지한다.

## 적용 기준

- 전용 장면: 가족·관계의 중요한 전환, 물건·장소가 바뀌는 사건, 행동으로 드러나는 개인 성장, 실제 이동·돌봄·공동 활동.
- 작은 삽화: 선물·가구·작업 결과, 해금 안내, 소품이 중심인 짧은 생활 활동.
- 기존 대화창: 초대·일정 안내, 재료 부탁, 생각·과거 이야기, 말만 달라지는 관계 확인.
- 원래 이벤트·대사·선택지·보상·시간·해금 조건을 삭제하거나 변경하지 않는다. 이 문서는 표현 방식과 제작 순서를 정하는 선별안이다.
- 이미 만든 전용 그림은 그대로 유지한다. 아직 제작하지 않은 항목만 새 우선순위를 적용한다.
- 사용자 최신 결정: 세 창 및 ㅍ·ㅎ 분담 대신 이 대화에서 순차 제작한다. 표의 기존 담당 표시는 과거 분담이며 완료·진행 중 작업만 대조하여 중복을 피한다.
- 사용자 최신 결정: 이 선별표를 자동 제작 기준으로 적용한다. 전용 이벤트 장면을 우선하고 작은 삽화를 이어서 만들며 기존 대화창 항목은 유지한다. 기존 heartbeat를 5분 간격으로 갱신했다.
