# 주민 나이와 자율생활 해금

## 동작

- 새 해금 규칙의 저장에서는 자율생활(신약 75장 완필) 이후 성인 주민의 노년 진행을 허용한다. 아이는 기존처럼 어른까지 자란다.
- 설정의 주민 나이 항목도 같은 규칙을 사용하며 해금 전에는 ‘나이 듦’을 누를 수 없다. 해금 후에도 직접 선택한 ‘그대로’는 유지한다.
- 잠긴 기간, ‘그대로’ 기간, 자율생활을 끈 기간은 성인 이후 나이에서 제외한다. 실제 출생일과 기존 가족·성장 기록은 변경하지 않는다.
- 기존 노년·은퇴 상태를 되돌리지 않으며, 개편 이전 저장은 기존 해금 권한을 유지한다.

## 관련 코드 검토 및 수정

1. `settleOneDay`가 자율생활 해금과 무관하게 노년 성장까지 정산하던 경로를 수정.
2. 빵집 아이를 `bakerBabyAt`에서 달력 날짜만 보고 다시 노년으로 만들던 저장/렌더 경로를 수정. 성인 이후 단계는 실제 정산 상태를 사용.
3. 단순히 성인에 고정했다가 옵션을 켜면 경과 날짜 전체가 반영되던 문제를 방지. `agePause`를 저장·복원해 멈춘 기간을 보존.
4. 견습 도중 나이를 멈춘 뒤 다시 켜면 부모가 즉시 은퇴할 수 있던 문제도 수정. 실제 견습 시작 기록은 유지하고 정지 기간을 별도로 제외.
5. 초기 생성, 같은 날 반복 정산, 최대 7일 따라잡기 후 보완, 자율생활 재개, 다른 저장 칸, 빵집 아이 표시를 함께 확인.
6. 대사 조건의 `bakerChildStage` 사용도 확인. 성인 조건은 adult/elder를 모두 허용하므로 이번 성인 정지와 충돌하지 않음.
