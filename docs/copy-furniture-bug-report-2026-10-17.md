## 남은 검증과 제한

실제 브라우저·휴대폰에서 게임을 연속 조작하는 최종 검증은 기존 권한 게이트 제약 때문에 수행하지 않았다. 새 브라우저·포트·CDP 등으로 우회하지 않았다. 로컬 PNG와 jsdom 검사만으로 브라우저 검증 완료라고 기록하지 않는다.

jsdom의 기존 CopyDesk 검사에서는 실제 Canvas 컨텍스트가 없어 `HTMLCanvasElement.getContext()` 미구현 경고가 출력된다. UI 검사는 통과했지만 실제 화면 검증의 대체 근거로 사용하지 않았다. 빌드는 큰 번들 경고와 함께 성공했으며, 번들 분할 작업은 이번 가구 추가 범위에 포함하지 않았다.

새 가구의 자율 생활 행동은 추가하지 않았다. 가구 곁에서 눌러 사용하며, 실제 근처 가족/동물이 없으면 빈 가구의 정리·준비 동작을 보여 준다. 다른 대화의 이벤트·의상·지도 변경과 기존 기록은 보존했다.
