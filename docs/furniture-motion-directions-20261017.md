# 가구 사용 모션 방향 점검

2026-10-17 사용자의 계속 요청에 따라 설치 방향과 직접 사용·NPC·아이·반려동물 사용 모션을 점검했다.

- 기본 가구/생활 가구의 기존 네 방향 모션 및 여닫기 프레임을 검사했다.
- 자율 앉기·눕기는 접근할 때 바라본 방향과 앉은 뒤 가구가 향한 방향을 구분한다. 직접 앉기도 가구 방향을 보존한다.
- 의자에 앉은 읽기·마시기·손일 역시 의자 방향을 따른다. 앞에 깔린 깔개가 의자보다 먼저 선택되지 않도록 실제 의자를 우선한다.
- 가구 곁에서 직접 읽기·마시기·손 뻗기·여닫기를 할 때는 가까운 가구 점유 칸을 바라보고 선 자세를 사용한다. 설치한 가구 방향은 spot에 별도로 보존해 가구 문과 인물 방향이 섞이지 않는다. 서 있는 인물을 앉은 프레임으로 그리지 않도록 렌더러 및 캐시를 구분했다.
- 아이 가구의 원래 몸 그림이 항상 down이던 부분을 실제 네 방향 캐릭터 원본으로 연결했다. 옆으로 앉은 다리도 구분한다.
- 반려동물은 설치 방향에 따라 그릇/장난감 접촉 방향을 향한다. 소품 반응과 정지 그림이 같은 방향 원본을 사용한다. 동물·세워진 그릇 자체를 90도 돌리지 않고 방향별 낮은 받침과 소품을 따로 그렸다. 둥글게 자는 자세는 기존 안정된 웅크림 원본을 유지한다.
- 유저 자율행동은 추가하지 않았다. 보상·재료·호감도·시간·저장 형식은 유지하며 추가 standing 필드는 일시 동작의 그림용 상태다.
