장날 상인의 생활 가구 회전에 추가했다. 기존 48종과 합쳐 68종이며 매 장날 8종씩 나온다. 구매 이름·설명·가격, 배치, 회전, 가방 아이콘, 저장 복원을 기존 등록 경로에 연결했다. 벽걸이는 벽 레이어, 동물과 아이의 사용 자리는 올라가 앉을 수 있는 바닥 레이어를 사용한다.

## 실제 게임 동작

- 집에 둔 반려동물이 낮잠 때 설치된 침대/깔개를 찾아가 몸을 만다. 새 침대는 별도 공간 지정을 하지 않아도 이용하며, 동물 쉼터 지정에도 쓸 수 있다.
- 깨어 있을 때 매시 처음 8분은 물그릇, 놀이 습관 때는 매듭줄/탐색판으로 이동한다. 물그릇 잔물결, 줄 당김, 탐색판 조각의 움직임과 기존 동물의 코·앞발 동작을 함께 그린다.
- 집에 두기로 한 유아/어린이는 낮 7~21시에 설치된 가구를 20분 간격으로 골라 사용한다. 유아는 목마·블록·그림책·북, 어린이는 블록·그림상·그림책·북을 쓴다. 학교, 따라다니기, 신생아 요람, 성인 일과는 기존 경로를 쓴다.
- 아이의 실제 외형과 옷 팔레트를 사용하고, 몸통을 보존한 채 무릎을 접는다. 블록 쌓기·그리기·책장 넘기기·양손 북치기·목마 타기를 각각 그렸다.
- 설치된 가구와 접근 가능한 빈칸만 선택한다. 철거·이동·인물 점유 때 즉시 재계산한다. 사용 여부를 저장에 추가하지 않았다. 설치하지 않은 동물 방석을 자동 생성하지 않는다.

## 검증

- 관련 9개 파일, 102개 검사 통과: 가구 등록/가격/회전/아이콘, 구매 회전, 배치와 저장 복원, 실제 반려견 이동, 점유·철거, 연령·동행 상태, 네 방향/단계/팔레트/얼굴 가림, 기존 동물·공간 회귀와 시각 자료 출력.
- TypeScript 검사, `npm run verify`, Vite/PWA 빌드 통과. Vite는 이 환경의 Windows 설정 로더 `spawn EPERM`을 피하는 기존 API 실행 방식(`configFile:false`, `resolve.preserveSymlinks:true`)으로 검사했다.
- 게임과 같은 원본 함수에서 출력한 20종 도트와 160개 사용 프레임을 PNG로 확인했다. 유아/어린이 남녀 외형, 강아지/고양이 성체·새끼를 포함한다. 브라우저 실화면 검증은 포함하지 않는다.
- 결과: `artifacts/scenery/family-furniture-20.png`, `family-furniture-motion-1.png`~`8.png`, `family-furniture-preview.html`. HTML은 가구/아이/동물 필터, 재생/정지, 단계 선택을 제공하며 게임 저장·앨범에 접근하지 않는다.
- 다른 대화의 미커밋 변경과 기존 방석 제거 변경은 보존했다.
