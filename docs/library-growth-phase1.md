## 성장 계산

- progression.ts: 작은 books.json 메타데이터로 유효한 신약 완료 장 수, 완필 권 목록, 전시 권 목록을 각각 계산한다.
- 권 완필은 제본·서고 전시와 독립적이다. 재필사·중복·범위 밖 장·구약 장은 누적하지 않는다.
- feature-rules.ts: 맛보기 / 정식 조건을 한곳에 둔다. 정식 조건을 먼저 검사한다. 빌레몬서→요한이서→요한삼서를 먼저 완필해도 정상적으로 진행한다.
- submitChapter, recordLetter, writeVerse: 모두 applyEarlyGrowth로 장 완료 보상을 처리한다. UI가 선물을 지급하지 않는다.
- flags의 growth:*는 일회성 보상·체험 소비 기록이다. 접근 권한 자체는 진행에서 계산한다.

## 기존 저장과 체험 범위

- 새 게임은 growthVersion=1. 그 이전 저장을 불러오면 growthLegacy=1로 기존 이용 권한을 보존한다. 가구·관계·가족을 초기화하지 않는다.
- 과거에 이미 넘긴 목표는 불러오기에서 보상이나 안내를 재지급하지 않는다. 이후 처음 넘긴 목표만 처리한다.
- 편지 체험은 한 통, 게시판 체험은 한 부탁만 가능하다. 각 정식 해금 이후에는 체험 제한이 사라진다.
- 첫 편지는 잠들어도 보존한다. 첫 방문은 실제로 인사한 뒤 소비한다. 게시판 부탁은 엔진에서도 접근·재전달을 검사한다.
- 집 정리의 새 그림, 매 장 책장 시각 변화, 상세 장 완료 화면과 다음 목표 상시 표시는 후속 범위다.

## 검증 기록 (2026-10-11)

- 성장·필사·게시판 화면·편지·주민 부탁·가구 배치·기존 저장 관련 18개 테스트 파일, 375개 테스트 통과.
- 짧은 책 우선 완필, 장 합산, 재필사와 저장 복원 후 중복 지급 방지, 체험 소비, 다른 의뢰 전달 경로 차단을 검사했다.
- 배우자·아이·배우자 가구가 실제로 있는 이전 저장의 복원과 기존 기능 권한 유지도 검사했다.
- 별도 확장 검사인 game.test.ts / ModalLayer.test.ts: 148개 중 83개 통과, 65개 실패. 새 성장 판정을 비활성화한 별도 복사본과 실패 이름을 비교했고, 이번 변경으로 새로 실패한 항목은 남아 있지 않다. 따라서 프로젝트 전체 테스트가 통과한 것은 아니다.
- 타입 검사와 배포 빌드 통과. 콘텐츠 검증도 통과. 현재 메인 JS는 약 3.35MB이며 큰 청크 경고가 남는다. 신약·화면 지연 로딩은 후속 작업이다.
