# 도감 점검 및 화면 가독성 수정

- 도감: ITEM_TEXT·FURNITURE_DEFS·BOOK_DESIGNS·RECIPES·NEW_DISHES·SKILL_IDS를 실제 도감과 비교하는 기존 검사 통과. 물건별 그림과 이름·설명·획득 경로도 확인했으며, 추가 가구 20종은 동적 목록에 이미 포함되어 누락 항목을 새로 만들 필요가 없었다.
- 웬델(내부 poppy) 돕기: 이미 실제 보상은 약초차였다. 완료 감사 대사에 남은 빵 문구를 약초차 한 잔으로 수정하고 대사·인벤토리·수첩·일기 일치를 검사했다.
- 어두운 전체 화면 이벤트: 하단 창에 밝은 본문/설명/선택지 색과 어두운 버튼 바탕을 함께 적용했다. 선택 상태·사용 불가 상태의 대비를 유지한다. 언덕으로 이어지는 길에서 등의 위쪽 장소 표시는 흰색에 가까운 #fffaf4와 그림자를 사용한다.
- 능력치: 기존 점수·보상·단계 계산은 유지한다. 누르면 현재 단계의 경험치/다음 단계 요구치 및 누적 경험치 기준 0·30·90·190·340을 설명한다. 매력 2단계·현재 경험치 4는 표시 점수 11/100임을 UI 검사했다. 반올림한 /100 점수만으로 모든 단계 경계를 정확히 구분할 수는 없다.
- 새 게임 첫 안내(welcome): 전체 화면 AuthoredStoryScene 대신 기존 아래 설명 창을 사용한다. 원래 세 줄·다음/닫기 순서를 유지하며 안내를 읽어도 이벤트 그림·앨범 기록을 생성하지 않는다. 다른 이벤트 렌더러는 유지한다.

검증: 관련 7개 테스트 파일 40개(능력치 추가 검사 포함) 통과, 별도 도감 선물 풀 검사 통과. TypeScript·전체 콘텐츠 verify·Vite/PWA 빌드 통과. 브라우저는 http://127.0.0.1:5191 접근을 저장된 사용자 권한 정책으로 거부하여 실제 시각 확인은 수행하지 못했다. 다른 브라우저나 주소로 우회하지 않았다.
