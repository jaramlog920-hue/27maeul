# 모바일 화면 확장 검증

검증일: 2026-10-11. Chrome 모바일 에뮬레이션. 320·360·390 × 664 CSS px.

앞선 시작·필사·오프라인 검증에 이어, 격리된 개발 서버에서 신규 게임과 신약 26권 완료 상태를 준비하여 화면 범위를 확장했다. 실제 사용자 저장 데이터는 사용하지 않았다. 후반 상태에는 재료, 주민 호감도, 배우자와 아이, 제본한 책을 넣었다. 화면별 직접 진입 검증이며, 모든 화면까지 지도에서 걸어가는 전체 진행 검증은 아니다.

## 확인 범위

- 후반 상태: **47개 화면·탭 × 3개 너비 = 141장**.
- 신규 상태: 그중 **14개 화면·탭 × 3개 너비 = 42장**. 빈 목록과 기능 잠금 안내를 함께 확인했다.
- 추가: 재제본·요리·소모임·행사·좌판·도감 등의 실제 터치 동작 캡처 32장, 높이 360px 화면 4장. 모음에는 **총 219장**을 수록했다.

## 발견하여 수정한 문제

1. **320px 가방의 오른쪽 칸 잘림**: 페이지 전체 너비는 정상이었지만 6열 격자의 내부 너비가 258px에서 284px로 넘쳤다. 340px 이하에서는 5열로 바꿨다. 수정 후 320px 격자는 258/258px, 칸 너비 약 48px. 360·390px에서는 6열 유지 및 칸 너비 44px 이상을 확인했다.
2. **소모임 날짜에 `{day}` 노출**: `98{day}일째`처럼 보이던 날짜를 텍스트 치환 함수로 처리했다. 브라우저에서 `92일째` 표시와 자리표시자 제거를 재확인했다.

가방·소모임 관련 테스트 **12개 통과**, `npm run build` 성공. 전체 테스트를 모두 통과했다는 뜻은 아니다.

## 검증 해석과 한계

후반 화면 47종의 최종 확인에서는 페이지 및 대화창 내부의 가로 넘침을 측정했다. 화면 전환 효과가 캡처에 남지 않도록 최종 캡처에서 애니메이션을 정지했다. 대표 화면은 캡처 모음으로 시각 검토했다.

초기 검증용 레시피 준비 과정에서 유효하지 않은 `map` 키가 포함돼 제작·도감 캡처 6장이 오류 안내를 표시했다. 이는 테스트 상태 구성 오류였다. 유효한 레시피 ID로 수정하고 해당 6장을 다시 검증·교체했다. 최종 결과에는 로딩/오류 안내를 정상 화면으로 집계하지 않았다.

이 보고서 작성 당시 공동시설 완료, 소모임·행사 당일, 여행 완료, 세대 교체·엔딩은 미검증이었다. 이후 대표 완료 흐름과 일부 예외 분기를 확인했으며, 후계자 이름 표시 오류를 추가 수정했다. 최신 결과는 [남은 모바일 흐름 검증](mobile-flow-verification.md)을 참고한다. 모든 조건 조합의 전수 검증, 실제 휴대폰·Safari·OS 키보드·홈 화면 설치·장시간 성능은 아직 미검증이다. 앞선 실제 필사·저장·오프라인 검증은 [기존 보고서](mobile-screen-verification.md)를 참고한다.
