27마을 — 이웃에게 배우는 생활 기술
작성일: 2026-10-05 / 상태: 미구현 기획

1. 목표
주민과 함께 배우며 생활 제작과 꾸미기의 선택지를 넓힌다.
능력치 숫자만 오르는 대신 새 무늬·모양·마감법을 실제로 사용할 수 있게 된다.
기존 능력치·직업 단계·제작법을 보존하고 중복된 기술 성장 체계를 만들지 않는다.
필사 속도와 정확성, 본문 접근에 학습 효과를 붙이지 않는다.

2. 배울 수 있는 것
목수·루디: 생활 가구의 마감과 작은 장난감 모양.
베 짜는 이웃·페넬로피: 천 무늬와 색 조합, 가장자리 장식.
빵 굽는 이웃·웬델: 간식 모양과 생활 음식 제작법.
대장장이·틸리: 생활 장식 고리의 형태와 안전한 마감.
파피: 찻잔과 간식 조합, 차 자리 꾸미기.
기름 짜는 이웃: 기존 생활 향초와 용기의 꾸미기.
포도원 할아버지: 생활 식물 지지대와 수확 바구니 손질.
주니퍼·덱스터: 생활 관찰 그림과 창작 기록의 꾸미기.
실제 상품·가구·제작법이 준비된 항목만 배울 수 있다.
약방 관련 학습은 생활 화분·선반 정리 정도로 한정하고 치료법을 제공하지 않는다.

3. 학습 발견
주민의 작업을 보거나 관련 대화·공동 작업을 하면 배울 거리를 알게 된다.
첫 기본 배움은 높은 친밀도 없이 가능하다.
개인적인 무늬와 응용은 실제 공동 경험이나 관련 개인 이야기에 따라 제안할 수 있다.
조건은 무엇을 함께하면 되는지 안내하고 선물 반복만으로 잠금을 풀게 하지 않는다.
주민이 근무·모임·행사 중이면 가능한 다른 시간을 안내한다.

4. 한 번의 배움
주민의 짧은 시범 → 플레이어의 모양이나 방식 선택 → 간단한 실습 → 결과 확인.
기존 손일 미니게임 중 어울리는 것을 사용한다.
주민의 성격과 설명 방식에 따라 대사와 동작이 다르다.
실수가 나면 다시 살펴보거나 다른 방식을 고르고 학습을 영구 실패로 만들지 않는다.
기본 수업 재료는 소량의 수업 공급분으로 처리하고 가방에 무료 재료를 쌓지 않는다.
특별한 개인 작품은 필요한 재료를 미리 보여 준다.

5. 습득과 사용
완료하면 지원되는 제작법·무늬·마감 옵션 하나를 등록한다.
이후 기존 작업대와 꾸미기 화면에서 사용할 수 있다.
새 방식은 모습과 선택의 차이를 중심으로 하고 수입·생산량 배율을 과도하게 올리지 않는다.
같은 배움을 반복해 제작법과 보상을 중복 받지 않는다.
현재 능력치 상승을 연결할 때 기존 하루·행동별 제한을 확인한다.
기술 목록은 별도의 끝없는 경험치 막대 대신 습득한 실제 선택지를 보여 준다.

6. 주민 관계와 후속
배운 날과 실습 작품을 중요한 공동 기억으로 남긴다.
배운 방식으로 만든 물건을 보여 주면 해당 주민이 반응한다.
주민은 플레이어 선택을 인정하고 자신의 방식만 정답으로 강요하지 않는다.
친구·연인·배우자 상태는 말투에 반영하되 학습 자체는 연애로 제한하지 않는다.
배우자가 되어도 이미 배운 기술을 다시 잠그지 않는다.

7. 다른 기획과 연결
02 공동 작업은 학습을 발견하고 실습할 기회가 된다.
01 모임에서는 이미 배운 손일을 같이 할 수 있다.
03 좌판에서 제작 가능한 생활 상품을 판매한다.
05 행사와 09 집 공간에 직접 만든 생활 물건을 사용한다.
07 공동 시설은 필요한 응용 기술을 선택적으로 활용한다.
08 아이와의 만들기는 연령에 맞는 안전한 과정만 공유한다.
기술 부족이 다른 기능의 기본 참여를 막지 않는다.

8. 화면과 저장
주민 메뉴의 “함께 배우기”에서 배울 것, 시간, 준비물, 결과를 안내한다.
생활 기술 목록에는 배운 항목, 가르쳐 준 주민, 사용 장소, 가능한 결과물을 표시한다.
저장: 기술 ID, 배운 날과 주민, 실습 회차·진행, 선택 결과, 해금·지급 여부.
실습 중단은 완료 단계까지만 저장하고 공급 재료와 결과 지급을 일관되게 처리한다.
job.ts, stats.ts, items.ts, minigame.ts, 기존 제작·사건·save.ts를 확인한다.

9. 구현과 검증
목수의 마감법 한 가지로 발견·배움·습득·제작·후속 반응까지 연결한다.
이후 천 무늬와 간식 모양 등 실제 지원되는 제작 선택지를 확장한다.
옛 제작법을 유지하고 저장·중단·반복 학습에 중복 보상이 없는지 확인한다.
해금한 옵션이 실제 제작·가구·상품 화면에 나타나는지 검증한다.
완성 기준: 친해지고 배우는 과정이 생활의 선택지를 넓히고 사용한 결과가 남는다.
