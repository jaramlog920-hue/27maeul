번호는 사용자가 요청한 기획의 순서다. 실제 구현의 의존 관계와는 구분한다.
01은 기존 소모임 기획의 내용을 가져왔고, 이후 이 폴더의 파일을 기준 문서로 사용한다.
캐릭터별 취향과 참여 역할은 docs/characters의 01~23번 파일에 있다.

공통 연결
- 04의 기억·취향은 01·02·03·05·08의 공동 경험을 연결하는 기반이다.
- 01의 초대·참석·일정 처리는 05의 단발 행사에도 재사용한다.
- 02의 공동 제작은 03의 판매용 생활 물건과 07의 시설 작업에 연결한다.
- 07은 01·05에서 이용할 장소를 풍부하게 만든다.
- 06과 08은 기존 동물·아이 상태와 시간표를 보존하며 확장한다.
- 09는 가구 배치를 05 집들이·06 동물·08 가족의 실제 행동 공간으로 연결한다.
- 10은 기존 일과와 사건 결과에 맞는 짧은 생활 변화를 추가한다.
- 11은 02 공동 작업을 배움과 연결하고 03·05·07·09의 생활 물건 선택지를 넓힌다.

실제 구현은 기존 코드의 지원 범위를 확인하고 필요한 공통 기능을 먼저 연결한다.
기억과 지급은 경험 고유 ID로 중복을 막고, 옛 저장에는 기본값을 제공한다.
새 기능이 완성되기 전에는 플레이어에게 빈 메뉴나 실행 불가능한 약속을 노출하지 않는다.
새 수치와 인원·시간·빈도 제한은 기획 기본값이며 플레이 확인 후 조정한다.

공통 콘텐츠 기준
docs/exclusion-list.md를 따른다. 성경 사건을 생활 이야기로 재현하지 않는다.
말씀 조각과 필사본은 상품·작업 보상·재료로 사용하지 않는다.
생활 콘텐츠 미참여나 재료 부족으로 필사를 막지 않는다.
관계와 성장을 압박하는 불참 벌점·죄책감 대사를 추가하지 않는다.
실제 적용 시 콘텐츠 검증, 관련 동작 테스트, 타입 검사, 빌드와 휴대폰 화면 확인을 수행한다.

기획 완료와 구현 완료는 구분한다. 이 모음은 플레이 규칙과 구현 방향을 정리한 문서이며 최종 대본·가격·그림 자산은 구현 과정에서 구체화한다.
