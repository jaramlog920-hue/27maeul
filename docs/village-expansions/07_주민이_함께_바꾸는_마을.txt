27마을 — 주민이 함께 바꾸는 마을
작성일: 2026-10-05 / 상태: 미구현 기획
참고 요소: 주민이 공동 선택과 작업으로 생활 공간을 변화시키는 경험.

1. 목표
사랑방 게시판에서 꽃밭·그늘막·긴 벤치 같은 공동 시설을 골라 주민과 함께 만든다.
서고 권수와 기존 부탁에 따른 해금은 유지하고 이미 열린 공간에 선택 가능한 생활 개선을 더한다.
환경 점수나 정치 체계보다 공동 선택과 실제 시설 사용에 초점을 둔다.

2. 제안과 선택
현재 해금된 공간에서 만들 수 있는 개선안 2~3개를 게시판에 표시한다.
효과, 위치, 필요한 작업과 생활 재료, 관심 있는 주민을 미리 보여 준다.
한 번에 진행하는 사업은 하나로 제안한다.
플레이어는 의견을 듣고 원하는 안을 고른다.
다른 안을 영구적으로 잃지 않도록 완료 후 다음 작업으로 선택할 수 있다.
같은 자리를 사용하는 대안은 형태 변경으로 다루고 되돌릴 수 있는 비용과 규칙을 안내한다.

3. 개선안
꽃밭: 주니퍼·벌 치는 이웃·물 긷는 아이가 관찰과 배치에 참여한다.
그늘막: 목수·베 짜는 이웃·할아버지가 구조·천·자리 의견을 보탠다.
긴 벤치: 목수·대장장이·기름 짜는 이웃이 제작과 위치 조정에 참여한다.
안내판: 목수·편지 나르는 이웃이 동선과 표지를 손질한다.
시설은 실재하는 공간과 지형·동선·계절 그림 규칙에 맞춰 배치한다.

4. 참여와 진행
의견 듣기 → 안 선택 → 주민별 기여 확인 → 선택적인 공동 작업 → 설치 → 사용 시작.
플레이어는 재료, 짧은 손일, 위치와 색 제안 중 참여 방법을 고른다.
주민이 기여하는 재료와 작업은 고정된 실제 공급분으로 관리한다.
돈과 재료를 플레이어 혼자 모두 부담시키지 않는다.
기본 공동 시설에는 주민 기여와 대기 진행을 두고 플레이어 재료는 선택 장식과 추가 참여에 연결한다.
몇 회의 작업과 며칠에 완성되는지는 현재 경제·시간 흐름을 확인해 정한다.
마감일과 미완성 벌점은 두지 않는다.

5. 주민들의 선택
직업과 취향에 따라 원하는 개선이 다를 수 있다.
의견 차이는 조율 대화로 보여 주고 선택하지 않은 주민을 적대적으로 만들지 않는다.
참여자는 자신의 담당을 수행하고 작업 후 함께 시설을 이용한다.
플레이어가 없을 때 진행된 주민 작업은 그들의 경험으로 기록한다.

6. 완성 후 변화
마을 그림에 시설이 남고 새 상호작용과 주민 일정이 연결된다.
꽃밭에서는 계절 관찰, 그늘막에서는 휴식, 긴 벤치에서는 소규모 대화를 제공한다.
시설이 있는 장소만 01 모임과 05 행사 장소 목록에 추가한다.
04 기억에는 실제 참여자의 공동 작업을 연결한다.
시간이 지나도 무작위 파손과 반복 수리 의무로 되돌리지 않는다.
선택 장식 변경은 가능하되 주민 일정과 이동 공간을 다시 확인한다.

7. 기존 성장과 구분
기존 이웃 부탁으로 생기는 벤치·장식·시설과 같은 항목을 이중 건설하지 않는다.
이미 설치된 시설이면 개선·장식안으로 전환하거나 다른 장소를 제안한다.
서고 진행으로 잠긴 장소를 공동 작업만으로 먼저 열지 않는다.
핵심 필사 접근과 기존 길을 시설로 막지 않는다.

8. 저장과 연결
사업 ID, 위치, 선택안, 단계, 주민 기여, 플레이어 기여, 설치 상태, 선택 장식, 기억 여부.
기여와 완성 지급을 한 번만 처리하고 설치 여부를 같은 상태로 판정한다.
board.ts, bonds.ts, world.ts, decor.ts, 기존 지도 캐시·장소 메뉴·save.ts를 확인한다.
서로 다른 계절과 날씨에서도 시설 위치가 일관되게 보이도록 연결한다.

9. 구현과 확인
기존 시설과 겹치지 않는 벤치 하나로 선택·공동 작업·설치·일과까지 완성한다.
다음으로 꽃밭과 그늘막, 반복 선택과 장식 변경을 추가한다.
통행·지도 캐시·저장·기여 중복·잠긴 장소·주민 일정 충돌을 검증한다.
완성된 시설이 실제 생활에서 사용되고 참여하지 않아도 마을 생활이 막히지 않아야 한다.
