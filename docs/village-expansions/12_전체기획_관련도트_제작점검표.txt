27마을 — 전체 기획 관련 도트 제작 점검표
점검일: 2026-10-05
상태: 자산 추가 제작 제안. 이 문서 자체는 도트 제작 또는 게임 연결 완료를 뜻하지 않는다.

범위
생활 확장 01~11, 캐릭터 01~23, 캐릭터 게임 적용 계획·사건 ID 표·소모임 기획.
중복된 소모임 문서는 생활 확장 01을 기준으로 한 번만 집계.
사건 ID 표는 구체적인 완료 뒤 소품과 갈래를 확인하는 데 사용.
구현이 병행되고 있으므로 아래 판정은 점검 당시 이 작업 폴더의 자산 기준이다.
다른 작업 폴더에서 새로 만든 그림은 합치기 전에 대조해야 한다.

판정 기준
[재사용] 기존 그림을 기능에 연결하면 됨.
[보완] 기본 그림은 있으나 상태·무늬·방향·레이어·실제 소품이 부족함.
[신규] 해당 기획을 표현할 전용 자산을 이번 점검에서 확인하지 못함.
[선택] 글자·기존 UI·기존 도트 장면 조합으로 구현 가능해 필수 제작은 아님.
모든 항목에 새 PNG가 반드시 필요한 것은 아니다. 기존 코드 도트도 실제 자산이다.

1. 이미 준비된 공통 자산
[재사용] 가구 39종의 기본 및 4방향 그림. 고정 가구 방향별 자산도 있음.
  src/render/home-space-art.ts, home-space-directions.ts, remaining-furniture-art.ts
  assets/furniture/game-ready, directional, remaining
[재사용/연결 필요] 사용 모션 8종 × 4방향 × 4프레임.
  sit/drink/read/craft/knead/reach/pet/lie
  src/render/furniture-use-motion.ts, assets/furniture/use-motion
  PNG는 기본 외형 예시. 실제 인물은 함수에 현재 외형 옵션을 전달해야 함.
[재사용] 기존 인물 방향·걷기·깜빡임·숨쉬기·인사·웅크리기.
[재사용/보완] 동물 성체·새끼·웅크려 잠자기, 아기 성장 단계 그림.
  동물은 현재 좌우 기본 그림을 뒤집고 이동 시 높이를 바꾸는 방식이므로
  앞뒤 그림·다리 동작·성격별 자세는 별도 보완 대상.
[재사용/보완] 마을 벤치·꽃·차양·벌통, 화덕 불·굴뚝 연기·날씨·장식.
  decor.ts/renderer.ts의 기존 코드 그림을 재사용하고 필요한 진행 상태만 추가.
자산이 있다는 것과 게임 연결 완료는 별개다. 방향/사용 모션은 연결 확인 필요.

2. 가장 먼저 필요한 공통 제작
A. 가구 겹침 레이어 [보완, 우선]
  의자·벤치·책상·탁자·침대·작업대의 앞부분/뒷부분 분리.
  침대 이불과 베개 앞부분, 의자 앞다리, 탁자 앞면.
  캐릭터와 소품이 자연스럽게 사이에 들어가도록 방향별 제공.
B. 행동 전환 [신규, 우선]
  앉기/일어나기, 눕기/일어나기, 집기/내려놓기, 건네기/받기.
  공통 인물 틀로 제작하고 머리·옷·피부·장신구를 유지.
C. 손에 든 실제 소품 [보완, 우선]
  컵·받침·간식 접시·쟁반·물뿌리개·씨앗 꾸러미·바구니·공책·그림·실패·바늘·천.
  대패/나무 조각·차가운 고리 부품·그물·기름 용기·양털 꾸러미·배달 가방.
  현재 사용 모션의 공통 컵/책/천/갈색 상자/장난감은 활동별로 교체.
  pet은 이번 자산에서 장난감 대상 예시이므로 동물 쓰다듬기는 몸 높이·반응을 추가.
D. 작업 진행 상태 [신규 또는 보완, 우선]
  재료/작업 중/완성 3상태. 기존 완성 가구를 다시 전부 그릴 필요 없음.
  반죽→빵, 나무 부품→의자, 실→천, 부품→고리, 장난감 조각→완성.
E. 공통 전시 [신규 또는 보완]
  낮은 전시 상자·그림 걸이·공책 받침·도안판·생활 일정표·작은 이름 표지.
  생활 창작 전시는 말씀 27권 선반과 별도 자산/자리.

3. 생활 확장별 점검
01 직접 만드는 소모임
  재사용: 탁자·의자·방석·차 마시기·손일·기존 텃밭/계절 식물.
  보완: 차잔 여러 개/간식 접시, 실 색·천 무늬·공동 방석, 씨앗 정리 상자.
  신규: 물 주기·텃밭 손질·관찰 그림 그리기·작품 보여 주기 동작.
  선택: 현장 모임 표시, 활동 아이콘. 이름과 구성원은 기존 인물/UI 재사용.
  동일 동작의 시작 시각을 달리하면 군무처럼 보이는 문제를 줄일 수 있음.
02 이웃과 함께 일하는 하루
  재사용: 반죽·손일·꺼내기 모션, 기존 작업장·화덕·기름틀·양 우리·나루.
  신규/보완: 빵집 반죽/빵/진열 쟁반; 목공 부품/대패/마감;
    대장간 도안/차가운 고리; 직조 선택 무늬/가장자리;
    기름 빈/찬 용기; 포도 빈/찬 수확 바구니; 양털 분류 꾸러미;
    찻집 차 따르기/쟁반; 약방 생활 용기 표지; 나루 펼친/수선한 그물.
  공통 행동을 재사용하고 도구·작업물·손 위치만 활동별로 보완.
03 내 작은 장날 좌판
  재사용: 기존 상인·차양·생활 상품 기본 그림.
  신규: 플레이어 좌판 틀, 천 레이어, 작은 간판, 3개 진열 자리,
    포장 묶음, 접힌/개점/마감 상태, 상품을 건네고 받는 동작.
  보완: 향초·직물·고리·장난감 등의 지도용 작은 진열 그림과 가방용 아이콘.
  선택: 거래 완료 표시는 기존 UI로 가능. 숫자 재고는 그림에 굽지 말 것.
04 관계의 추억과 생활 취향
  재사용: 인물·장소·작품 도트와 실제 공동 장면.
  선택: 기억/취향 작은 아이콘과 수첩 장식.
  새 장면 그림을 기억마다 한 장씩 제작할 필요 없음. 기존 도트를 조합한 썸네일 권장.
  실제 머리·옷·참여자·선택 물건을 반영하고 고정 가족 초상으로 대체하지 않기.
05 내가 준비하는 작은 행사
  재사용: 모임 자리·찻잔·기존 계절 잔치 장식/불/음식 자산.
  신규/보완: 간식 나눔 쟁반·음식 접시·차받침, 고른 행사 천,
    작품 소개 받침·초대 표지, 준비/진행/정리 상태.
  신규: 음식 놓기·차 따르기·장식 걸기·작품 보여 주기·정리하기.
  생일은 기존 생일 표현과 대조하고 별도 현대식 케이크를 필수로 추가하지 않음.
06 반려동물의 성격과 습관
  재사용: 고양이/강아지 기본·새끼·웅크려 잠자기, 기존 방석.
  보완: 앞/뒤 모습과 실제 다리 걷기, 앉아 기다리기, 냄새 맡기,
    고개 돌리기·꼬리 흔들기·앞발 놀이·장난감 물고 오기.
  신규/보완: 작은 장난감·담요, 기존 창가의 사용 가능한 자리 표현.
  동물 돌봄용 사람 손 동작과 동물의 몸 높이를 맞춤. 성체/새끼 각각 확인.
  새 먹기 모션은 실제 식사 시스템의 지원 여부를 확인한 뒤 선택 제작.
07 주민이 함께 바꾸는 마을
  재사용: 기존 벤치·꽃·차양·게시판·주민.
  보완: 공동 시설용 긴 벤치·그늘막·꽃밭 경계·안내판, 선택 색/장식.
  신규: 공사 전 재료 묶음·조립 중 프레임·설치 완료 상태,
    나무/천 운반·설치·물 주기 동작.
  꽃밭·차양을 기존 해금 시설과 중복 건설하는 그림은 피함.
08 아이의 첫 경험과 가족 기억
  재사용: 성장 단계·요람·기존 가족 활동/장난감/생일 기록.
  보완: 성장 단계별 앉기·안전한 만들기·그림 그리기·장난감 들기·보여 주기.
  신규/보완: 배 모양 장난감·아이 선택 무늬 천·가족 화분·그림·작품 전시 받침.
  선택: 앨범 표지·경험 아이콘. 장면은 실제 가족과 자산을 조합해 썸네일 생성.
  모든 배우자×모든 가족 구성을 고정 그림으로 만들지 않음.
09 집 안 공간별 쓰임
  재사용: 현재 가구와 8가지 모션이 가장 직접적으로 쓰임.
  우선 보완: A 가구 전후 레이어, B 전환 동작, 어린이·동물 높이.
  신규/보완: 차자리 쟁반·손일 도구·가족 그림·동물 담요.
  선택: 차/손일/휴식/동물/독서 자리 표시. 꾸미기 중에만 표시해도 됨.
10 주민들의 작은 근황
  재사용: 기존 인물·걷기·휴식·가구·작업 모션.
  보완: 새 빵 진열·천 색 변경·바구니 정리·수선 가방·점심 접시·관찰 그림.
  별도 근황 전용 캐릭터 시트를 전부 만들지 않고 다른 기능 자산 재사용.
11 이웃에게 배우는 생활 기술
  재사용: 공동 작업의 도구·시범 동작·진행 상태.
  신규/보완: 가구 마감·천 무늬/테두리·간식 모양·장식 고리 형태·향초 용기 장식·식물 지지대.
  색만 다르면 팔레트 치환, 모양/무늬가 다르면 별도 픽셀 템플릿.
  선택: 배운 기술 아이콘. 해금된 결과의 실제 모습은 필수, 경험치 그림은 불필요.

이름·날짜·일정·간판 문구는 UI에서 실제 데이터로 표시. 작은 도트에 글자를 고정하지 않는다.
모든 단계/선택 결과 그림은 해당 실제 사건 상태가 있을 때만 표시.

5. 제작 묶음과 추천 순서
1순위: 가구 전후 레이어 + 앉기/일어나기·눕기/일어나기 + 실제 컵/쟁반/공책/작업 도구.
2순위: 공동 작업의 재료·작업 중·완성 + 개인 이야기 23명의 영구 소품.
3순위: 좌판·상품 진열·판매 전달 + 모임/행사 준비 소품.
4순위: 동물 자세/놀이 + 어린이 전용 동작/작품.
5순위: 공동 시설 공사 상태 + 기술별 무늬/마감/형태 + 선택 UI 아이콘.
구현이 이미 진행된 기능은 위 순위보다 실제로 연결 가능한 항목을 먼저 제작.
정확한 신규 개수는 구현된 상품 종류·선택 갈래·전시 위치 확정 뒤 정함.

6. 실제 사용 가능한 납품 기준
원본 16px 타일 격자·기존 팔레트·정수 픽셀·투명 PNG·nearest-neighbor.
방향을 쓰는 가구/인물/착용 소품: 앞뒤좌우. 세워진 가구를 이미지 회전으로 대체하지 않음.
무늬/상품 작은 아이콘: 기존 8×8 규격과 실제 지도 그림을 각각 제공.
손 소품: 뒤/앞 레이어, 캐릭터 외형 팔레트와 분리.
manifest: 자산 ID·연결 기능/사건·방향·프레임 시간·캔버스 크기·기준점·겹침 순서.
아이·성체/새끼 동물·다양한 옷/머리, 책상/침대 높이, 4방향 겹침을 실제 화면에서 검수.
모임·좌판·공동 시설은 실제 장소 크기에 맞춤. 휴대폰에서도 구분 가능해야 함.
본문·말씀 조각·필사본을 판매/작업 재료/생활 창작 소품으로 바꾸지 않음.

결론
현재 기본 가구와 공통 모션은 출발점이다. 전체 기획을 화면으로 완성하려면
작업 상태·선택 결과·전시 소품·개인 사건의 남는 변화·동물/아이 동작을 보완해야 한다.
재사용 가능한 도트는 다시 그리지 않고, 위 목록을 기능 담당자의 실제 구현과 대조해 제작한다.
