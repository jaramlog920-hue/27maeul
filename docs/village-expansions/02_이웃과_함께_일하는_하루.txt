27마을 — 이웃과 함께 일하는 하루
작성일: 2026-10-05 / 상태: 미구현 기획
참고 요소: 직접 작업장에 참여하는 직업 플레이.

1. 목표
이웃의 부탁 하나를 처리하는 경험을 준비·작업·마무리로 이어지는 짧은 하루로 확장한다.
주민의 기술과 성격을 실제 행동으로 보여 주고 결과가 작업장과 기억에 남는다.
현재 의뢰·공방·손일 미니게임을 활용하며 다른 생업과 필사는 그대로 선택할 수 있다.

2. 시작과 참여
이웃과 대화하거나 작업장 안내를 통해 “오늘 함께 일하기”를 선택한다.
작업 내용, 예상 시간, 준비물, 수고비나 결과물을 먼저 안내한다.
주민이 실제 근무 중이고 기존 사건과 충돌하지 않는 시간에만 시작한다.
낯선 작업은 기본 단계부터 참여할 수 있고 높은 친밀도나 기술을 요구하지 않는다.
한 작업은 게임 시간 약 두 시간 안에서 진행하도록 제안한다.

3. 플레이 흐름
준비: 주민이 오늘 할 일을 설명하고 플레이어가 맡을 부분을 고른다.
작업: 2~3개의 짧은 행동과 선택으로 진행한다. 적합한 기존 미니게임을 재사용한다.
마무리: 결과를 함께 확인하고 진열·정리·인계한다.
이후: 작업한 흔적이 남고 해당 주민이 관련 상황에서 경험을 떠올린다.
각 단계를 시간 경쟁으로 만들지 않으며 늦거나 서툴러도 다시 시도하거나 마무리할 수 있다.

4. 작업장별 구성
빵집: 반죽 모양 선택 → 안전한 손일 → 빵 진열. 화덕의 위험 작업은 주민이 맡는다.
목수 집: 재료와 모양 선택 → 안전한 다듬기 → 마감. 구조 작업은 목수가 맡는다.
대장간: 고리 도안 → 차가운 부품 손질 → 완성품 확인. 뜨거운 쇠는 주민이 다룬다.
베 짜는 집: 색 고르기 → 작은 짜기 → 가장자리 마감. 선택한 무늬를 결과에 남긴다.
기름틀: 용기 준비 → 기존 기름틀 작업 → 보관 정리. 실제 재료와 생산 수량을 맞춘다.
포도원: 상태 살피기 → 수확 또는 바구니 정리 → 공동 마무리. 계절에 맞는 작업을 제공한다.
양 우리: 도구 정리 → 양털 분류 → 보관. 동물 돌봄을 우선하고 실종 사건은 추가하지 않는다.
찻집: 찻잔과 간식 선택 → 차 준비 → 손님 자리 정리. 건강 효과는 단정하지 않는다.
약방: 생활 용기·표지·선반 정리만 다룬다. 진단·치료를 게임 작업으로 만들지 않는다.
나루: 그물 손질 → 도구 보관 → 작은 손일. 현재 날씨와 장소 접근 조건을 따른다.

5. 주민의 차이
목수는 실물과 손짓으로 설명하고 틸리는 작업 횟수를 세며 웬델은 진열 취향을 묻는다.
페넬로피는 색 비교 시간을 갖고 바질은 다른 사람에게 역할을 맡기는 경험도 한다.
친구·연인·배우자에 따라 대사는 달라지지만 작업 접근을 연애로 제한하지 않는다.
공동 작업 경험은 04 기억 구조에 연결한다.

6. 재료와 보상
가게 일을 돕는 기본 작업 재료는 작업장 공급분으로 처리한다.
플레이어 개인 물건을 제작하는 선택 활동만 개인 재료를 사전에 안내한다.
가게 재료를 가방에 가져가거나 중단·재시작으로 결과를 중복 받지 못하게 한다.
수고비와 결과물은 현재 생업 수입을 기준으로 조정하고 대량 돈벌이 수단으로 만들지 않는다.
직접 만든 생활 상품은 03 좌판에서 판매할 수 있으나 가게 소유 제품은 자동으로 개인 소유가 되지 않는다.
완료 경험과 생활 변화는 숙련 경쟁보다 중요하게 다룬다.

7. 중단과 일정
중간에 나가면 완료한 단계까지만 저장하고 그날 주민 일정 안에서 이어갈 수 있다.
다음 날로 넘어가면 해당 회차는 정리하고 소모 재료·부분 보상 규칙을 분명히 적용한다.
이미 처리한 단계와 결과는 다시 지급하지 않는다.
주민의 공동 모임·행사·특별 사건과 겹치면 시작 전에 다른 시간이나 작업을 안내한다.

8. 화면과 저장
작업장 메뉴 → 작업 안내 → 단계별 짧은 활동 → 결과 화면.
화면에는 현재 단계, 맡은 일, 필요한 선택만 표시한다.
저장: 작업 회차 ID, 주민, 시작일, 단계, 선택, 재료 소유와 소비, 완료와 지급 여부.
연결 후보: job.ts, requests.ts, minigame.ts, people.ts, 기존 사건과 가방·돈 구조.
구체적인 수정 위치는 구현 전 확인한다.

9. 구현과 확인
목수 또는 빵집 하나로 전체 흐름을 완성한 뒤 작업장별 내용을 확장한다.
기존 의뢰와 이중 보상되지 않는지, 저장 후 이어가기와 중단 후 결과가 맞는지 확인한다.
주민 근무·날씨·계절과 작업이 일치하고 선택한 결과가 실제 진열이나 소품으로 남아야 한다.
휴대폰에서 짧게 참여할 수 있고 작업을 하지 않아도 다른 생활과 필사가 가능해야 한다.
