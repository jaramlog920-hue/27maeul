# 기능별 순차 버그 검사

사용자 요청: 시간을 정해 한 번에 훑지 않고, 기능 하나를 코드 → 재현 검사 → 수정 → 회귀 검사 순서로 확인한 뒤 다음 기능으로 진행한다.
기존 변경은 보존한다. 사용자 저장을 초기화하지 않는다. 배포는 별도 요청 시에만 한다.
2026-10-11 최신 사용자 지시: 이제부터 버그는 검사·재현·기록만 한다. 실행 코드·콘텐츠·설정·시험 파일은 수정하지 않는다. 이전에 완료한 수정은 되돌리지 않는다.
테스트 통과를 전체 게임 무결함 또는 브라우저 자연 플레이 완료로 표현하지 않는다.

## 검사 방식

- 정상 진행뿐 아니라 중단·재개·재접속·중복 입력·시간 경계·지도 전환·재료 부족·해금 조건을 확인한다.
- 정상 게임에서 가능한 상태 전환과 잘못된 저장 방어를 구분한다.
- 버그는 가능한 한 수정 전 실패하는 재현 검사로 확인하고, 수정 후 같은 검사를 다시 실행한다.
- 기능별 실제 검사 파일·재현 내용·남은 확인 항목을 기록한다.
