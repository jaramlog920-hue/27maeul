# NPC 가구 사용·호감도·돕기·지도 수정 (2026-10-15)

## 적용 범위

- 유저는 자율 가구 행동에 등록하지 않는다. 이동·가구 사용은 직접 조작으로만 한다. 새 자율 대기 동작도 시작하지 않으며, 눈 깜박임/호흡과 직접 입력한 인사·기상 동작은 유지한다.
- 집에 둔 자녀와 여유 있는 NPC는 모션이 등록된 가구를 고르고, 접근 칸까지 걸어간 뒤 사용한다. 가구와 접근 칸을 예약해 동시 점유를 방지한다.
- 기존 생활 가구 전용 11개 모션, 수납 여닫기, 기본 앉기/읽기/차/손일, 새 유아·어린이 가구의 사용 모션을 같은 자율행동 경로에 연결했다. 나이와 상태에 맞는 가구만 선택한다.
- 학교·동행·대화·행사·이야기·특별 일과를 우선한다. 귀가 인사를 마친 배우자는 집에서 가구를 쓸 수 있다. 출입구와 작업대 앞은 지나갈 수 있지만 사용 중 서 있는 칸으로 점유하지 않는다.
- 가구 이동·회전·철거, 접근 차단, NPC가 자유 시간을 마친 경우에는 사용을 취소한다. 자율행동은 저장하지 않으며 보상·소지품·호감도·추가 시간 소모를 만들지 않는다.
- 실제 아이/주민 외형으로 공용 모션을 그린다. 서서 하는 공용 동작은 다리를 접지 않고 컵·물건을 얼굴 아래에 둔다.

## 나머지 수정

- NPC 자율 관계 기능이 해금되기 전(현재 기준 신약 75장 이전)에는 NPC끼리의 만남과 모임에서 오르는 호감도를 기존의 **1/5**로 적용한다. 해금 후에는 기존 상승량을 적용한다. 유저와 NPC 사이의 호감도는 바꾸지 않는다.
- 소수점 호감도를 저장/복원하고, 해금 시 기존 수치를 재설정하거나 소급 증폭하지 않는다.
- 화면 이름 **웬델**은 내부 ID `poppy`인 찻집 주민이다. 해당 주민의 일반 돕기를 찻잔 정리 손일과 약초차 1개 보상으로 바꾸었다. 파피(`wendell`)의 빵집 보상은 보존했다. 아이콘/수첩/하루 기록도 실제 보상에서 자동 연결된다.
- 지도 나루/벌통 설명을 실제 구역 조건인 신약 4권/6권에 맞추었다. 사도행전 완필 조건으로 나루 개방을 설명하지 않는다. 열린 벌통에도 설명을 볼 수 있는 위치 표시를 추가했다.
- 지도 하단의 “건물·장소를 누르면 설명” 문구를 삭제했다. 설명 버튼은 유지한다.

## 배포 상태

로컬 Vite/PWA 빌드는 완료했다. 연결된 `27maeul` 프로젝트에 대한 Vercel API 확인은 **403 권한 없음**으로 실패했다. 같은 팀/프로젝트에 대한 로컬 CLI 대체 경로도 실행/네트워크 제한(`spawn EPERM`, 프록시 연결 거부)으로 실패했다. 다른 팀으로 배포하거나 보호 설정을 바꾸지 않았다. 실제 배포는 프로젝트 접근 권한이 있는 Vercel 연결에서 이어가야 한다.
