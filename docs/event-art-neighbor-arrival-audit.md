# 새 이웃 이사 배경별 잔여 전체 검증

약방·목공방·베틀 이사 소개의 각 배경 잔여 전체3개(movedIn:apothecary·movedIn:carpenter·movedIn:weaver)를 계획 순서대로 모두 완료. 약방은 기존 붉은 기와·차양·약초 화분 앞에서 이사 짐과 세이지 인사, 목공은 기존 공방 창·공구와 표지용 판자·짐 옆 아서 인사, 베틀은 기존 날실·작업 천·실 바구니와 새 실패 짐을 둔 방에서 아이리스 입장→인사를 그린다. 아침 이벤트 큐의 실제 게임 위치는 그대로 두는 장소 소개 컷이며 약초 가격/매입·책장 선물·베틀 장비/가리개 해금·보상·시간을 추가하지 않는다. 실제 이웃 및 다음 세대 외형을 기존 해결기로 읽고 네 원문 행 전체, 시작0/.35/.6/.8/8초, 기본·실제 사용자, 가로·세로·휴대폰·썸네일에서 얼굴/몸/짧은 손/발과 소품 배치를 확인했다. 실제 ModalLayer 원문·미리보기/썸네일/모음과 저장/앨범 불변, 몸 전체 가림 및 약방·이사/잔치·기존 초대 회귀를 포함한7파일1,957검사와 사전검사·TypeScript·전체 Vite/PWA 빌드 통과. 이사 조건 목공1권·약방2권·베틀7권 및 원래 엔진 처리는 보존했다. 실제558개 연결/118개 미제작. 다음: 동쪽 큰길 표지 배경 잔여 전체(east-road).

세 배경은 각각1개씩 남아 있던 전체이며 임의 개수 제한이 아니다. 원문 및 기존 각 배경 사건은 보존하고 이사 소개4행만 새로 그렸다.

React 검토: hooks/RAF cleanup/기존 원문 UI·버튼 유지, 새 상태 쓰기·게임 이동·저장·앨범 생성 없음. 같은 렌더러를 실제 대화·미리보기·썸네일에 등록했다.
