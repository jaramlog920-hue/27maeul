개역한글 구약 39권 929장을 책별 파일 `src/content/ot/<id>.json`(장 → 절 배열 `string[][]`, 신약 `bible-subset.json`과 같은 모양)로 둔다. 모든 수치는 `node scripts/verify-ot.mjs --stats`와 `npm run build`로 **측정한 값**이다 (2026-10-06).

## 만들기와 검증

- 원본: `jaramlog-v2/public/bible/krv/<순번 1..39>/<장>.json` (`{"v":[[절,본문],…]}`). 환경 변수 `KRV_DIR`로 위치를 바꾼다.
- 만들기: `npm run build:ot` (`scripts/build-ot.mjs`). 책 표는 `src/engine/ot-books.ts`의 `OT_BOOK_TABLE`. 절 번호가 1부터 빠짐없이 이어지지 않거나 장 수가 표와 다르면(표보다 많아도) 아무것도 쓰지 않고 실패한다. 글자는 고치지 않는다.
- 검증: `node scripts/verify-ot.mjs` (`npm run verify`·`prebuild`에 들어 있음). 39파일 존재, 장 수, 빈 절·제어 문자·태그·앞뒤 공백 없음, 가장 긴 절 < `DRAFT_MAX`(copying.ts, 600), 창 1:3 고정 대조, `KRV_DIR`가 있으면 원본과 글자까지 같음(없으면 "원본 비교 생략"을 출력).
- 역방향 픽스처: `scripts/verify-ot.test.ts` — 장 삭제·절 빠짐·글자 바꿈·빈 절 등이 실제로 걸린다.
