# 유저·반려동물 통과

2026-10-17: 유저와 동물이 닿을 때 동물이 튕기듯 움직이는 현상을 수정했다.

원인: 집에 두기 동물의 매 tick 점유 목록에 유저 칸이 들어 있었고, 동물의 현재 칸이 점유됐다고 판단되면 목표로 즉시 위치를 옮겼다. 유저가 동물 칸으로 이동하는 것 자체는 원래 막지 않았다.

변경: 동물의 자리/경로 점유 판정에서 유저 칸만 제외했다. 렌더러의 동물 가구 사용 판정 두 곳도 같은 규칙으로 맞춰, 통과 순간 이용 중인 가구나 모션이 사라지지 않게 했다. 벽·고정 가구·NPC 회피와 문/지도 이동 시 동물 동행은 유지한다. 동물을 눌러 상호작용하는 기능도 유지한다.

검증: 고양이·강아지 각각 유저와 같은 칸에서 10 tick 안정 유지, 동물 칸으로 걷기→겹침→반대편으로 나가기 회귀 검사. 반려동물 습관·가구·동행·새 터 관련 5개 파일 55개 검사, TypeScript·전체 콘텐츠 verify·Vite/PWA 빌드 통과. 실제 브라우저 확인은 기존 접근 정책 제한으로 수행하지 못했다.
