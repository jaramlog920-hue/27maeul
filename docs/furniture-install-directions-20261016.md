# 가구 설치 방향 연결 수정

사용자: 네 방향을 만들었는데 설치할 때 방향이 적용되지 않음.

확인된 문제와 변경:
- 설치 경로는 항상 `placement(..., undefined, ...)`를 호출했고, 꾸미기에서 놓기 전 방향을 고를 UI나 상태가 없었다. 놓고 나서 회전하는 경로만 있었다.
- 저장하지 않는 UI 상태 `decorFacing` 및 설치 전 아래/오른쪽/위/왼쪽 선택·실제 원본 도트 미리보기를 추가했다. `placeFurniture`에 선택 방향을 전달해 방향에 따른 점유 칸·겹침·벽·통로를 설치 시점부터 검사한다. 기본 방향은 기존 `facingOf`를 따른다. 이동과 기존 회전·취소·가방 소비 규칙을 유지한다.
- 서늘한 찬장은 `COOL_CUPBOARD`에 네 방향이 있었지만 `hasFacingArt`에서 빠져 회전 단추가 없었다. 기존 원본을 연결했다. 찬장의 시각 높이(두 칸)와 실제 점유 칸(한 칸)은 기존 렌더러 규칙 그대로다.
- 집 선반은 앞면 원본만 기본 경로에 연결돼 있었다. 앞면은 그대로 보존하고 같은 가구 계열의 뒷면/측면을 연결했다.
- 배우자 방에서 가져온 가구의 방향 조회가 기본 가구 원본의 일부만 탐색하던 경로도 넓혔다.
- 벽걸이는 기존 부착 방향을 유지하며, 탁자 위 물건·벽·통로로 회전이 막힐 때는 기존 배치 안전 규칙을 유지한다.

원본 상태의 한계: 배우자 고유 가구 중 31개 배치 항목은 `SPOUSE_ROOM_ART` 단일 앞면만 있으며 `SPOUSE_ROOM_VIEWS`에도 다른 방향 원본이 없다. 실제 assets에도 해당 signature/personal/keepsake의 up/left/right 원본이 없었다. 이들을 같은 그림 네 장으로 연결해 완성으로 처리하지 않았다. 현재 수정은 존재하는 네 방향 원본을 빠짐없이 설치에 연결하는 범위이며, 단일 원본 고유 가구의 새 도트 제작은 남아 있다.

검증: 설치 전 오른쪽 선택 → 미리보기 16×32 → 경계 밖 설치 거부·가방 보존 → 유효한 위치에 세로 배치 → 저장/불러오기 방향 보존 검사. 선반/서늘한 찬장 네 방향 선택 UI 검사. 네 방향 원본이 있는 집/배우자 가구 목록 연결 검사. 배치·이동·가구·성장·도감 등 8개 파일 72개 테스트 통과. TypeScript·전체 콘텐츠 검증·Vite/PWA 빌드 통과. React Best Practices의 상태·효과 의존성·컴포넌트·선택 상태 접근성 확인. 브라우저 시각 확인은 기존 저장된 브라우저 접근 정책 제한 때문에 수행하지 못했다.
