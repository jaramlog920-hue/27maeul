# 구약 마을과 주민 세대 도트

작성: 2026-10-06. 계획 18·19의 자산 준비이며 게임 기능 연결은 별도다.

## 추가 배경 소재의 용도 — 2026-10-07 사용자 확정

`assets/background-materials-simple.png`는 **유저가 새 터(구약 맵)를 직접 꾸밀 때 선택해서 놓는 추가 요소**의 시안이다. 길 소재는 유저가 길을 꾸미는 선택지로 추가한다. **구약 맵에 원래 깔려 있는 기본 길 자체를 바꾸거나 기존 길 그림을 일괄 교체하는 용도가 아니다.** 나무·바닥 등도 같은 꾸미기 소재 범위다.

현재는 소재 시안만 저장되어 있으며 게임 기능에는 연결되지 않았다. 적용할 때 기본 맵 지형과 유저가 배치한 꾸미기 요소를 구분한다. 자세한 안내: [배경 소재 사용 범위](../assets/background-materials-usage.md).

## 기존 구약 마을·주민 세대 자산

- 원본: `src/render/old-village-art.ts`, `src/render/generation-art.ts`
- 내보내기: `node scripts/export-old-village-art.mjs`
- 결과: `assets/old-testament-generations/`
- 미리보기: 위 폴더의 `미리보기.html`
- 좌표·분리 레이어·프레임 정보: `manifest.json`
- 사용 규칙/재사용/남은 범위: `도트_목록과_연결안내.txt`

정지 그림 267개: 소품 24, 직업 표식 10, 지형/자연 10, 건물 25종의 4방향 100, 공통 공사 골격 적용 100, 내부 배치 원안 23.
동작 168시퀀스: 성장 20, 가족 행동 136, 성인+아이 배치 12. 각 4프레임.
분리 레이어를 포함한 PNG 파일은 2,971개다. 이는 고유 물건 종류 수가 아니다.

현재 자식 직업 16종에 대응하는 일터가 모두 포함된다. 건물 양식은 공통으로 재사용하고 직업 표식/일부 창과 굴뚝을 달리했다.
주민 생성 외형은 기존 외형 시스템을 쓰고, 가족 모션의 실제 인물은 함수에 해당 주민의 외형을 전달한다.
새 주민의 이름·꿈·선물이 확정되기 전에는 해당 고유 자산을 최종 제작 완료로 처리하지 않는다.

전용 검사 4개 통과, PNG 내보내기 검사와 건물·성장·함께하는 장면의 미리보기 확인.
공유 작업 폴더의 다른 진행 중인 기능에서 발생하는 오류 때문에 전체 TypeScript 검사는 현재 통과하지 못했다. 이번 자산에서 보고된 타입 오류는 없었으며 전체 빌드 성공으로 표시하지 않는다.
