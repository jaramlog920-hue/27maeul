# 제작·두루마리·창가 도트 후속

2026-10-08 사용자 요청: 종이/실/잉크 제작, 도예, 악기 제작, 약초 손질, 두루마리, 커튼/창문 동작을 모두 준비. **자산만 제작했으며 게임 연결은 하지 않았다.**

## 준비한 것

| 묶음 | 동작 |
|---|---|
| 제작 재료 | 파피루스 펴기, 종이 누르기, 작은 방추로 실 자아내기, 잉크 섞기 |
| 도예 | 진흙 주무르기, 그릇 모양 잡기, 완성 그릇 내려놓기 |
| 악기 제작 | 나무 몸통 손질, 줄 매기, 줄 튕겨 확인하기 |
| 약초 손질 | 잎 고르기, 절구로 빻기, 병에 담기 |
| 두루마리 | 펼치기, 말기, 끈 묶기 |
| 창가 | 하늘빛/풀빛/장밋빛 커튼 열기·닫기, 창문 빗장 풀고 열기·닫고 빗장 걸기 |

인물 16동작 × 4방향 × 4프레임: 합성 PNG 256장 + 뒤 소품/인물/앞 소품 768장. 커튼 3색 × 2동작 × 4프레임 24장, 창문 2동작 × 4프레임 8장. 개별 PNG 1,056장과 도감 1장.

## 연결용 API

원본: `src/render/craft-followup-art.ts`.

- `craftFollowupFrame(action, facing, frame, avatar)`.
- `CRAFT_GROUPS`와 `CRAFT_ACTIONS`에 16개 동작 ID, `CRAFT_LABELS`에 한글 이름.
- 반환: 32×32 `actor`, `propBack`, `propFront`, 인물 `palette`, 발 기준 `anchor`, `duration`, `loop`.
- 뒤 소품 → 인물 → 앞 소품 순서. 소품은 `CRAFT_PALETTE`, 인물은 반환된 `palette`. 실제 `FullAvatar`를 마지막 인수에 넣으면 피부·머리·옷을 유지한다. 기본값은 미리보기용 예시 모습이다.
- 기존 `workDetailFrame`의 작업 자세만 재사용하고 해당 작업의 손과 도구/작업물은 새로 그렸다. 왼쪽은 오른쪽을 한 번 뒤집는다.
- 실 자아내기·잉크 섞기·진흙 주무르기·몸통 손질·줄 튕기기·절구 빻기는 반복 동작. 나머지는 단발이며 끝 자세에서 멈춘다.
- 파피루스가 펼쳐지고, 진흙은 그릇 높이가 생기고, 악기에는 줄이 늘어나고, 약초는 병에 담긴다. 작업별 단계가 구별되는 원안이다. 조리/약품 효능/새 제작 규칙은 추가하지 않았다.
- 작업대 받침이 소품 레이어에 포함되어 있다. 기존 가구 위에 연결할 때에는 받침을 중복으로 올리지 않도록 작업물만 분리해서 사용해야 한다.

### 두루마리

`unroll`과 `roll`의 소품 레이어는 정확히 역순이다. 펼친 줄은 문자가 아니라 종이의 짧은 결을 표현한 것이다. 성경 본문이나 가상의 구절을 도트에 넣지 않았다. `tieScroll`은 말린 두루마리에 천 끈을 묶는다.

### 커튼·창문

- `curtainRows(color, 'open'|'close', frame)`: 32×16. color는 sky/sage/rose. 기존 커튼의 2칸 가로대와 양옆 6px 열린 천 형태에 맞췄다. 닫힌 천이 네 단계로 양옆에 모인다.
- `windowRows('open'|'close', frame)`: 32×32. 빗장을 움직이고 양옆 창짝을 좁혀 열린 틈을 보여 준다. 창틀·창턱은 고정이다.
- 두 함수는 `WINDOW_PALETTE`를 사용한다. 열기와 닫기는 정확히 역순, 반복하지 않는다.
- 커튼과 창문은 벽에 거는 **정면 자산**이다. 인물 동작과 달리 4방향을 제공하지 않는다. 실제 방의 창문 위치나 가구 ID에 연결하지 않았다.

## 파일과 미리보기

- 내보내기: `node scripts/export-craft-followup.mjs`.
- `assets/craft-followup/manifest.json`: `connected: false`, 분류별 방향·프레임·크기·레이어·시간·앵커·반복 여부·팔레트.
- `assets/craft-followup/preview.html`: 분류 필터, 방향 선택, 재생/정지, 단발 동작 다시 보기.
- `assets/craft-followup/contact-sheet.png`: 위 4줄은 왼쪽부터 파피루스/종이/실/잉크, 진흙/성형/그릇 내려놓기/악기 몸통, 악기 줄/튕기기/잎 고르기/절구, 병 담기/두루마리 펼치기/말기/묶기. 아래는 3색 커튼 열린/닫힌 끝 자세, 창문 열린/닫힌 끝 자세.

## 검증

- 내보내기 성공, 도감 PNG 육안 확인.
- `npx tsc -b`: 통과.
- `npm test -- --reporter=dot src/render/craft-followup-art.test.ts`: 4테스트 통과. 모든 작업물의 실제 프레임 변화, 방향·크기·색·앵커, 인물 외형 교체, 두루마리 역순, 커튼/창문 역순과 고정 받침 검사.
- 게임 렌더러·엔진·일과·제작 레시피·직업·아이템·가구·저장·기존 자산 원본은 수정하지 않았다. 신규 모듈은 앱에서 import하지 않는다.
- 게임 연결·브라우저 확인·커밋·배포 없음.
