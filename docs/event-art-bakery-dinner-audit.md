# 빵집 실내 잔여 저녁 초대 전체 검증

빵집 실내 배경의 남은 전체(dinner:baker) 완료. 이미 연결된 빵집 사건을 다시 만들지 않고 유일한 잔여 저녁 초대2행을 같은 창·밀가루 선반·준비대 배경으로 연결했다. 플레이어와 실제 baker는 식탁 양옆에 몸통·짧은 손·발이 모두 보이게 앉고 수프 두 그릇의 김, 식탁 밑 열린 다리 사이에서 노는 공용 유저 아기 도트 전체를 그린다. 실제 가구의 아기 외형을 읽으며 이미 성장한 고정 자녀를 아기로 바꾸지 않는다. 원문에 있는 아기를 그릴 때 가족 자료가 없으면 baker 외형의 공용 아기 팔레트를 쓰고 이름·다른 부모를 만들지 않는다. 모든 대사와 동작0/.35/.7/1.2/8초를 기본/실제 외형, 가로·휴대폰·썸네일에서 확인했다. 미리보기 저장·앨범 불변, 실제 ModalLayer·초대 조건·아기 성장 회귀와 사람/아기 몸 전체 가림을 포함한6파일1,873검사 및 사전검사·TypeScript·전체 Vite/PWA 빌드 통과. 원래 초대 시간18시–20시30분·90분 경과·배고픔60감소·호감도·그날 식사 제한은 엔진 수정 없이 보존했다. 실제555개 연결/121개 미제작. 다음: 약방 이사 배경 잔여 전체(arrival-herb).

새 단위는 이 배경에 실제 남아 있던1개 전체이며 개수 제한이 아니다. 기존14개 빵집 그림과 앞선 완성 장면은 보존했다.

React 검토: 기존 hooks/RAF cleanup 유지, 새 상태 쓰기나 저장·앨범 생성 없음, 기존 이웃·세대 외형 해결기와 아기 가족 읽기 경로 재사용, 버튼과 원문 UI 보존.
