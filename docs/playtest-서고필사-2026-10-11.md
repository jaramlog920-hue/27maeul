# 27마을 서고·필사 중후반 점검 — 2026-10-11 (2번 창)

요청: 서고·필사 영역을 중후반까지 플레이하며 버그 찾기. 대상은 필사 방식 셋, 제본·표지, 서고 퀴즈 전 종류, 편지 빈칸, 사도행전 여정 카드, 일곱 교회, 27권 잔치. 소스는 고치지 않았다.

방법:
- 개발 서버 5183(저장 따로). 새로 시작해 68일째까지 게임 동작으로 진행했다.
- 신약 27권을 모두 책상의 `copyType`으로 한 절씩 필사했다(화면 입력과 같은 길). 낱말 조각 절 하나는 화면 단추를 눌러 풀었다.

- 여정 판·일곱 교회 판은 ▲▼(`moveBoard`·화면 단추)으로 맞췄다. 일곱 교회 판은 화면 단추로 했다.

## 확인된 버그

### 1. 여정 판: 같은 이름 카드 둘만 자리가 바뀌면, 이름 순서가 정답과 똑같아 보여도 "어긋났다"고 함 — 중간
- 재현:
  1. 사도행전 28장을 필사해 카드 46장을 받는다.
  2. 여정 판에서 ▲▼로 이름을 본문 순서대로 맞추되, 예루살렘 #1(`행 1:12`)과 #4(`행 9:26`)만 서로 자리를 바꿔 둔다.
  3. 화면 이름 줄이 정답과 글자까지 같은데, "차례 확인"을 누르면 "차례가 어긋난 카드가 있어요."가 나온다.
- 원인: `src/engine/journey.ts`의 `boardInOrder`·`journeyComplete`가 카드 번호(order)만 본다.
- 같은 이름이 여러 번 나오는 것 자체는 설계다(plan-5 "새로 가는 자리마다 한 장"). 판에는 예루살렘 4·안디옥 5·가이사랴 3장, 다소·더베·에베소·드로아가 2장씩 있다.
- 카드를 눌러 구절을 보면 구분은 되지만, 어느 카드가 틀렸는지는 알려 주지 않는다.
- 고칠 방향: 완성 판정을 "판의 이름(place) 줄이 본문 순서의 이름 줄과 같으면 완성"으로 바꾼다. 아니면 같은 이름 카드에 장 같은 작은 구분을 붙인다. 일곱 교회 판은 이름이 겹치지 않아 해당 없다.

### 2. 이사 선물로 다른 사람의 '배우자 방 가구'가 가방에 들어옴 — 중간 (내 영역 밖이지만 플레이 중 발견)
- 재현: 결혼하지 않은 채(집 0단계) 68일째까지 지냈다. 가방에 `spouse:cosmo:0`·`spouse:poppy:4`·`spouse:penelope:3`가 들어 있었다.
- `game.moveInGifts` 기록상 출처는 이사 선물이다: 코스모 → `spouse:cosmo:0`, 루디 → `spouse:poppy:4`, 아이리스 → `spouse:penelope:3`.
- 원인: `src/engine/collection-gifts.ts`(커밋 안 된 새 파일)의 `COLLECTIBLE_ITEMS`가 `Object.keys(FURNITURE_DEFS)`를 쓴다. `furniture-defs.ts`가 불러올 때 배우자 방 가구 53종을 `FURNITURE_DEFS`에 넣으므로, 선물 후보 145개 중 53개가 배우자 가구다(`farewell` 선물도 같은 목록).
- 고칠 방향: `COLLECTIBLE_ITEMS`에서 `spouse:`로 시작하는 것을 빼고, `save.ts`의 `moveInGifts` 정리에서도 거른다. 이미 받은 저장은 같은 정리 때 다른 물건으로 바꿀지 결정해야 한다.

### 3. 서고 퀴즈 빈칸(복음서·사도행전·요한계시록): 끝말만 보고 답이 보임 — 낮음
- 예: 사도행전 꽂기 퀴즈 `행 22:17` "…기도할 [ ] 비몽사몽간에", 보기는 바리새인인줄 / 말하시는 / 때에 / 또는 → 답 "때에".
- 원인: `src/engine/quiz.ts`의 `blank()`는 답을 아무 낱말(2자 이상)에서 고르고, 보기는 같은 장 낱말을 끝말 상관없이 섞는다. 편지용 `letterBlank()`는 내용 낱말(`isContentWord`)만 답으로 쓰고 보기를 `rankOptions`(끝말 같은 것 먼저)로 고르는데, 다른 책 쪽에는 그 처리가 없다.
- 고칠 방향: `blank()`도 `letterBlank()`와 같은 규칙을 쓴다.

### 4. 같은 꽂기 퀴즈에 같은 이야기가 두 번 나옴 — 낮음
- 누가복음 꽂기 퀴즈(서고에 1권)에서 "먼저 나오는 이야기" 두 문제의 정답이 모두 `lk-004-001`(시험을 받으시다)이었다.
- 원인: 순서 문제로 채울 때 보기 묶음이 똑같을 때만 거른다(`quiz.ts` `buildLibraryQuiz` 끝 부분).
- 고칠 방향: 이미 낸 문제의 조각 id를 빼고 `order()`를 부른다.

### 5. 편지 빈칸 오답이 다른 편지의 끝인사와 거의 같음 — 낮음
- 빌레몬서 꽂기 퀴즈 `몬 1:25` "…은혜가 너희 심령과 함께 [ ]", 보기는 있을찌어다 / 말보다 / 믿음의 / 할찌어다, 답 "할찌어다".
- "있을찌어다"로 채운 문장은 본문 어디에도 똑같이는 없어서 검사(`countAnywhere === 0`)를 통과한다. 하지만 갈 6:18·빌 4:23("…심령에 있을찌어다")·딤후 4:22("…함께 있을찌어다")와 거의 같아서, 외워 둔 사람도 헷갈리기 쉽다.
- 고칠 방향: 끝인사 절(마지막 절)은 편지 빈칸에서 빼거나, 이런 축복 어미(`있을찌어다`·`할찌어다`)는 서로 오답으로 쓰지 않는다. 설계 판단이 필요하다.

### 6. 신약 필사 길잡이 배경 칸도 "-세요" — 확인 필요(문체)
- `src/content/nt/*.json`의 `guides.background`에서 518문장 중 86문장이 "-세요."로 끝난다.
  - "부활하신 예수님이 … 말씀하세요."(행 1)
  - "갈릴리 가나의 혼인 잔치에 초대받으세요."(요 2)
  - "하나님의 나라를 전하세요."(눅 8)
- 어제 구약 길잡이 배경 칸은 "-셨어요"로 바꿨다(사용자 결정). 신약도 같은 기준으로 바꿀지 결정이 필요하다. 바꾼다면 `scripts/ot-guides-honorific-past.mjs`와 같은 방식이면 된다.

## 정상 확인
- **필사**
  - 한 절씩 기록되고 장이 마친다. 직접 다 쓴 장에는 정성 도장이 찍힌다.
  - 필사 실력 4부터 낱말 조각 절이 나온다. 틀린 조각을 눌러도 불이익이 없고, 맞추면 본문 그대로 기록된다.
  - 실력 9 기준으로 신약 7,939절의 빈칸·조각을 모두 만들어 봤다. 보기 중복이나 답 없는 보기는 없었고, 조각을 이으면 늘 본문과 같았다.
  - (없음) 절(마 17:21 등 12곳)은 필사 절에서 빠진다.
- **제본·표지**: 그대로 제본하면 완성본이 가방에 들어간다. 특별 제본·표지 꾸미기는 재료가 모자라면 "이대로 꾸미기"가 꺼지고 바뀌지 않는다.
- **서고 꽂기 퀴즈**
  - 문제 종류: 먼저 나오는 이야기, 말씀 조각 맞추기, 어느 구절, 빈칸, 어느 책(서고에 2권부터), 먼저 나오는 구절, 편지 첫머리(보내는 사람·받는 사람·받는 곳), 이름이 적혀 있지 않음(히브리서·요한1·2·3서).
  - 27권 퀴즈 모두 보기 중복이나 답 없는 보기가 없었다. 빌레몬서 첫머리 보기는 4개였다.
  - 다 맞히면 금박, 한 번 틀리면 은박과 "다시 읽을 구절" 알림이 나온다.
  - 처음 꽂으면 나의 한 줄 창이 뜨고, 닫으면 그 책의 방 선반으로 돌아간다.
- **다시 도전**: 금박 1과 기름 1이 없으면 막히고, 있으면 퀴즈가 다시 열린다(출제는 서고 전체). 재료가 줄고, 다 맞히면 은박 → 금박이 된다.
- **책 수에 따른 일**: 꽂은 책 수로 구역이 열리고, 책 수에 따라 이웃이 이사 온다.
- **복음서 방 잔치**: 아기 잔치 날을 피해 다음 날 열린다.
- **여정 판**: 사도행전 장마다 카드가 들어와 46/46장이 된다. 다 맞추면 "여정 판을 다 이었어요" 알림이 뜨고, 다음 날 아침 배 장면(`actsShip` 1→2)이 나온다.
- **일곱 교회 판**: 요한계시록 2·3장에서 카드 7장이 생긴다. 화면 ▲로 맞추면 완성 알림이 뜬다.
- **27권 잔치**
  - 27번째 책(요한계시록)을 꽂으면 "스물일곱 권의 서고" 처음/지금 비교 창이 뜬다(화면 확인).
  - 그날 밤 자면 다음 날 일정표에 "스물일곱 권 잔치 18:00–21:00"이 잡힌다.
  - 모닥불 곁에 있으면 18:30에 장면이 열린다. 그때 이웃 23명이 모두 불 곁에 있었다(화면 확인).
  - 다음 날 아침 새 터 선물 장면이 나온다.
- **나눠 받는 신약 본문**: 새로고침 직후 아직 받지 않은 책을 "펼쳐 보기"로 열어도 본문이 나온다.
- **저장**: 68일째 상태(27권 등급·제본·여정·교회·잔치·도장 259장)가 새로고침 → 이어하기 뒤 그대로다.
- 진행 중 콘솔 오류는 0건이었다.

## 버그 아님으로 판단한 것
- 탐정 문제가 안 나옴: 테스트(library-quiz "관련 본문 표기로 … 탐정 문제를 만들지 않는다")가 일부러 막았다.
- "어느 책" 문제의 비슷한 구절(막 2:22 ↔ 눅 5:37): 본문 글자가 다르면 내는 설계다(`countVerse === 1`).
- 로마서 첫머리 "[로마]에 있어": 책 이름을 문제에 쓰지 않는 규칙(exclusion-list §4-6)은 지켜졌다. 꽂는 책이 로마서라 짐작되는 것은 어쩔 수 없다.
- 필사 결과 창의 "지능 1 → 10": 단계가 아니라 1–100 점수다(`statScore`).
- 점검 방식 때문에 생긴 일:
  - 필사 결과에 매력·근력이 섞였다: 필사 창을 `copyExit` 대신 닫았다.
  - 순위 창이 다음 아침에도 다시 떴다: 순위 창을 ✕ 대신 닫았다. 순위 날은 계절 1·21일(계절 40일)로 맞다.
  - "?가 이제 혼자 걸어 다녀요"의 '?': 빵집을 만나지 않고 돕기를 불렀다. 만나지 않은 이웃을 '?'로 쓰는 것은 설계다(gen-text.ts).
  - 첫 장 장면이 며칠 늦게 떴다: 장면을 띄우는 프레임보다 먼저 창을 닫았다.
  - 오후 첫 필사에서 책상이 안 열렸다: 새 `nt-loader`가 본문을 받은 뒤 이어서 여는데, 스크립트가 기다리지 않았다.
- 옛 조각 책상·편지 빈칸 창(`Desk`·`LetterCopy`)이 지금 화면에서 열리지 않음: 계획 14 주석대로 닫은 길이다. 편지도 필사 책상에서 쓰고, 빈칸은 필사 방식 셋 중 하나로 나온다.
- 창이 반쯤 투명하게 찍힘: 미리보기 창이 가려져 등장 애니메이션(`rise`)이 멈춘 것이다.
