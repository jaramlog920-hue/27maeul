2. **내 집·가족 방 — 신규 29개 완료**: 기존 ‘같이 읽은 책’의 방 배경을 공용 함수로 분리했다. 배우자 13명 활동·아이 활동·식사·생일·편지·가구 해금에 실제 가족 모습과 원래 선택을 연결했다. 기존 읽기·임신·출산 4개를 포함한 가족방 모음은 33개다. 검사 276개, 전체 빌드, 가로/세로·선택 소품 시각 확인 완료.

   **배경 재사용 기반 정리**: 기존 장면에서 방·건물·바닥·창·기와를 재사용 가능한 함수로 떼어 낸다. 새 디자인을 한꺼번에 덮어쓰지 않고 배경군 하나씩 진행한다. 카메라·인물 크기·소품 기준 좌표를 고정한다.
3. **빵집 → 찻집 → 대장간 → 베틀 → 나루**: 완성 장면의 배경이 이미 있는 묶음부터, 그 묶음의 미제작 이벤트 전체를 제작·연결·확인한다. 소수 항목마다 완료 보고하고 끝내지 않는다. 같은 NPC의 이어지는 이야기는 앞 사건부터 만든다. 처음에는 단순 소품/대화 장면으로 재사용 구조를 확인하고, 이후 선택별 행동·가족 장면을 연결한다.
4. **벌통 → 약방 → 목공방 → 기름 작업장 → 포도원 → 양 우리**: 장소마다 기본 배경을 공유하고 각 이벤트의 물건 상태·인물 조합·행동만 만든다. 서고/광장/언덕/사랑방으로 실제 장소가 바뀌면 그쪽 배경을 사용한다.
5. **광장·사랑방·언덕·편지 집·서고·여행**: 여러 NPC가 같은 장소를 쓰는 장면을 모아 처리한다. 참석자·아이 나이·계절·해금 조건은 실제 상태를 사용한다.
6. **현재 위치/확인 대기 묶음**: 초대·재료 부탁·선물·해금 등은 발생 장소부터 확인한다. 이동 중에도 뜨는 이벤트는 현재 위치에 맞는 배경을 고른다. 대사가 초대/미래 계획이면 실제 모임/작업을 미리 실행한 그림을 그리지 않는다.
7. **전체 누락 검사**: 676개 모두에서 그림 유무와 게임/미리보기/썸네일 연결을 확인한다. 남은 수가 0이고 검사까지 통과해야 전체 완료다.
