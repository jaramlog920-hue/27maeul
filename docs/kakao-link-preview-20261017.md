- 공유 이미지: `public/og-kakao-v2.jpg` (1200×630, 약 95KB).
- 원본: `artifacts/scenery/og-kakao-v2-source.png`.
- 제작: 내장 image_gen 도구. 크림색 바탕, 초록 지붕의 작은 도트 집, 펼친 책과 깃펜, 나무와 꽃으로 구성.
