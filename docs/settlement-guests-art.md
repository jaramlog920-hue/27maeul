# 손님집 고유 도트·모션과 새 터 건물

2026-10-07 사용자 요청: 손님 입주에 필요한 고유 도트와 모션, 관련 건물 제작.

## 완성한 자산

- 헤이즐: 버들 바구니를 짜는 나그네. 갈색 땋은 머리, 갈색 조끼, 허리 주머니, 손잡이가 있는 버들 바구니.
- 모리스: 기존 대사의 늙은 뱃사람 설정을 반영한 은빛 짧은 머리·눈가 주름·쪽빛 조끼·목수건. 별을 점으로 이은 별자리판.
- 아이비: 씨앗 모으는 여행자. 묶은 머리, 풀빛 여밈옷, 접어 올린 바지, 어깨 가방과 씨앗 주머니.
- 각자 8동작 × 4방향 × 4프레임: 서기, 걷기, 고유 손일, 인사/선물 건네기, 짐 들기, 앉기, 읽기, 잠자기. 같은 주민 몸체와 기존 사용 동작을 재사용하고, 소품과 외형은 인물별로 고정했다.
- 손님집·입주 주택·직조 공방·공동 마당·기억 정원 5종: 네 방향 64×64 원본과 기존 공사 골격. 기존 건물에 창가 화분·천 장식·지붕 배색·마당 소품을 더했다. 입구·문턱·그림 크기·부지 크기는 보존했다.

## 원본과 사용 방법

- 인물: `src/render/settlement-guests-art.ts`의 `SETTLEMENT_GUESTS`, `settlementGuestFrame(id, facing, action, frame)`.
- 반환값은 24×24 `actor`, `propBack`, `propFront`, `anchor`, 인물 `palette`, `duration`, `loop`. 도구는 `GUEST_PROP_PALETTE`로 별도 그린다. 배경 도구 → 인물 → 전경 도구 순서다.
- `walk`는 0·1·0·2 걸음 순서, 모리스는 모든 포즈에서 노년 외형 유지. 손일은 헤이즐 바구니 엮기, 모리스 별자리판 기록, 아이비 주머니 손질.
- 건물: `src/render/settlement-building-details.ts`, `old-village-art.ts`의 `OLD_BUILDINGS`에서 자동 적용. 게임 새 터의 기존 건물 렌더링이 직접 읽는 원본이다.
- 내보내기: `node scripts/export-settlement-guests.mjs` → `assets/settlement-guests/`.
- PNG: 인물 합성 384장 + 레이어 1,152장 + 고유 소품 3장 + 건물/공사 40장, 총 1,579장. `manifest.json`은 방향·동작·프레임별 앵커·시간·반복 여부·레이어 경로를 기록한다.
- `preview.html`에서 방향 선택, 모션 재생/정지. 동작 줄의 순서는 위의 8동작과 같다. `contact-sheet.png`는 앞모습 동작(잠은 옆모습), 건물 앞·오른쪽 모습이다.

## 연결 범위와 남은 것

건물 디테일은 게임의 기존 시설에 연결했다. 손님은 입주 구현에서 바로 사용할 수 있는 자산을 준비한 상태로, 아직 지도 NPC와 일과에 연결하지 않았다. `newland-life.ts`의 사흘 체류·대화·선물·재방문 기능은 그대로다. 손님 입주에는 집 배정·저장·일과/동선·상호작용 연결이 남는다. 미리보기나 자산 완성을 입주 기능 완성으로 표시하지 않는다.

결정: 건물 범위는 현재 새 터에 지을 수 있는 관련 시설 5종으로 정했다. 새 건물 종류나 가격, 부지 규칙을 추가하지 않았다. 배경 소재·길·지형 원본은 수정하지 않았다.
