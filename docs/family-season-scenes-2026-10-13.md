# 가족과 계절: 새 전체 화면 도트 장면 10개

이전에 제안한 가족/서고 장면 다섯 개와 사용자가 추가로 요청한 다섯 개를 함께 구현했다.

| 장면 | 게임에서 열리는 조건 | 반복 |
|---|---|---|
| 결혼 후 첫 아침 | 결혼 바로 다음 날 정오 전, 배우자와 기록자가 집에 있음 | 한 번 |
| 배우자의 귀가 | 저녁 18시 이후, 배우자가 실제 집 밖에서 안으로 이동하고 기록자가 집에 있음 | 해마다 한 번 |
| 아이의 첫 도움 | 도움 단계 아이가 실제 물건을 가져온 날, 아이와 기록자가 집에 있음 | 한 번 |
| 책으로 채워진 서고 | 신약 27번째 책을 처음 꽂음. 금박 재도전은 제외 | 한 번 |
| 가족의 겨울밤 | 겨울 눈 오는 밤, 배우자·아이·기록자가 집에 있음 | 해마다 한 번 |
| 봄날 꽃길 | 맑은 봄 10~16시 언덕 주변 세 칸 | 해마다 한 번 |
| 여름날 물가에서 쉬기 | 맑은 여름 10~16시 호숫가 정자 주변 (10~16,30~33) | 해마다 한 번 |
| 가을 낙엽길 | 맑은 가을 10~16시 언덕 주변 세 칸 | 해마다 한 번 |
| 비 사이로 뜬 무지개 | 기존 무지개 이벤트(가을 비 오는 날 16~17:30 야외)를 전체 화면으로 그림 | 기존 기준 유지 |
| 필사를 마친 늦은 밤 | 밤에 한 장을 실제 완료. 비 필사·책 완성 장면과 겹치지 않음 | 해마다 한 번 |

돈·시간·호감도·능력치의 추가 보상과 새로운 해금 조건은 없다. 장면을 닫으면 기존 일지/앨범 처리로 돌아간다. 가족의 기억은 가족 일지에 분류된다.

기본 성인 10×14 도트와 기존 짧은 앉은 다리를 재사용했다. 배우자의 실제 모습, 아이의 성장 단계와 입힌 옷을 따른다. 아기는 기존 요람/포대기 그림을 사용한다. 아이가 건네는 물건은 실제 도움 능력치와 당일 번갈아 받는 물건을 반영한다. 팔을 늘려 그리지 않는다.

미리보기: `/assets/stargazing/family.html`, 모션 순서: `/assets/stargazing/preview.html?scene=firstMorning&set=family`.

검증: 신규 조건·실제 아침/물건 수령·전체 화면·가족 앨범 분류·저장·서고·필사와 기존 회귀를 합쳐 167개 테스트 통과. 콘텐츠 검사, TypeScript, 제작 빌드 통과. 브라우저에서 열 장면과 미리보기 순서를 확인했다.
