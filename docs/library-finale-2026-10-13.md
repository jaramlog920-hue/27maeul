# 스물일곱 권이 모인 날

27권 완필과 27권 서고 완성을 두 순간으로 나누었다.

- 신약의 실제 27권 모든 장이 처음 완료되는 순간 `lastManuscript`를 예약한다. 본문을 불러온 범위가 아니라 책별 실제 장 수로 판정한다. 마지막 책이 어떤 책이어도 동작하고, 완료한 옛 저장이나 다시 쓰기에는 예약하지 않는다. 일반 `bookBound` 풍경을 짧은 특별 풍경으로 대체한다. 제본은 그대로 가능하고, 제본 창을 먼저 열어도 특별 풍경을 지우지 않는다.
- 마지막 책을 처음 꽂으면 일반 `shelved` 장면 대신 `fullLibrary` 한 장면을 연다. 0~3초 마지막 책 꽂기, 3~7초 서고 전체 보기, 7~12초 이웃과 가족 모이기, 12~16초 함께 책장을 바라보기, 16초 이후 서고 밖 저녁 등불과 작은 식탁 순서다.
- 실제 마지막 책과 은박/금박 등급을 반영한다. 이미 마을에 온 이웃 중 가까운 세 명을 선택하고 현재 모습/옷을 따른다. 실제 결혼 상태의 배우자, 떠나지 않은 아이만 함께 나온다. 아기는 기존 요람, 자란 아이는 기존 성장 비율을 사용한다. 미리보기는 가족이 있는 예시다.
- 앨범 사진은 시간 14초의 단체 구도로 별도 그린다. 장면을 바로 넘겨도 첫 프레임이나 저녁 화면을 사진으로 남기지 않는다. 다시 보기와 모션 줄이기를 지원하며, 나중에 가족이 바뀌어도 완성 당시의 앨범 사진은 보존한다.
- 완성 장면을 닫으면 기존 서고 완성 기록 창으로 이어진다. 이후 확장권/새 터 안내와 다음 날 실제 잔치의 조건·보상 흐름을 유지한다. 앨범 재감상에서는 완성 기록 창을 다시 띄우지 않는다.
