# 모바일 화면 검증 — 2026-10-11

배포 빌드를 로컬 미리보기 서버에서 Chrome의 모바일 에뮬레이션으로 실행했다. 격리된 브라우저의 새 저장만 사용했으며 사용자의 저장은 수정하지 않았다. iPhone 기기 프로필은 화면 크기·터치·배율 설정에 사용했으며 실제 iOS Safari 검증을 뜻하지 않는다.

## 발견하고 수정한 문제

처음 받은 적 없는 본문의 동적 import가 오프라인에서 실패하면 Chrome이 같은 모듈의 실패를 기억하여, 인터넷을 복구해도 같은 페이지의 ‘다시 불러오기’만으로 복구되지 않았다. 실제 브라우저에서 재현했다.

`NtContent.tsx`에 ‘저장하고 다시 접속’을 추가했다. 저장 성공 뒤에만 새로고침하며, 저장 실패 시 알림을 표시하고 화면을 유지한다. 기존 재시도 버튼도 유지한다. 새 버튼을 통한 실제 브라우저 복구를 재검증했다.

관련 로딩·화면 오류 테스트 6개 통과. 배포 빌드와 초기 의존성/PWA 캐시 검증 통과. 초기 JS는 2,199.13 kB(gzip 660.93 kB).

## 개선점과 실기기에서 남은 확인

- 320픽셀 화면의 하단 메뉴 버튼 일부는 높이 28픽셀이다. 동작하지만 손가락으로 누르기 작다. 조작판 높이와 지도 영역을 함께 고려하여 터치 영역 확대를 권장한다.
- 실제 한글 IME 조합·가상 키보드 열림/닫힘·iOS Safari·홈 화면 설치·실제 터치 정확도와 발열/프레임 성능은 확인하지 않았다. 축소 높이 검증을 실제 키보드 검증으로 해석하면 안 된다.
