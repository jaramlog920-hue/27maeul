# 기능별 순차 버그 검사

## 작업 원칙

사용자 요청: 기능을 하나씩 재현·수정·재검사한다. 사용자 저장 초기화, 커밋, 배포는 하지 않는다.
사용자가 시간 간격 없이 한 기능을 마치면 바로 다음 기능으로 진행하도록 변경했다.
10분 반복 자동화는 일시 중지했다. 작업 중에는 기능별 검증 후 즉시 다음 기능으로 넘어간다.
엔진·컴포넌트 검사와 실제 브라우저 자연 플레이 검증을 구분한다.

## 이번까지 확인한 기능

- 새 터 배치: 플레이어를 나무로 가두는 배치 차단. 관련 82건 통과. 상세는 `ot-map-audit-2026-10-10.md`.
- 새 터 주택 출입: 방향별 문, 저장 복원, 밤의 입장·퇴실 24건 통과.
- 방문객: 대화·선물·입주 관련 18건 통과. 확인 범위에서 추가 버그를 재현하지 못함.
- 장날 좌판: 아래 마감 시간 버그 수정. 상인 판매·좌판 엔진·출입 상호작용·화면 컴포넌트 관련 4개 파일 40건 통과.
- 요리: 음식을 차린 뒤 의자를 줄여도 좌석보다 많은 사람이 함께 먹던 문제 수정. 요리 엔진 44건 통과.
- 반려동물: 입양 안내·이틀 후 미입양 동물 떠남·조각·성향·습관·쉼터 관련 6개 파일 43건 통과. 추가 수정할 버그는 재현하지 못함.
- 낭독 모임: 자동 알림·중도 종료·저장 복원·음성 취소 관련 컴포넌트 12건 통과.
- 가방·제작: 재료 표시·선택·제작 조건·아기침대 제작법과 요리 화면 관련 5개 파일 51건 통과. 추가 수정할 버그는 재현하지 못함.

## 요리 좌석 수 버그

두 자리에 음식을 차린 뒤 의자 하나를 치워도 `canSit`이 두 사람의 식사를 허용했다.
수정 전 회귀 검사에서 `canSit`이 null을 반환함을 확인했다.
식사를 시작할 때 현재 식탁의 실제 좌석 수를 다시 계산하도록 수정했다.
좌석 부족 시 초대를 줄이거나 의자를 놓으라는 안내를 표시하며, 혼자 먹거나 남은 음식을 치우는 동작은 허용한다.
음식·좌석 모두 충분할 때의 기존 식사 흐름은 유지한다.
이 검사는 구성한 엔진 상태와 컴포넌트 검사이며, 실제 브라우저 자연 플레이 검증은 아니다.

## 좌판 마감 시간 버그

기다리는 손님이 있고 16:46일 때 `stallStatus`는 `over`인데 `answerGuest`는 판매를 허용했다.
수정 전 회귀 검사에서 17:01로 시간이 진행되고 닢이 10에서 21로 증가함을 재현했다.
화면도 `over` 또는 `away` 상태에서 응대 버튼을 계속 표시하고 있었다.

수정: 응대에 필요한 15분을 마감 전에 확보하지 못하면 판매를 거부한다.
응대 가능한 `guest` 상태에서만 응대 버튼을 표시하며, 마감 상태에는 안내 문구를 보여 준다.
좌판을 떠났을 때도 무반응 응대 버튼을 감추고 기존 위치 안내를 유지한다.
추가 검사: 엔진 회귀 1건, 컴포넌트 마감·자리 이탈 검사 2건.
실제 브라우저 자연 플레이로 재현한 것은 아니다. 테스트 환경의 canvas getContext 경고가 있어 도트 렌더링 검증은 별도로 필요하다.

## 다음 검사 순서

### 좌판 추가 수정

좌판 창에서 16:45에 기다려 17:00이 되면 창을 닫기 전까지 마감·재고 반환이 수행되지 않는 문제를 재현했다.
좌판 판매로 500닢에 도달해도 업적 기록·알림을 거치지 않는 문제도 수정 전 테스트로 재현했다.
좌판 상태 변경을 공통 저장 경로로 모으고 저장 전에 만료 좌판을 마감하도록 수정했다.
창을 켠 상태의 시간 변경도 감지하며, 마지막 판매 수익 보존·미판매 재고만 반환·재개 시 중복 반환 방지도 검사했다.
관련 4파일 45건 통과 후 추가 경계 검사를 포함한 좌판 화면 테스트 8건 모두 통과. 빌드 성공, 배포하지 않음.
엔진·스토어·컴포넌트 검사이며 브라우저 자연 플레이/도트 렌더링 확인은 아직 아니다.

### 추가 제작 집중 검사

일반 제작법 10종을 대상으로 스토어에서 시작·중단·완료·중복 완료 입력·저장 복원을 검사했다.
각 제작법을 궤짝 재료로 만드는 경우와 가방·궤짝이 모두 가득 찼을 때 재료를 보존하는 경우도 확인했다.
추가 테스트 `craft-flow.test.ts` 20건과 `CraftQuantity.test.tsx` 2건을 포함해 관련 6개 파일 61건 통과.

재현한 게임 버그 1건: 개선된 기름틀은 실제 기름 2개를 만들지만 제작 버튼은 1개로 안내했다.
수정 전 컴포넌트 검사에서 개선 상태의 안내가 '올리브 2 → 기름 1'로 나타나 실패했다.
이제 제작 엔진의 `recipeGives` 결과로 안내 수량을 계산하여 기본 1개·개선 후 2개를 표시한다.

기존 `skills.test.ts`에는 아기침대 제작법이 없는 옛 제작법 목록이 남아 있었다.
이는 게임 버그가 아니라 검사 기대값의 누락으로 분류하고 새 제작법을 포함하도록 갱신했다.
실제 브라우저에서 자연 플레이한 결과가 아니라 엔진·스토어·컴포넌트 검사 결과이며, 배포하지 않았다.

1. 일정·행사: 예약 충돌·해금되지 않은 참가자·행사 중 대화·중도 종료.
2. 이동: 키보드·터치 이동 경계·NPC와 문·충돌.
3. 저장 복원: 화면과 엔진 상태 차이·미완료 작업·옛 저장 호환성.
4. 앞서 엔진으로 확인한 기능들의 실제 화면 검증. 사용자 저장을 덮어쓰지 않는 별도 검사 환경을 사용한다.

한 기능의 검사 기록을 남긴 다음 다음 기능으로 넘어간다. 기존 결혼·꾸미기 진단도 참고하되 전체 기능이 버그 없다고 단정하지 않는다.
