# 텃밭·필사·손일·문·편지·생활 소품 모션

2026-10-08 사용자 요청: 제안한 모션을 모두 도트로 준비. 게임 연결은 사용자가 클로드에게 맡기므로 신규 자산 원본·PNG·분리 레이어·미리보기만 만들었다.

## 완성 자산

| 묶음 | 동작 |
|---|---|
| 텃밭 | 씨앗 넣기, 흙 덮기, 허브 수확, 콩 수확 |
| 필사 | 펜에 잉크 묻히기, 글쓰기, 펜촉 닦기, 쓴 종이 옮기기 |
| 직업 손일 | 망치질, 그물 꿰매기, 양털 분류 |
| 편지 | 편지 접기, 봉투에 넣기, 봉투 열어 펼치기 |
| 문 | 입주 주택·손님집·직조 공방·구약 서고·가족 주택 각각 앞/왼쪽/오른쪽 열기와 닫기 |
| 생활 소품 | 등잔 불꽃, 갈대 말리는 틀의 다발 흔들림 |

인물 14동작 × 4방향 × 4프레임: 합성 224장 + 뒤 소품/인물/앞 소품 레이어 672장. 문 5건물 × 3방향 × 2동작 × 4프레임: 합성 120장 + 뒤 건물/앞 문 레이어 240장. 생활 소품 8장. 개별 PNG 1,264장, 도감 1장.

## 클로드 연결용 API

### 인물 동작

`src/render/work-details-motion-art.ts`의 `workDetailFrame(action, facing, frame, avatar)`.

- `WORK_DETAIL_GROUPS`가 텃밭/필사/직업/편지별 동작 ID를 제공한다.
- 반환: 32×32 `actor`, `propBack`, `propFront`, 인물 `palette`, `anchor`, `duration`, `loop`.
- 실제 인물의 `FullAvatar`를 마지막 인수로 넣을 수 있다. 기본은 도트 확인용 예시 모습이다.
- 뒤 소품 → 인물 → 앞 소품 순서. 소품은 `WORK_DETAIL_PALETTE`, 인물은 반환된 `palette`로 그린다. 기존 캐릭터 팔레트와 소품 팔레트를 합치지 않는다.
- 왼쪽은 오른쪽 동작을 한 번 뒤집고, 앞/뒤는 각 방향의 기존 얼굴·옷 원본을 사용한다. 소품은 뒤 방향에서 인물 뒤 레이어로 간다.
- 글쓰기·망치질·그물 꿰매기·양털 분류만 반복. 씨앗 넣기·흙 덮기·수확·펜 관리·종이 옮기기·편지 동작은 단발이며 마지막 자세 유지.
- 텃밭은 몸을 낮춘 자세와 작업물의 단계 변화가 함께 있다. 망치질에는 불꽃이나 뜨거운 금속을 추가하지 않았다. 그물은 작은 구멍을 꿰매고 양털은 한 뭉치를 옮긴다.
- 작업대는 소품 레이어에 포함한 원안이다. 기존 작업대 가구 위에 연결할 때는 작업대 받침을 중복해 그리지 않도록 분리하거나 해당 소품만 사용해야 한다.

### 건물 문

`src/render/door-ambient-art.ts`의 `buildingDoorFrame(id, facing, action, frame)`.

- 건물: home/guest/weaver/archive/family. 방향: down/left/right. 동작: open/close.
- 64×64 합성 `rows`, `back`(건물과 열린 틈), `front`(문짝), `anchor`, 기존 `entry`, `duration: 180`, `loop: false`.
- `DOOR_PALETTE`로 그린다. 뒤 건물 → 앞 문짝 순서. 합성과 분리 레이어 결과는 같다.
- 열기 마지막과 닫기 처음은 같은 열린 상태, 닫기 마지막은 기존 `OLD_BUILDINGS` 원본과 같다.
- 문턱(59px 아래), 건물 크기, 기존 출입구 화소 위치를 보존했다. 충돌·방 이동·입구 판정은 연결 담당자가 기존 엔진 규칙에 맞춰 유지한다.
- 뒤쪽 건물에는 문이 없으므로 up 방향 문 모션을 만들지 않았다. 기존 건물 원본을 덮어쓰지 않았다.

### 등잔과 갈대

같은 파일의 `ambientDetailRows(action, frame)`, 16×16, `AMBIENT_PALETTE`.

- lampFlame: 등잔 받침은 고정하고 불꽃만 작은 폭으로 변한다. 프레임 180ms.
- reedSway: 기존 갈대 틀의 기둥/가로대 형태를 유지하고 세 다발의 아래 부분만 한 화소씩 흔든다. 프레임 500ms.
- 기존 `decor.ts`의 Canvas 그림이나 지도 소품은 이 작업에서 바꾸지 않았다.

## 파일과 미리보기

- 내보내기: `node scripts/export-work-details.mjs`.
- `assets/work-details/manifest.json`: `connected: false`, 방향별 프레임·레이어·시간·반복 여부·앵커·출입구·팔레트.
- `assets/work-details/preview.html`: 묶음 필터, 방향 선택, 재생/정지, 단발 동작 다시 보기. 단발은 마지막 자세에서 멈춘다.
- `assets/work-details/contact-sheet.png`: 인물은 왼쪽부터 씨앗/흙/허브/콩/잉크/필사, 다음 줄 펜 닦기/종이 옮기기/망치/그물/양털/편지 접기, 다음 줄 봉투에 넣기/펼치기. 아래 건물은 열린 문 상태 5종, 맨 아래는 등잔과 갈대 틀.
