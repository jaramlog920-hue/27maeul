# 서고 성장 개편: 3차 구현

## 후반 생활 연결

| 완필 권 수 | 적용 |
|---|---|
| 9 | 목수에게 편의 설치물 주문, 장날 빗물·잉크 항아리 구입 |
| 11 | 새 서고 방문객·방명록 생성 |
| 12 | 아침 순위 정산·보답, 최초 순위 화면 |
| 13 | 새 행사 예약 및 행사 종류 목록 |
| 14 | 주민의 새 자율 관계·혼인·출생 정산, 자율 생활 켜기 |
| 15 | 깊은 관계 단계 접근. 쌓은 마음 점수는 유지 |
| 16 | 연애 후보 판정 |
| 20 | 배우자 선물·데이트·저녁 식사·저녁 독서 |
| 23 | 아이와 활동, 책상 동행 시작, 배우자와 아이의 가족 활동 |
| 25 | 주민 자녀의 견습 시작 |
| 26 | 견습 기간이 지난 주민의 은퇴·자리 계승 |

기존 장·권 완료 수 조건과 함께 비용·날짜·관계·장소 등 각 활동의 원래 조건도 검사한다. 27권 잔치는 이미 27권 전시와 일곱 교회 판 완료를 요구하므로 그 흐름을 유지했다.

## 유지하는 진행

- `growthLegacy` 저장은 기존 생활 이용 권한을 유지한다.
- 행사 취소·마무리와 예약 재료 반환, 이미 주문한 설치물의 아침 완성은 계속 가능하다.
- 기존 아이의 나이 변화와 이미 시작한 책상 동행은 계속 처리한다. 성장 자체를 23·25권 조건으로 멈추지 않는다.
- 이미 은퇴한 주민의 가족·자리 계승 기록은 유지한다.
- 기존 관계가 플레이어의 연인·배우자라면 관계 표시를 강제로 낮추지 않는다.
- 기존 순위 기록·팝업과 방명록은 계속 읽을 수 있다.

잠긴 버튼에는 필요한 완필 권 수를 표시했다. 7장 완료 후에는 전시 권 수와 별개로 서고 창에 필사 기록 꾸러미가 생긴다. 제본하지 않은 기록을 완성 책으로 표시하지 않는다.

## 검증

`late-growth.test.ts`는 실제 완필 진행을 갖춘 새 저장으로 해금 전후·자원 보존·순위 중복 보답 방지·예약 취소 시 재료 반환·견습과 은퇴 분리를 검증한다. 기존 생활 시나리오는 `legacyGame` 준비 상태로 개편 이전 저장의 동작을 검증한다. 기존 동작에 대한 기대값은 유지한다.

`LifeGrowth.test.tsx`에서 7장 기록 꾸러미와 후반 잠금 안내를 확인한다. `npm run build`, `npm run measure:startup`으로 TypeScript·콘텐츠·배포 빌드와 초기 정적 의존성/PWA 캐시 분리를 확인한다.

관련 시나리오 391개 통과. 첫 화면 JS는 공통 파일까지 2,198.89 kB(gzip 660.83 kB)다.

전체 테스트에는 기존 화면 초기화·지도 스냅샷 등의 실패가 남아 있다. 관련 테스트의 통과를 전체 테스트 성공으로 해석하면 안 된다. 모바일 실기기의 첫 실행·느린 연결·오프라인 재접속 검증과 공통 게임 번들의 추가 최적화도 남아 있다.
