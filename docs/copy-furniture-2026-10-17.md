# 필사 전용 수집 가구 40종

## 적용된 구성과 지급 순서

유아 5종 → 어린이 5종 → 나머지 30종(목욕탕 8, 부엌 8, 애완동물 8, 계절 전시물 6). 같은 단계의 미획득 가구 중 하나를 선택하며, 앞 단계의 다섯 종류를 모두 받아야 다음 단계로 넘어간다. 이름과 고유 ID는 `src/engine/copy-furniture.ts`에 있다.

처음 실제로 필사 완료한 장마다 25% 확률로 가방에 한 개를 지급한다. 기존 장 완료 기념 가구와 같은 확률로 정했으며, 기존 옷·삯·생활 가구 보상은 유지한다. 세계 seed·책·장으로 추첨을 고정하고, 재필사에는 지급하지 않는다. `copyFurniture:<id>` 영구 획득 표식을 저장하므로 배치·회수·선물 뒤에도 수집 순서가 되돌아가지 않는다. 모두 모으면 신규 지급을 종료한다.

장날·입주·작별 선물 추첨에서는 신규 40종을 제외한다. 도감에는 포함한다. 기존 68종 생활 가구의 장날 순서와 이전 보상 풀은 유지했다. 새 제작 재료는 추가하지 않는다.

## 제작 및 연결

- 40종 기본 그림과 네 단계 사용 모션을 등록했다. 최신 사용자 수정에 따라 38종은 정면 고정이며, 긴 낮잠자리와 탈의 칸막이만 가로/세로 두 방향을 제공한다. 불필요한 상하좌우 그림과 회전 버튼은 제거했다. 게임과 미리보기 생성기는 `copyFurnitureUseFrame`을 함께 사용한다.
- 가방 아이콘·이름·설명, 집 배치·회전·회수, 장 완료 보상 알림, 저장·불러오기를 연결했다. 신규 벽걸이는 벽 부착을 유지하고 정면을 사용한다. 다른 기존 벽걸이 규칙은 유지한다.
- 실제 가족이 근처에 있고 성장 단계가 맞을 때만 가족을 표시한다. 씻기·낮잠은 실제 아기, 이유식·난간·천 공은 걷는 유아, 어린이 놀이는 유아/어린이 단계에 맞춘다. 사람 아기는 `newbornArt`의 기존 공용 원본을 쓴다. 반려동물도 실제 근처의 동반 고양이/강아지를 사용한다.
- 가족이 없거나 멀리 있으면 빈 가구의 정리·준비 동작을 표시하며 임의의 아기/동물을 만들지 않는다. 새 40종은 가구 곁에서 눌러 사용하는 방식이다. NPC가 임의로 유아 가구를 사용하거나 가족을 만들도록 자율 행동에 등록하지 않았다.
- 시대 배경의 토기·돌·천·목재로 구성했다. 향을 즐기는 가구, 전기 기기는 추가하지 않았다.

## 미리보기

`/assets/furniture/copy-collection.html`은 40종 전체 재생, 필요한 방향만 선택, 일시정지, 단계 조절, 기본/다른 외형/가족 없는 상태 비교를 지원한다. 반려동물 가구 8종은 아기/성체 고양이·강아지 네 구성을 별도로 선택할 수 있다. 저장·앨범·보상 상태를 읽거나 쓰지 않는 정적 모음이다. 가족과 외형은 비교용 예시이며 실제 사용자 저장으로 표시하지 않는다.

생성: `node artifacts/scenery/render-copy-furniture.mjs`
전체 한 장 모음: `python artifacts/scenery/render-copy-furniture-overview.py`

## 검증 범위

현재 42개 실제 방향 × 기본 3구성 × 4단계는 504프레임이다. 반려동물 8종에 고양이 성체/강아지 아기 두 구성을 추가해 총 136시트·568프레임을 생성했다. 필요한 로컬 PNG를 시각 확인하고 동일 픽셀의 빈 가족 구성은 검토를 재사용했다. 이미지 해시와 검토 범위는 `artifacts/scenery/copy-furniture-visual-review.json`에 기록했다. 이전 1,920프레임/네 방향 검토 수치는 이번 수정의 근거로 사용하지 않는다.

관련 자동 검사와 전체 빌드 결과, 발견/수정 사항은 `copy-furniture-bug-report-2026-10-17.md`에 있다. 기존 권한 게이트 제약 때문에 실제 브라우저·휴대폰 실기 검증은 수행하지 않았다. 로컬 PNG 및 jsdom 검사를 브라우저 최종 검증으로 세지 않는다. 기존 이벤트 676개 제작 완료 기록과는 별도 작업이다.


## 2026-10-17 비율·성장 단계·반려동물 수정

짧은 유아의 앉기에서 머리·몸통을 자르던 공용 의자 변형을 적용하지 않고 실제 다리 행만 굽힌다. 아이는 가구 옆 작업 공간을 사용하며, 얼굴·손·발 위에는 소품을 덧그리지 않는다. 벽걸이는 사용 전후 같은 벽 높이를 유지한다.

고양이/강아지는 이미 작게 그린 원본을 재축소하면서 한 픽셀 발·몸통·귀가 빠지던 문제를 수정했다. 원본 픽셀을 보존하고 발 기준선을 맞춘다. 놀이 중 떨어진 코 색 점을 제거했으며, 아기는 작은 웅크린 원본을 쓰고 수면 전후 방향을 유지한다. 계단 높이와 빗질 받침 접지를 조정했다.

항아리 숨숨집은 코만 들어가던 작은 입구를 실제 정면 동물에 맞춰 넓혔다. 집 앞 → 등을 보이며 입장 → 안에서 얼굴 내밀기 → 바깥으로 나오기의 네 단계로 구분한다. 네 동물 구성의 실제 렌더러 비교는 `public/assets/furniture/copy-pet-hideaway-review.png`에 있다. 실제 동물 좌표·성장·저장은 변경하지 않는다. 새 필사 반려동물 가구는 근처에서 누르는 사용 방식이며 자동 방문 행동은 아직 추가하지 않았다. 기존 반려동물 침대의 자동 사용은 유지하고 아기 수면 크기를 수정했다.
