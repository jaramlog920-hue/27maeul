## 검사 범위·제한과 기존 suite 실패 분류

최초 분담은 독립 엔진 모듈 59개, 관련 기능 TS/TSX 24개, 장면 모듈 4개를 전체 읽었고, game.ts/store의 사회·가족·연애·이야기 핸들러는 명시한 범위를 집중 검사했다. 세부 파일과 깊이는 `COVERAGE.json`에 있다. 현재 재검증은 최초 7건과 직접 연결된 변경 소스 및 생산 호출/렌더 경로에 집중했다. 외부 변경된 58개 파일 전체를 이 분담에서 다시 완전 읽었다고 주장하지 않는다.

기능별 현재 확인 수는 가족 옷장 1, 세대 동반자 렌더 1이다. 소모임 저장/복원, 출산 간격, 후계자 결혼 준비 호감도, 연애 보상 중복, 가구 재배정은 위의 표적 재현에서 각각 0건이다. 이는 해당 기능에 다른 문제가 없다는 뜻이 아니다.

과거 `full-suite.json`의 실패 assertion 15개는 독립 분류해 `TEST_FAILURE_TRIAGE.md`에 저장했다. 그 실행은 현재 소스 변경 전이므로 현재 제품 결함의 근거로 합산하지 않는다. 분류는 과거 제품 연결 오류이나 현재 수정 코드가 있는 항목 2, 기대값/fixture 변경 항목 10, 시간 한도 2, 빌드 산출물 전제 1이다. 최종 현재 suite 결과는 root의 재실행 결과를 따른다.

실제 장기 플레이, 전체 날씨·계절·모바일 픽셀, 브라우저 새로고침, 실제 계정/운영 저장, 모든 난수 조합은 이 분담에서 실행하지 않았다. 축제 준비 stage3에서 참가 인원이 사라지는 경계 상황과 가족 여행의 선택 아이 전환은 정상 UI로 이어지는 확정 재현이 부족해 버그 개수에서 제외했다. 자녀별 생일 처리 범위는 문서화된 의도와 전원 보상 계약이 확정되지 않아 별도 버그로 세지 않았다.

우선 수정은 SOC-06의 인물별 옷장 대상 일치이며, SOC-03은 동반자 생성 중복 제거다. 모든 버그를 찾았다고 보장하지 않는다.
