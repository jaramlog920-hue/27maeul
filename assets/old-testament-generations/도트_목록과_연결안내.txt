1. 원본
src/render/old-village-art.ts
- OLD_PROPS: 서고·가족·이사·기억 소품 24종
- OLD_JOB_SIGNS: 직업별 표식과 작업 소품 10종
- OLD_TERRAIN: 땅·길·물·심는 자리·나무·꽃·왕래 표식 10종
- OLD_BUILDINGS: 시설/일터 25종 × 4방향 = 100장
- OLD_CONSTRUCTION: 25종에 적용하는 공통 공사 골격 × 4방향 = 100장
- OLD_INTERIORS: 건물 내부 배치 원안 23장
정지 그림 합계: 267장. 방향·공통 공사 상태·내부 배치도 포함한 수량.

src/render/generation-art.ts
- generationRows: 아기·유아·어린이·청소년·성인 × 4방향 × 4프레임 = 20시퀀스
- familyFrame: 달래기·아기 안기·함께 읽기·식사·심부름·견습·작품 보여주기·이사·맞이하기·듣기 = 136시퀀스
  아기 안기/달래기는 성인만 PNG로 내보낸다.
- familyPairFrame: 함께 읽기·식사·맞이하기 × 4방향 = 12시퀀스
동작 합계: 168시퀀스, 프레임 672장.
PNG 합계: 2,971장. 분리 레이어도 포함한 파일 수이며 새로운 물건 수가 아니다.

2. 디자인과 크기
16px가 한 타일. 투명 PNG, 정수 좌표, nearest-neighbor 확대만 사용한다.
건물은 64×64px, 내부 배치 원안은 128×96px.
건물은 공통 건축 양식에 지붕 창·굴뚝·직업 소품을 바꾼 모듈형 디자인이다.
공사 골격은 시설별 고유 건축 과정을 뜻하지 않는다.
건물 4방향은 지붕/문 위치를 별도로 그렸다. 이미지 회전으로 만들지 않았다.
서고 책장은 전시 소품이다. 필사 용량·기름 소비·능력치 효과가 없다.

3. 원본을 게임에서 사용할 때
정지 그림: OLD_VILLAGE_PALETTE로 rows를 그린다.
그림자 z는 RGBA 색상이다. PNG에는 제외하고 게임 렌더러의 기존 그림자를 쓰는 것을 권장한다.
동작: propBack → actor → propFront 순서.
인물은 writerPalette(계절, 실제 외형), 소품은 OLD_VILLAGE_PALETTE를 각각 사용한다.
외형·성장 단계·방향·프레임은 함수 입력으로 전달한다.
내보낸 PNG 인물은 샘플 외형이다. 모든 주민에게 샘플 PNG를 그대로 입히지 않는다.
머리·옷·장신구 색 선택은 기존 외형 데이터와 캐시를 그대로 사용한다.
PNG의 성인/자녀 색과 원본 배우자/주민 색을 같은 팔레트로 합치지 않는다.

4. 좌표와 이동
정지 소품의 anchor, 건물의 anchor/entry/footprint는 manifest에 있다.
건물의 footprint는 제안값 4×3타일, 그림은 4×4타일로 윗부분이 걸친다.
실제 지도 연결 전에 엔진의 출입구·통행·충돌 좌표를 확정한다.
뒤를 보는 건물은 문이 없고 entry:null이다. 앞/옆 문 위치를 읽어 사용한다.
공사 그림은 완성 건물의 entry를 그대로 상호작용 입구로 사용하지 않는다.
마당·정원은 열린 공간이다. 건물처럼 전체 영역을 막지 않는다.
내부 PNG는 배치 원안이다. 가구 재배치 기능에서는 바닥·벽과 OLD_PROPS를 각각 그려야 한다.
그림만 보고 길이 안전하다고 판단하지 않는다. 출입구부터 이용 자리까지 경로 검사가 필요하다.

5. 함께하는 사람
한 사람의 동작 캔버스는 24×24px.
두 사람 예시는 48×24px이며 각 24px 캔버스를 좌우로 배치한다.
인물 그림을 가로로 늘리지 않는다. 실제 게임에서는 두 인물의 실제 좌표와 앵커를 각각 사용한다.
키가 작은 인물은 위쪽 투명 여백으로 바닥 위치를 맞춘다. 확대해서 성인 키로 만들지 않는다.
성인+아이 예시는 가로 배치 원안이다. 자리·손잡기·가구 공유는 실제 엔진 좌표로 조정한다.

6. 재사용하는 기존 자산
결혼식: wedding-art.ts / weddingActorFrame
생일·발표·집들이·손잡고 걷기: event-life-motion.ts / eventMotionFrame
직업 손일·요리: cooking-art.ts / cookingFrame
가구 사용: furniture-use-motion.ts / furnitureUseFrame
건네기·받기·그림·직조·물 주기: expansion-life-motion.ts / extraUseFrame
이번 가족 동작 일부는 위 동작의 크기/단계를 맞춘 재사용이다. 전부 새 동작으로 세지 않는다.

7. 아직 게임에 자동 적용되지 않는 것
구약 맵 개방, 건설, NPC 자율 결혼/출산, 계보, 독립은 계획 18·19의 구현 항목이다.
새 기능의 완료·보상·일과·실제 참석 여부는 그림 함수가 결정하지 않는다.
구약 서고 아침빛은 기존 화면 밝기/빛 효과로 연결할 연출이며 이 묶음에 영상이나 완성 연출 코드가 있지는 않다.
앞으로 확정될 개별 주민의 꿈터·특별 선물·고유 외형은 인물 설정을 정한 뒤 추가 그림이 필요하다.
이번 묶음은 현재 기획에서 정한 공통 시설·성장·가족 생활을 위한 실제 원본이다.
