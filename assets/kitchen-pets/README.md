# 요리·펫 용품 원본

요리: 포도즙, 보리죽, 올리브빵. 펫 용품: 방석, 실뭉치, 물그릇.
재료 및 중간 상태 포함 16×16 도트 14종과 8×8 아이콘 14종.

요리 모션은 으깨기·따르기·젓기·담기·섞기·빚기·굽기·빵 담기 8동작을 남녀 예시로 내보냅니다.
펫 모션은 고양이·강아지 성체/새끼의 방석 쉬기·실뭉치 놀이·물 마시기입니다.
수정된 새끼 앞뒤 걷기도 포함합니다. 총 30세트, 각 4방향·4프레임입니다.

`manifest.json`의 `views`는 PNG, 재생 시간(ms), 발 기준점, 분리 레이어를 제공합니다.
레이어 순서: back → actor → front → hands. 손 레이어는 인물 팔레트를 사용합니다.
정지 도트는 가구 팔레트, 펫 actor는 동물별 팔레트를 사용합니다.
요리 인물 24×24, 펫 용품 장면 32×32, 새끼 걷기 16×16입니다.

`preview.html`은 스크립트 없이 자동 재생되는 APNG 미리보기입니다.
재생 APNG는 통합 미리보기 내보내기 시 만들어집니다.

재생성 순서:
```
node scripts/export-kitchen-pets.mjs
node scripts/export-all-assets-preview.mjs
```

게임의 요리법·소지품·상호작용은 연결하지 않았습니다.
