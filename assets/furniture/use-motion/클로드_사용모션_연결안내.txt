27마을 — 가구 사용 모션 연결 안내

위치: assets/furniture/use-motion/
원본: src/render/furniture-use-motion.ts
재생 미리보기: 미리보기.html (브라우저에서 열기)

완료 분량
8개 동작 × 4방향 × 4프레임 = 128개 투명 PNG 프레임.
각 동작/방향에 96×24 전체 시트와 캐릭터·뒤 소품·앞 소품 시트 제공.
개별 프레임 24×24, 원본 픽셀 크기 그대로 사용. 확대 시 nearest-neighbor 적용.
앉아 쉬기 / 차 마시기 / 책 읽고 장 넘기기 / 바느질·손일 / 반죽하기 /
물건 꺼내고 넣기 / 장난감·인형 쓰다듬기 / 누워 쉬기.
장식 가구 자체의 개폐·불빛 애니메이션, 이동부터 착석까지의 전환은 이번 분량에 포함되지 않는다.

외형 유지
PNG는 기본 봄 기록자 예시다. 플레이어와 주민의 실제 머리·옷·장신구는
furnitureUseFrame(who, facing, action, frame, spriteOpts)로 현재 캐릭터 옵션을 전달해 생성한다.
actor는 writerPalette(현재계절, 현재avatar) 또는 기존 주민 팔레트로 그린다.
소품은 USE_PROP_PALETTE로 그린다. 캐릭터용 팔레트와 합치지 말 것.
성장/short 옵션도 기존 spriteRows에 전달된다. 어린이별 가구 높이 조정은 연결 단계에서 검토한다.

그리기와 위치
함수의 actor/propBack/propFront는 각각 24행×24열 문자 픽셀 레이어다.
가구 뒤쪽 → propBack → actor → propFront → 가구 앞쪽 순서로 겹친다.
가구 전체를 무조건 마지막에 그리면 캐릭터가 가려질 수 있으므로 의자 앞다리,
책상 앞면, 침대 이불처럼 필요한 전경 영역만 분리할 것.
좌표 원점은 반환 anchor를 실제 사용 자리 좌표에 맞춰 뺀 위치다.
interaction은 손과 소품의 접점이며 anchor와 별개다. 부지 충돌 박스로 사용하지 않는다.
방향은 down(앞), up(뒤), left(왼쪽), right(오른쪽).
누움의 앞/뒤는 세로 침대 위에서 본 몸 방향, 좌/우는 가로로 누운 몸이다.
기존 가구 회전 그림을 90도 회전시키지 말고 이미 만든 방향별 가구를 함께 선택한다.

재생
manifest.json에 프레임별 duration(ms), anchor, interaction, 권장 가구 목록이 있다.
duration을 순서대로 누적하여 0~3 프레임을 반복한다. 타이머로 게임 상태를 매번 갱신하기보다
기존 렌더 루프의 경과시간을 사용한다. 취소/이동 시 사용 상태와 자리 점유를 해제한다.
권장 가구 목록은 자동 상호작용 등록이 아니다. 가구별 자리·사용 조건을 직접 연결한다.
reach의 물건은 갈색 상자 예시, pet의 대상은 장난감 예시이며 실제 아이템에 맞게 교체 가능.
이번 작업은 사용 모션 자산과 생성 함수까지 완료. 게임 사용 메뉴/상태/저장 연결과 배포는 하지 않았다.

검수
동작·방향·프레임 모두 정수 좌표, 투명 배경. 왼쪽 방향은 오른쪽을 한 번만 미러링.
뒤를 보는 캐릭터의 소품은 뒤 레이어에 배치. 선택한 캐릭터 외형을 유지하는 방식.
게임 연결 후 각 가구 높이와 앞뒤 겹침, 어린이, 긴 머리/옷, 사용 취소를 실제 화면에서 확인할 것.
