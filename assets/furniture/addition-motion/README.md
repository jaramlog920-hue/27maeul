# 가구 48종과 생활 모션 · 4방향

정지 가구: 48종 × 4방향 = 192개. 캐릭터 사용: 11종 × 4방향 × 4프레임 = 176장면. 가구 움직임: 여닫기 8종 + 흔들의자 + 하프, 총 10종 × 4방향 × 4프레임 = 160프레임.

사용 모션: 흔들의자, 재봉, 반죽, 세면, 하프 연주, 그림, 설거지, 맷돌, 물 주기, 인형 눕히기, 수레 밀기.

여닫기: 긴 서랍장, 옷장, 보석함, 씨앗 정리장, 빵 보관장, 이불장, 화장대, 바느질함. 프레임 0 닫힘 → 1 열기 → 2 열림 → 3 닫기 → 0.

## 픽셀과 배치

16픽셀 타일 유지. 넓은 2×1칸 가구의 옆면은 1×2칸이며 세워진 그림을 90도 돌리지 않고 따로 그렸습니다. 앞모습은 대부분 원본 유지. 흔들의자는 정면 좌석·팔걸이를, 수레는 양손으로 잡는 손잡이를 다시 그렸습니다. 왼쪽은 별도로 그린 오른쪽 모습의 반전. 대칭 가구는 일부 방향이 같을 수 있습니다.

가구 움직임 PNG는 방향별 원래 캔버스 유지. 사용 장면은 48×48px 캔버스에 실제 크기 가구·10×14px 캐릭터와 손동작을 담았습니다. 캔버스는 여백이며 인물이나 가구를 확대하지 않습니다.

## 재사용과 레이어

use/의 PNG는 기본 외형 예시. 실제 캐릭터는 additionUseFrame(who,facing,action,frame,opts)로 생성하며 외모·머리·옷·계절을 유지합니다. 레이어 순서는 furnitureBack → propBack → actor → furnitureFront → propFront. 각 레이어 시트와 합성 시트, 개별 합성 프레임, 앵커·접촉점·프레임 시간이 manifest.json에 있습니다.

preview.html에서 방향 필터와 일시정지로 확인. use/*-review.png는 방향별 4행, 프레임별 4열. directions/preview-1~4.png는 가구 12종씩 방향 4열.

원본: src/render/addition-furniture-directions.ts, src/render/addition-furniture-motion.ts. 재생성: node scripts/export-addition-furniture-motion.mjs.

상태: 도트와 모션 자산 완성. 게임 내 상호작용·구매·저장·NPC 행동에는 아직 연결하지 않았습니다.

## 2026-10-12 전체 모션 보정

의자에서는 좌석에 골반을 맞추고 무릎을 접으며 발은 자연스럽게 매달립니다. 작업대 앞·뒤의 인물은 원근에 맞는 서로 다른 바닥 위치를 쓰고, 옆모습 작업대는 캔버스 깊이가 높이처럼 늘어나지 않게 다시 그렸습니다. 손은 기존 craft-followup/work-details의 2픽셀 손바닥·아래 윤곽을 참고하고, 짧은 옷소매로 몸에 연결합니다. 뒷모습에서는 머리와 등이 팔·손·도구를 가립니다. 수레 손잡이와 인물은 같이 이동하고 발걸음을 번갈아 딛습니다. 상자 뚜껑은 경첩에 붙어 회전하며, 서랍·문은 가구 본체와 연결된 채 열립니다.

actorAnchor는 서 있을 때 발, 앉을 때 골반을 뜻합니다. manifest 프레임의 posture는 standing/seated/crouching을 구분합니다. 모든 방향 확인용 이미지: use/all-directions-review.png, objects/all-directions-review.png. 미리보기에서는 4·6·8배 확대와 프레임별 정지를 지원합니다.
