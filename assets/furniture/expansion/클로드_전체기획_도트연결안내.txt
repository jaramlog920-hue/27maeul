연결 규칙
원본 TS: src/render/expansion-prop-art.ts, expansion-life-motion.ts.
내보내기: node scripts/export-expansion-art.mjs
게임에 기능/렌더러/메뉴/저장 연결은 이번 작업에서 하지 않음. 배포도 하지 않음.
선택 색·모양과 사건 완료 표식은 기능 담당자가 실제 데이터와 대조해 연결.
같은 외형의 표지·일정표는 데이터 글자를 UI로 얹는다. 실제 이름을 도트에 고정하지 않는다.
props는 방향 독립적인 작은 물건. 4방향이 필요한 시설은 structures 사용.
좌판과 그늘막은 앞/뒤 3×2타일, 좌/우 1×3타일. 배치 충돌 영역은 기능에서 확정.
열린 찬장/미완성 의자 등은 상태 자산이며 기존 가구를 자동 교체하지 않는다.

외형과 그리기
PNG는 기본 봄 외형 예시. 현재 머리/옷/피부는 extraUseFrame(who,facing,action,frame,opts)로 유지.
actor는 기존 writerPalette 또는 주민 팔레트. extraUseFrame의 propBack/propFront는 FURNI_PALETTE.
기존 furnitureUseFrame의 소품은 USE_PROP_PALETTE. 두 소품 팔레트를 혼동하지 않는다.
props와 배우자/아이는 현재 실제 참여자·선택 물건으로 조합.
extraUseFrame의 기본 propId는 예시다. 실제 상품/작품/도구로 교체 가능.
물주기와 차따르기 기본 대상은 소품 예시이며 실제 대상 화분/컵 위치를 맞출 것.
동물 기본 샘플의 놀이/물어오기 물건도 실제 petToy/toyBall에 맞춰 교체 가능.
소품 자체 투명 PNG를 흰 배경으로 바꾸지 말 것. 확대는 nearest-neighbor.

앞뒤 레이어
가구 back → propBack → actor → propFront → 가구 front 순으로 겹친다.
이번 분리는 기존 픽셀을 앞뒤로 나눈 기본 마스크. 두 레이어를 합치면 원본과 정확히 일치.
실제 착석 위치/침대 방향/어린이 키에 따라 컷 위치와 기준점을 화면에서 검수·조정해야 함.
자동 분할만으로 모든 겹침이 맞는다고 간주하지 않는다.
명령/이동/사용 취소와 자리 예약은 그림 자산에서 처리하지 않는다.

반복
sitDown/standUp/lieDown/rise/give/take는 단발 재생. 나머지는 반복.
미리보기는 확인을 위해 단발 동작도 잠깐 쉬었다 반복하지만 게임은 완료 후 상태를 전환.
어린이 기존 사용 8종은 반복 동작으로 재생.
성장·아기·성인·반려동물 명령 조건은 실제 기능 상태를 따르며 그림으로 판정하지 않는다.

검증과 남은 연결
정수 픽셀·지원 팔레트·캔버스 경계·가구 레이어 복원·동물 프레임 변화 검사.
실제 집과 마을에서 4방향·휴대폰·긴 머리/옷·어린이·새끼 동물의 겹침 확인은 기능 연결 후 필요.
이 패키지는 전체 기획에서 공유할 기본 자산 묶음이다. 최종 상품 종류/추가 선택 갈래마다
전용 무늬/소품이 필요해지면 지원된 원본 템플릿에서 확장한다.
말씀 조각·필사본은 상품/재료/생활 작품으로 사용하지 않는다.
