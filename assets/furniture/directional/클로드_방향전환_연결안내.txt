집 가구 20종 — 네 방향 실제 도트 원본
작성일: 2026-10-05
상태: 도트 제작 완료. 방향 선택 UI·배치·저장·렌더링 기능에는 아직 연결하지 않음.

파일
각 가구 ID-down/up/left/right.png: 실제 크기의 투명 PNG, 총 80개.
atlas.png: 같은 도트 80개를 4열 20행으로 모은 투명 시트.
preview-3x.png: 픽셀을 그대로 세 배 확대한 확인용 이미지.
manifest.json: 파일별 크기, 점유 칸 크기, 시트 위치, 옛 기본 방향.
원본: src/render/home-space-directions.ts의 HOME_SPACE_DIRECTIONS.
재생성: node scripts/export-home-space-art.mjs --directions

시트
각 행은 가구 하나, 왼쪽부터 down(앞), up(뒤), left(왼쪽), right(오른쪽).
행 순서: table, chair, stool, teapot, cupboard, fruitBowl, supplyChest,
basket, chest, longBench, daybed, cushion, pillows, mat, woodToy, clothDoll,
bookcase, lectern, nightstand, lantern.

그림 기준
16px = 한 칸. 기존 가구 팔레트와 기존 아이템 ID를 사용.
세워진 가구의 앞·뒤·옆면을 따로 그렸고 이미지를 단순히 90도 회전하지 않음.
탁자·찻장·긴 벤치·휴식 침상·돗자리는 앞뒤 2×1칸, 좌우 1×2칸.
나머지는 모든 방향 1×1칸.
대칭 소품은 같은 그림을 공유하는 방향이 있음. 누락이 아니라 의도된 대칭.
방향에 따라 손잡이·등받이·수납장 앞면·무늬가 달라짐.

기능 연결 순서
1. Furniture에 facing 선택 상태를 추가하고 네 방향 선택 UI를 만든다.
2. 그림은 HOME_SPACE_DIRECTIONS[item][facing]로 선택한다.
3. footprint는 고정 FurnitureDef 크기 대신 해당 방향의 w/h를 사용한다.
4. 회전 시 기존 가구 크기에 따른 충돌·필수 통행·벽·방 범위를 다시 검사한다.
5. 탁자·협탁 위 소품이 있는 회전은 규칙을 정한다. 안전한 초기안은
   소품을 먼저 회수하도록 안내하고 소품이 있는 표면은 즉시 회전시키지 않는 것.
6. 회전 실패 시 위치·방향·가방·소품을 모두 그대로 둔다.
7. 옛 저장의 방향 누락은 HOME_SPACE_LEGACY_FACING 기준으로 보완한다.
   기존 의자와 나무 장난감은 right, 주전자는 left, 나머지는 down.
8. 이웃집의 기존 flip은 기본 그림 기준을 먼저 확인하고 새 facing으로 변환한다.
   같은 그림에 flip과 facing을 동시에 적용하지 않는다.
9. 렌더러 캐시 키에 방향을 넣는다. 가방 아이콘은 대표 방향 하나를 사용해도 된다.
10. 저장·불러오기, 가장자리 회전, 문 앞 통행, 표면 소품과 점유 칸을 검증한다.

렌더링과 배치
방향별 이미지의 왼쪽 위는 가구 점유 영역의 왼쪽 위.
이미지 width/height와 점유 영역이 일치하므로 현재 TILE 배율로 그린다.
기존 on 소품의 높이 보정은 유지하되 세로 탁자의 놓이는 면을 확인한다.
이미지 보간을 끄고 정수 픽셀 배율을 유지한다.
입력 및 저장 방향은 down/up/left/right를 사용한다.

현재 게임의 기본 가구 도트와 동작은 이번 파일 추가로 바뀌지 않는다.
공간 지정과 가족·동물의 자리 이용은 별도 기획 기능이다.
