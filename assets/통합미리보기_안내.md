통합 미리보기는 이 폴더의 `preview.html`을 열면 볼 수 있습니다.

앞으로 추가하는 도트와 모션도 이 통합 미리보기에 등록합니다. 별도 미리보기만 제공하지 않습니다.
주소 끝 `#pack=newland-building-upgrades`는 건물 묶음 필터이며, 책 다시 펼치기는 `#pack=book-reopen`입니다. `전체 묶음`을 누르면 모든 추가 자산을 함께 볼 수 있습니다.

- 전체 / 모션만 / 정지 도트만 / 모든 원본 PNG 중에서 선택합니다.
- 왼쪽에서 결혼식, 생활 동작, 입주, 제작, 동물, 건물 등 자산 묶음을 고릅니다.
- 이름을 검색하고 방향, 속도, 확대 배율, 배경을 바꿀 수 있습니다.
- `크게 · 프레임`을 누르면 개별 프레임과 인물·소품 레이어를 확인할 수 있습니다.
- 한 번 동작은 마지막 자세를 잠시 유지한 뒤 다시 재생합니다. `한 번 동작도 이어서 반복`을 끄면 마지막 자세에서 멈춥니다.
- `모든 원본 PNG`에는 개별 프레임, 시트, 분리 레이어와 이전 비교 이미지까지 모두 들어 있습니다.

로컬 파일로 바로 열 수 있습니다. 목록 데이터는 옆의 `preview-data.js`에서 읽습니다. 스크립트가 실행되지 않아도 첫 페이지의 그림과 분류·페이지 링크는 표시됩니다. `preview.html`만 따로 옮기지 말고 자산 폴더를 함께 보관하세요.

`all-preview/all-all-1.html`은 스크립트 없이 작동하는 기본 미리보기입니다. 네 가지 분류, 자산 묶음, 이전·다음 페이지를 링크로 이동하며 모든 방향의 모션을 자동 재생합니다. 검색·속도·프레임 조절은 `preview.html`에서 사용합니다.

기본 미리보기의 움직이는 PNG와 페이지는 `all-preview` 폴더에 생성합니다. 이 폴더는 원본 PNG 목록에 포함하지 않습니다. 기존 그림 원본은 그대로 읽고, 미리보기를 다시 만들 때 최신 그림을 반영합니다.

자산을 추가하거나 목록이 바뀌었을 때 프로젝트 폴더에서 `npm run preview:assets`를 실행하면 목록을 다시 만듭니다. 그림 원본이나 게임 연결을 변경하지 않습니다.
